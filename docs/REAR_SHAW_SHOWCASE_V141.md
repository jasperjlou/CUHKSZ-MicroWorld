## 实际更新

- 新增「图书馆后侧 · 沿车道到逸夫」：从沥青后场沿现有车道绕学生中心楼角，到后门短进出，再沿升坡进入逸夫东座较高的后入口。路点使用当前地形高度，保留 V74 楼角折线，不恢复旧版穿楼斜线。
- 新增「逸夫东座 · 门廊与公共台地」：前场浅阶、黄色门廊、折返梯、三层开放平台。上下段之间按既有产品明确剪辑；每章内部是原角色物理步行，无受阻瞬移。
- 黄色门廊撤掉误借的食堂马赛克，复用低纹理哑光表面。准确现状涂层仍未确认，不声称材质实测。
- 东座五处梯段补齐踏步视觉立面：旧 120mm 厚踏步小于单级高差，产生细长漏光缝。只给本楼调用启用封闭立面；坡面碰撞、尺寸及其他建筑调用不变。
- 平台结束镜头回望院落、扶手和层间关系。视角回归脚本用章节 ID 定位，增加章节不会让旧索引错指别的楼。
