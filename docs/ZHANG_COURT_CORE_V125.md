- 在后侧短连接翼设置折返楼梯，切开四个使用楼层的梯井并保留屋顶，补半层平台、梯底、栏杆、门框及地面入口。

## 来源和精度

ROCCO 一期校园首层/三层平面支持后侧连接翼的楼梯核心及院内交通关系。图纸年代未标，不当成当前竣工图。2026-10-10 用户照片 222250、222257 的 EXIF 支持近期拍摄（设备时钟未独立校准），可见两层外廊、连续铜色格栅、混凝土梯与细杆栏杆；官方 D 全景用于首层门廊与柱梁环境交叉核对，拍摄日未知。

位置、梯井约 4.8×12.5 米、梯宽 1.9 米、走廊宽 3.2 米及四个沿用楼层标高均为模型拟合。历史图像分辨率不足以测绘梯井角点；本批结构仍不能认定为现状所有核心和完整房间布局。来源、哈希及限制见 `references/visual_build_20261008/zhang_core_v125_evidence.json`。

## 集中检验与修复

初版较宽梯井和转角通道与斜楼翼重叠，地面直接目标还撞上支撑柱；初批失败不计验收。改为后侧连接翼的较窄净空井，入口支路避开柱，随后四层上行及前两层连接通过，下行暴露梯面碰撞余量在平台端形成小挡边。

将梯面碰撞余量以短斜面回接平台后，对受影响四层楼梯集中复核：45 段单起点连续记录覆盖后路—地面门口—四层上下行—顶层院廊—回到后路，全过。另保留上一批未受影响的 9 条前两层连廊/门口记录；旧的 3 条相关梯段记录由新批替代。合计 54 条局部有效记录、2 个起点，不是一次全校园巡游。

物理复核后只收尾栏杆外观和重叠铺地：栏杆碰撞盒的尺寸/变换保持原值，重叠楼板改成无重叠分区但实体占用并集不变；新增导航元数据不改几何。之后集中复看四个最终视角。初版被斜墙挡住的院落机位已作废并更换。没有 SCRIPT ERROR/ERROR，最终物理与渲染批均退出 0。索引：`tests/artifacts/zhang_core_v125_accepted.json`。
