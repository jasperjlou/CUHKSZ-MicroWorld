# V176：田径场植栽边坡与外侧街道

开发线 `2.0.1-dev`，东门原点保留，真实北向未校准。稳定版 v2.0.0 不覆盖；全 A–G Goal 继续。

## 证据与年代

复看[十周年二期校园航拍](https://10.cuhk.edu.cn/phase-ii-campus)，田径场是高起平台，外缘绿色围网下有植栽坡面，城市道路在较低处绕过综合运动馆白色端翼。图像目录 `2023-11` 只说明上传路径，不能当拍摄日期。模型使用白色端翼侧、对侧等相对方位，不据此猜测地理北向。

结合[2023-12-06 校运会报道](https://10.cuhk.edu.cn/node/605)的800米和跳高照片，撤回上一批沿用的三个推定围网开口。报道记载活动发生于12月2日，具体照片拍摄日期未从原始元数据核实。馆前敞开通路继续保留；临时施工围挡不作为永久建筑。图片哈希和采用范围在 `references/visual_build_20261008/track_bank_v176.json`。

## 模型修改

- 新增 `TrackOuterSite.gd`，以局部地形函数建立田径场外缘植栽坡、较低街道、树带、自行车带和石材步道；街道绕白色端翼一端转折，接回现有校园路。
- 撤掉原同高矩形外圈实体铺装，导航轨迹分别交由场内边缘铺地或新街道网格表达。撤三处无照片依据的围网开口，保留馆前开放入口。
- 灯塔基座随坡地落位；移除悬空旧坡边座椅，以及此前“西门方向”占位铺装、灯杆和世界标牌。方向线索仍在台账中，真实校门位置待核，不作建筑实体。
- 解决接坡草地穿面：单纯加密地形不能解决弯道两段中心线投影的高度跳变，改用共同横断面推算坡度，并在坡道路面横向分段。局部地形0.75米采样，其余边坡1.5米；收窄路段不再画出界的白色车道线。

田径场标高2.24、低处街道-1.76，约4米相对高差、18米道路宽度、3米步道、曲线和植栽分布均为照片拟合，未称测绘精度或无障碍坡度达标。没有沿另一端施工区域镜像补一条城市道路。

## 集中检验

主批次 `TrackBankV176.gd` 完成20段分批通行、3起点、8检查。收尾 `TrackBankV176Finish.gd` 完成4段接坡往返、1起点，发现加密地形后草条仍存在，因此这些画面不能证明该问题解决。共同横断面修正后 `TrackBankV176Grade.gd` 完成6段接坡通行（步道往返4段、沥青2段）、2起点，最终转角与接坡两图逐张查看，横穿道路的草条消失。三批合计30条成功记录/6起点、8检查；不是30条独立当前路线或单次全区连续验收。旧接坡坐标由最终6段取代，平地弯道调整横断面后仅复看画面，未按新的精确步道中心坐标重走。

最初辅助函数覆写及浮点类型推断错误已修复，失败日志保留；两次后续运行退出0但未生成最终报告，仅有清理警告，明确不作为通过记录。最终隐藏进程完整生成报告，失败列表为空，最终标准输出/错误日志无引擎错误或警告。保留4张分范围有效图：早期总览仅证明未改的田径场/坡面，早期坡面近景及最终转角/接坡图各按范围使用；哈希见 `tests/artifacts/track_bank_v176_accepted.json`。只复查本次受影响的道路段，不重复验证校园其他楼栋。
