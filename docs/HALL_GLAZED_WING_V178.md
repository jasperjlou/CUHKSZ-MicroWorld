# V178：大学体育馆玻璃候坐侧厅

开发线 `2.0.1-dev`。东门原点不变，真实北向仍未校准；稳定 v2.0.0 不覆盖，整个下园 Goal 继续。

## 实景依据与模型

重新查看校方[体育馆接待厅全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116440785)资源70037182的左、前、右三个面：接待厅侧墙有开放矩形通口，候坐区有通高玻璃、浅色宽柱、横梁分隔的上部窗带、外侧竖向遮阳片，以及红色壳形椅、白色圆桌和浅灰地板。全景拍摄及发布年份未知，不能标成十周年或2026现状照片。

原侧翼为实心体量，接待厅侧墙也没有实际开口。本批改为空心玻璃侧厅，补实体地板/顶板、分段侧墙和门头、两层窗带、柱梁、灰色铺地、条肋吊顶、灯具及两组候坐家具。原体育馆高墙在侧厅范围内退让，保留上部主馆围护。侧厅延续既有建筑局部坐标和侧翼位置；25×21米范围、0.84米楼面、7.25米顶板底及4米宽侧口均为拟合，未完成全景与独立楼层图的配准。

校方设施页79及103只用来区分大学体育馆/综合运动馆功能，后者列大学体育馆健身房102、综合运动馆302，不能据此推断房间平面。已有外景不能定位背面门位，因此背面和完整下层空间保持未核状态。

## 验证与画面修正

一次集中物理检查：主入口—接待厅—侧口—候坐区—原路返回20段，馆外侧廊4段，合计24段、2起点；8项墙/门头/地板/顶板/玻璃边界探针全部通过。两次运行日志无引擎错误或警告。

首批4图检查发现：外景机位进入邻近综合运动馆，不可当外观证据；窗顶约10厘米细缝、旧墙窗梃重复穿在新窗前。随后补非碰撞窗顶收口、移除重复装饰窗梃，改用两馆间侧廊机位，仅复看3图。最终4张分范围有效图（共查看7张），未改变物理结构，不重复步行。接待厅开口画面复用未改初图。

来源、日期限制、原图哈希见 `references/visual_build_20261008/hall_glazed_wing_v178.json`；验证记录见 `tests/artifacts/hall_glazed_wing_v178_accepted.json`。
