# 下园区间修正 v31

2026-10-10。用户反馈：图书馆往逸夫、科研楼及体育馆一段，道路、建筑结构和排列不像。

- 依据校方 2026 年 5 月导览图与全景 130027046、116443798，修正诚道 / 知仁 / 乐天的前后与道路侧别。诚道由 `(-32,-646), yaw=90` 移到 `(59,-666), yaw=-90`；乐天由 `(46,-652)` 移到 `(108,-713)`。坐标为东门局部 X/Z，不是真北方位。
- 道路、入口铺地和导航点同步修改。逸夫至主广场主路增加折转；服务路绕开乐天与逸夫西座；楼群内留出横向步行巷。
- 图书馆前场从下沉中庭西侧通往学生中心，再由 x=30 的连廊下方通行，避开 x=38 的高架步行楼梯。灰色块材步道接逸夫东座、主广场和科研楼 / 体育馆。
- 逸夫东座临街端面改为宽灰墙与窄窗带；科研楼补圆柱、悬挑檐、水平分缝与梁底，下层铺地连成整体。科研塔楼上部仍为前期估计体量，本轮没有证据宣称其高度已核实。
- 增加树池、绿篱、长椅、灯杆和排水口；科研楼车道上的设施退到侧边。
