# V165 旧馆成对楼梯与上层通路

2026-10-12，开发模型 `official-visual-build-165-old-library-paired-cores`。正式版 v2.0.0/V145 不覆盖。

## 依据

本轮下载并逐张查看校图书馆[馆内地图](https://library.cuhk.edu.cn/zh-hans/floor-maps)所提供的旧馆1F、3F、4F原尺寸导览图。三张图都显示一端的主楼梯/应急楼梯和另一端电梯；中央有楼梯/中空符号，四层有侧向附属空间。原图、页面快照、URL和SHA-256保存在 `references/visual_build_20261008/originals/old-library-plan-20261012/`。

这些是无比例尺、无北箭头的功能导览图，2020-09只是资源上传目录，不是绘图或拍摄日期。2026-10-12仍由官网提供，但不据此认定家具及分区已跟随2026暑期改造更新。[2026年7月官方简报](https://cuhk-shenzhen.libguides.com/Newsletter/2026-7)明确8月1日重开及知新二楼纳入图书馆统一管理。二层图未公开，不能用三层图冒充。

## 实际结构改变

- 原模型上层为连续封板，没有任何通往上层的楼梯。新增成对的独立折返楼梯，连接当前地面、2F、3F、4F；每层有入口平台、中间平台、两跑楼梯、连续栏杆、围护和开门净空。
- 低横楼的4.6/8.3/12m楼板切真实洞口；保留15.7m屋顶。洞口以互不重叠的矩形分割生成，不把内洞误三角化为实板。
- 撤去同一区域旧大厅整片装饰吊顶，避免盖住楼梯开口；对应楼板底面仍存在。
- 对端补封闭电梯井及门缝；没有实现电梯功能。没有按老导览复制房间名称和家具配置。
- 门口初次实走发现12cm平台边缘阻挡，补1.2m长的局部过渡坡接现有地面；保留失败记录。

导览图的入口侧与既有院落入口对齐、成对梯配置到局部-X端，均为有标注的方位拟合，不是测绘配准。84×14.56m低横楼和0/4.6/8.3/12m楼层高度沿用既有估计，不从导览像素硬推尺度。

## 验证

最终62段连续往返、1起点、15检查通过，4张最终画面逐张查看，无有效日志引擎错误。收据：`tests/artifacts/old_library_cores_v165_accepted.json`。183个导出依赖路径去重及存在性检查通过，未重新导出正式包；本批只覆盖新增两梯、公共厅至其入口及连接上层，不代表整栋或全下园完成。初次测试的辅助函数名cp与继承链重名，在场景运行前解析失败；改为ocp后才开始物理检查。随后首个门槛受阻，未继续之后路段。失败日志及初批JSON保留；初批截图文件由最后运行的同机位终图覆盖，不作为独立初图归档。

## 保留的结构缺项

第三座对端楼梯、中央采光井/中央楼梯、完整楼翼尺度与入口朝向、二层现状分区均待核。尤其另一端现有教学返回翼与低横楼存在部分重叠，后续需先按四层附属空间与外观注册体量再接第三核心，不能将两份重叠楼板当作合理结构。

学生中心028分解轴测及033横剖面本轮已看，尚不能识别032的平面剖切线；局部低房间与下沉院沿廊房间不混同。既有77点旧模型交点不重扫。下一批继续旧馆完整结构配准/中庭与对端核心，再F/G侧后区域；图书馆后路G2F和全A–G缺项保留，Goal active。
