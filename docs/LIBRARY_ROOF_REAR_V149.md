# V149 图书馆后翼端面与屋顶收口

2026-10-12，开发模型 `official-visual-build-149-library-roof-rear`，产品版本 `2.0.1-dev`。稳定版 v2.0.0/V145 不覆盖，整个下园 Goal 继续。

## 本批模型

- 两处上层后翼端头从齐平玻璃改为内退玻璃，补浅灰厚边框、中柱、横梁、细窗梃和红褐色深侧壁。玻璃及边框保留封闭碰撞。采用既有公开平面的边 0/12，没有移动建筑或旋转方位。
- 屋顶增加沿轮廓转折的低金属挡边与压顶；连续天窗基座提高，并逐顶点贴合屋面坡度，避免原水平盒子底缘局部漏缝。保留两个中庭的独立楼板洞口。
- 四根现有跨层柱由原固定顶高 25.2 接到形状屋面的底面，保留 0.6 米碰撞占地；其中原平面点 `(850,740)` 的柱脚悬在 2F–3F 楼梯洞上，向旁侧三楼实心楼板拟合约 1.3 米至 `(865,754)`，整根同步移动。其余三根柱脚不动。这是消除模型悬空的几何校正，不是测绘柱网；模型共用一个屋面高度函数，避免柱、天窗和屋面各自漂移。

端面退距 1.35 米、框厚、天窗和屋面挡边高度均为图像拟合，不能称为施工尺寸。整个屋面仍是形态近似，未完成构造测绘。

## 验证

批次完成后集中运行 `tests/LibraryRoofRearV149.gd`，其后只续查未完成的左窗净空和受影响的柱脚。结果以 `tests/artifacts/library_roof_rear_v149_accepted.json` 为准，保留初次失败与后续替代索引。

初批左窗横走目标穿入原 Cambridge 书架边缘；日志明确命中 `OakStacks_Cambridge/Solid`。改走玻璃与书架间已有净空，未删除家具或缩小玩家碰撞。原柱脚探针一处失败，渲染确认悬在楼梯边；最终柱脚改到完整楼板，补查四角楼板、柱身各层、旧位置净空及三楼旁侧通道。旧柱脚机位与旧位置检查退休。窗顶第一次补面仍后缩而露出水平亮缝，改为前后两面后只重看端面。

验证只覆盖改动端面的碰撞、窗边通道、这四根柱的局部连接及屋顶最终画面，不代表完整承重系统或全馆验收。没有重跑未变的全校路线。

接受结果：**19 条有效分批移动记录、4 个起点、34 项局部检查**；9 张图已查看，其中 6 张用于各自未被后续修改影响的范围。屋面/天窗、未移动柱顶图保留；两个端面采用补齐窗顶后的图；移柱采用最终柱脚图。不是一次连续全馆游览。相关三次运行日志无引擎错误；169 项导出依赖均仍存在，未重建稳定包。

## 接续

官方后路图同时显示下层后墙以灰色实体墙及窄窗为主，当前沿用旧平面的下层返翼仍需按各层独立配准校正。不能仅按上层端面向下拉伸，也不能把上层端面与下层整面玻璃混为一谈。

下一批先注册下层后翼墙、门和柱脚，再接学生中心真实下层入口及服务门。保留完整柱网、屋面更精确轮廓/设备、六层前端房间身份与室内、所有 A–G 地面/高差/道路/背面/角落和跨区连接待办。东门原点不变，地理北向仍未校准。
