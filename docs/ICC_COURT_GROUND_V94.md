# 会议中心下层地面与支撑 V94

2026-10-11，东门原点及 V69 会议组团锚点保留。

本批对照官方 ICC Avenue（116443783）已有正/右图，并补存、查看背/左图，参照会议中心入口全景及 V69 已存建筑师航拍。官方全景拍摄日期未知；建筑师文章发布于 2025-12-24、列竣工 2024-01，均不当作照片拍摄日期。来源 URL 与文件哈希见 `references/visual_build_20261008/icc_ground_v94.json`。

## 实际改动

- 填补门厅平台下、悬挑玻璃翼旁及外梯脚的默认草地缺口，形成连续硬质铺地。区分廊内大块灰石与外围矩形石板。
- 新增带低石边的双层绿篱，分别表现低矮边缘和较高灌木，留出两侧通道。
- 补门厅平台下 6 根支撑柱、柱头/梁、方格吊顶、嵌灯和雨水管。
- 补连续排水条及外梯脚收口，保留既有绿色地面玻璃与凹入木门。

代码：`ConferenceCourtGround.gd`、`ConferenceAvenue.gd`、`ConferenceCentre.gd`；配置版本 `official-visual-build-94-icc-court-ground`。

## 验证

只运行一次结构批次：`tests/ICCGroundV94Capture.gd`。20 段真实移动均通过，从东门上平台进入 ICC 侧路，经过门列、侧翼/绿篱绕行及平台下方，再上外梯进入门厅并返回东门。单次 fixture 内未传送。Godot 退出 0，无脚本或引擎错误。

4 张画面已查看，其中阶前高机位落入邻楼体内，不能作为验收图；另外 3 张有效，覆盖门列大道、平台下方及东门侧总览。测试记录在 `tests/artifacts/icc_ground_v94.json`。没有为无效高机位重跑整批。

## 新发现与下一批

新补的左右向全景明确显示：真实 ICC 大道包含开敞天空的长段，对侧有连续绿篱和立面；现模型门厅突出平台覆盖大道的范围偏大。**当前 ICC 门厅、报告厅长边和大道的相对位置仍不准确。** 这属于楼体配准问题，不是本次通行或铺装检查能够证明正确的项目。

下一批优先重新配准旧 ICC 的主厅/门厅/突出玻璃翼与露天大道关系，并同步调整地面、入口和连接；不能继续沿用错误覆盖范围。花池范围、支撑间距和米制尺度本批仍属拟合。没有根据绿色地面玻璃另加地下层。其余 A–G 及图书馆主入口楼梯下面的馆内下层缺项继续保留，Goal active。
