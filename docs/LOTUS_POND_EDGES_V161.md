# V161 荷花池景墙、岸边灰石与栏杆

开发模型 `official-visual-build-161-lotus-pond-screen`，产品 `2.0.1-dev`。正式 `v2.0.0` / V145 和玩家/Agent 两个固定入口不变。

## 较新实景与对应关系

[校方图书馆书展报道](https://library.cuhk.edu.cn/article/981)发布于2024-01-29，活动时间为1月15–19日。其室外照片能看见左侧学生中心灰砖与黄色内退、池岸灰石、黑色栏杆，以及池端白墙的矩形透空格和圆形洞口。活动时间提供年代语境，照片没有确认到具体拍摄日。

已重新查看[官方荷花池全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116440795)的四张本地原始立方图：学生中心侧、图书馆侧及连廊侧的相对关系与上述特征一致。全景拍摄日未知，资源目录中的数字不当作拍摄年份；其中旗帜、节庆挂布不作为永久构件。

[建筑师中庭说明](https://wwjarch.com/Central-Courtyard-of-Chinese-University-of-Hong-Kong-SZ)支持底层、地面和上层连桥的复合连接关系，但未提供本池墙尺寸，不能据此补齐测绘精度。

## 实际修改

- 旧景墙为11米实心短板加表面条纹；改为沿当前池端的浅色墙体，加入真实矩形透空格、圆形贯通洞、压顶和深色石基。
- 四边已有步道与弧形亲水平台改深灰方石铺装，只改荷花池区。现有水面轮廓、地形开口和未变通行面保留。
- 连廊一侧增黑色竖杆栏杆及独立碰撞，保持沿岸步行通道和端部绕行。

新增模块 `world/visual_campus/LotusPondEdges.gd`，由 `LowerCampusLandscape.gd` 调用；没有使用现场照片作发行贴图。

## 精度边界与接续

当前51×26米池塘、26米景墙、1.86米墙高、8×1.2米透空格和1.12米圆洞均为照片比例及既有坐标内的拟合，尚无测绘验证。书展照片可以校对材料及相对特征，无法唯一确定被人物遮挡的入口门位，也没有解决学生中心真实下首层及图书馆后路标高。季节性荷叶状态沿用现有模型，不能称为2024年1月植被复刻。

东门原点保持，真实北向未校准。接下来继续中央入口/共享下层连接与图书馆后路G/2F，并覆盖D至F/G及全A–G缺项，Goal active。

## 本批验证

集中检查池岸一圈、景墙实际开孔、格栅和栏杆边界，未重复学生中心内部楼梯和全区测试。15段连续实走、1起点、8检查（7初检+1收尾）通过，无引擎错误。6张画面已看，4张分范围有效图；圆洞边缘仍有轻微着色接缝待渲染收尾。柱下草带和旧绿砖柱面已按全景修正为灰石与浅色饰面，未变通行复用。原始结果及最终验收索引见 `tests/artifacts/lotus_pond_edges_v161*.json`；证据与照片哈希见 `references/visual_build_20261008/lotus_pond_edges_v161.json`。


此次宽景对照还确认：注册后的学生中心池侧立面仍缺/错配黄色双层凹廊及上部红板。下一批优先核对该立面和入口，不能将池墙材料修复当作整片外观已像实景。
