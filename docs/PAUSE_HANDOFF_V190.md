## 恢复后的优先顺序

1. **玩家体验 / 视角**：先听取本版游玩反馈，再针对图书馆各层内梯、低顶、窄房间、转角以及其他楼栋复用 V190 局部相机验证。关注墙角回弹、升降平滑、遮挡和缩放。真实房间净高/门宽不足时单独核对图纸，不能靠整体放大错开已对齐标高。HUD 占屏、亮部过曝、角色简模等体验问题留后续。
2. **校外景观**：按可辨地标和已知道路关系分类。图书馆后侧墙绘挡坡和密林、张岭彬楼下林坡/水景、科研裙房与钟楼桥端的山体属于有实景约束的地形，保留并精修。无依据的均匀草底、随机远山、道路外裸坡、用于填空的背景才是待替换项；不一刀切削平真实山体，也不把中性外围底面宣称真实城区。先对照旧 GTA 的场地组织，再用较新照片核定颜色、植栽和边界。逐视角记录“保留 / 调整 / 无依据占位”，真实北向仍未校准。
3. **地板样式**：东门到学生中心优先；区分石砖尺寸/拼缝/带状分区、沥青、庭院砖、架空层、排水沟、路缘及真实草坪。已完成 V181–184 / V187–189 局部处理可复用，仍需精细对照，不能用统一草坪或一种砖铺满。
4. **层内结构**：主入口楼梯下面的馆内下层是用户明确的“负一层”；对应公开 1F 与全景 G。先检查净空、楼板开口、楼梯顶底、房间边界，再补隐蔽端部。学生中心 032 低层、旧馆 2026 改造及体育馆背面保持待办。
5. **拓扑与空间排列**：主入口—下层—外廊—背后车道—逸夫，学生中心连廊—知新—旧馆，再覆盖科研体育。C–D 共同标高、后路 G/2F 和后翼窗层数未配准；不能以局部走通替代真实连接验证。全 A–G 详细缺项继续保留在覆盖台账。

按地面 → 高差/楼梯 → 位置体量 → 立面/层内 → 连接 → 渲染推进，每个结构批次末集中验证。固定 v2.1.2 包不动；恢复时首个实际代码改动再转下一开发版本。
