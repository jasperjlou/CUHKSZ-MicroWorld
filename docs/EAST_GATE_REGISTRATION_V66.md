# V66 东门广场、右侧车行入口和连桥配准

## 改正的空间关系

官方内广场 `116443795 / 70040611` 的背向图块显示四根华表及校名石背面，右向图块显示右侧楼的深凹廊和旁边车辆入口。它们与摄影者 2026-03-06 发布的照片 7–10 相互印证。官方起点 `116410030 / 70013461` 的右半图块还显示门岗位于车辆通道右侧。

V65 只看了起点正向立方体面的一部分，把相机位置误当成礼仪中轴的定位依据，导致车道仍居中、门岗居左，前后双桥也未能判断。本批补齐关键方向和右半图块：全景相机在侧面车辆入口，不能代替名义上的“东门门槛中心”原点。保留 `(0,0,0)` 和入校 `-Z`、右侧 `+X` 的坐标约定，移动车道而非整体平移校园。

重要图块：`square-b-1-1/2`（四华表、校名石、横向路），`square-r-1-1/2`（凹廊、车行入口），`square-l-1-1/2`（左翼与街道）。每个 512×512 图块只覆盖一个立方体面的四分之一，不能当整面解读。
