# V243 图书馆后车道：墙脚排水沟、沥青收边与坡段标线

2026-10-14；开发 2.1.8-dev。本批推进模型，固定正式 v2.1.7 双入口不变。

## 改动及依据

官方全景 70037189 可见沥青直接接墙脚排水沟、白色边线、黄色虚线及细混凝土小梯。已阅读本地原图，来源和 SHA256 见 [证据](../references/visual_build_20261008/rear_road_finish_v243.json)。拍摄日期与发布日期未知，2026-10-10 是资料缓存日期，不能视为实景年份。墙面涂鸦仍是历史配色概括，未宣称复原当前作品。

- 模型 z=-340 至 -232 的道路—排水沟之间改为随坡沥青，移除该侧错误的独立路缘带和默认草缝。
- 水平盖板盒改为连续随坡网格，分出板缝、槽口与白色边线；虚线标记沿整条后车道贴合坡面。
- 小梯与盖板使用细混凝土材料，去掉过大的假砖缝；踏步尺寸和楼梯碰撞均保留。
- 涂色挡墙保留原碰撞，隐藏与涂色面相交的可见底网格，修掉坡度变化处的白色三角。
