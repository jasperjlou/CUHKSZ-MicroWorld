# Campus Exterior V4 — 外观校园 Beta

## 交付范围

分支 `world/campus-exterior-v4` 从 V3 `6cd48b04fc669dfe92e33b82fe2b63feabfa8fea` 建立。V3 用独立场景保留；本轮新入口是 `world/campus_exterior/CampusExterior.tscn`，没有重定向 RC1。

这一轮解决的体验问题：

- 音乐学院原先由通用体量组成：改为两座曲面表演体量、三个教学庭院体量、遮阳竖片和短水平连接；第八书院另保留两栋住宿体量。外观数量词汇有官方文字支持，具体形状、层数和关系仍推理。
- 书院原先共用相近布局：道扬/思廷/学勤/祥波/永平/厚含/第八/逸夫东西组团改为不同塔楼位置、宽深比例、退台和院落开口。道扬补独立门廊；思廷、学勤和逸夫的楼群数量由文字资料支持。
- 建筑背面与屋顶过简：44 栋保留全周立面，并补四边低围边和保守屋顶设备轮廓；没有把推理的设备轮廓当成真实机房测量。
- 车行/步行线叠在一起：对 30 个共线段建立侧向车行带，保留既有步行节点和交汇点；车行与步行分别使用铺地、路缘、路灯和过街词汇。六条车行线、九条步行线的高层拓扑不变。
- 地形平台转折生硬：过渡从 12 扩为 42 游戏单位，地面采样从 10 改为 5；地面与碰撞共享同一三角网格。建筑内部高程优先于邻近平台，修复综合运动馆入口被邻近平台抬高的问题。
- 广场挡边与测试出现在地下：上园广场改为贴地铺装；物理路线的独立起点改为当前地形高度，修复旧高程导致的错误出生位置。没有改角色速度、重力、碰撞掩码或移动 API。
- 连廊过多：保留 8 段短开放廊道，而非无依据的大型全校园廊网；原 44 处入口、三处湖区地标和两处占位站点仍有可走接入。
- 湖区缺少身份：题字石改为非规则岩石轮廓、绿色竖排“神仙湖”、碎石/低植物；亭子补瓦色分层屋顶与白色栏杆；水面加入低成本微波纹。沿用既有湖岸与地标锚点。
- 远处没有校园上下文：补三层推理山脊、背景地面延续、已有校门两翼和简化挡墙。山体无游戏碰撞，不代表真实山名、朝向或山高。
- 开发标签干扰场景：正常模式隐藏浮动名称、边界与置信图；F1/F6 仅在需要时显示。实际校园牌面允许双语；玩家 HUD 用简体中文。
- 每次启动重新铺路和造窗：静态场景预烘焙，保存网格、批量实例与简单碰撞；运行时仅载入缓存和玩家/界面。缓存与源数据指纹绑定，可重新生成。

## 启动与演示

运行 `启动校园外观V4.cmd`。`-Presentation` 从校园总览开始。F2 切换地面/俯视；0 全校园；1–4 分区；5 地标巡览；F1 中文置信信息；F6 置信热图；R 返回上园。

旧 `启动校园主规划.cmd` 保留 V3。`project.godot`、GodotPhysics3D、CharacterBody3D + move_and_slide()、Agent/benchmark 与科研默认入口未改变。

## 可维护的烘焙与复查

源代码和数据保留为可编辑构建器，版本化副本用于保证 V3 完全不变；不能只改旧 V3 构建器后期待新缓存自动更新。

```text
python tools/build_exterior_v4_data.py
python tools/check_campus_exterior.py --bake
python tools/check_campus_exterior.py --walk
```

烘焙必须使用可渲染的 Godot 进程。无窗口渲染服务器不能可靠保存 MultiMesh 实例缓冲；脚本明确拒绝 headless bake。已经添加渲染检查，逐批确认缓存中窗格和绿化实例变换非零。源文件哈希归一化 CRLF/LF，兼容 Windows/Linux 克隆；二进制场景另有 SHA-256。缓存约 6 MB，不使用 LFS，不包含原始摄影/全景/旧 GTA 模型。

若源数据变化，指纹失效时运行时会改用可编辑构建器；正式演示前应重新烘焙，避免退回较慢的构建过程。地面采样 JSON 是由构建器生成的估计地形，不是实测数据。删除/重生成前应保留源数据。

## 验收记录

本轮数据和源文件审计 795 项通过，覆盖 44 栋和 95 个置信记录；冻结的 78 个 V3/RC1 源文件保持一致。原空间审计 1770 项、原环境采样审计 272588 项、RC1 核心 279 项均零失败。

物理路线使用原玩家控制器和方向/快走输入；每条独立路线只有起始定位，连续巡游没有中途传送。无窗口最终回归 4126 项通过，92490 次物理采样，约 12651.58 游戏单位。不是现实米数或首次人类通关时间。

带画面路线完成上园→中园/湖区→下园、反向回程、16 条独立往返/湖岸环线，以及一次连续 13 地点巡游：道扬→思廷→上园服务区→西岸亭子→东岸题字石→音乐学院→下园体育馆→图书馆→学生中心→行政楼→会议中心→教学 A 庭院→逸夫东组团（下园结束）。最终带画面数字见下方交付数据。

额外检查 44 栋每栋入口的三处胶囊探测；44 张背面/屋顶斜视图和置信图。视觉复查用于发现缺面、缓存丢实例、建筑下方断层和标牌裁切，不构成实景盲认测试。

## 性能与边界

Godot 4.5.1 / GL Compatibility / Intel Arc 130T。同一校园总览、关闭垂直同步、120 帧短采样；原先不属于本任务的旧校园实例保持运行。正式测量不与另一验收进程并行。

本轮尝试动态太阳阴影，但增加绘制调用且初版色调映射过曝，最终采用中性线性色调、柔和环境光与太阳光，关闭动态阴影；保留建筑轮廓与玻璃/木材色差。没有新增后处理、反射探针或复杂水面反射。小窗框/遮阳件和灌木具有距离可见性范围。

以上是开发者脚本与截图验收，不是港中深学生的首次试玩或识别率测量。空间仍有风格化和概括性，不能称为照片级复刻。少数门廊/屋顶、真实道路侧向位置与高程还需新资料；不为这些缺口无限补证。
