# V83 道远后立面与知新设备屋面

模型版本：`official-visual-build-83-rear-screen-service-roof`。Goal 继续 active。

## 实际改变

- 道远后翼上部由通用平墙改为退台玻璃窗带、四排真实镂空屏墙及横向支撑梁；两端小体块和屋顶设备按可见轮廓补入。保留 V82 建筑位置和外围台地。
- 知新低屋面补蓝绿色分格顶罩、两座圆筒冷却塔、成组室外机、长管道与支座。冷却塔位于低屋面暴露区域，避开较高教学翼。
- 知新和道远屋面增加局部接缝、低反射与较大尺度风化色差，材质类型 36 只用于本批屋面。

官方下园航拍资源 92544949 的 l2_l_03_03、l2_l_03_02 是主要细节依据；原图与完整 URL 见 `references/visual_build_20261008/rear_roof_v83.json`。拍摄日未知，不将下载日期当拍摄日期。当前建筑关系沿用 V82 校方图和建筑师总平面。

前景知新屋面遮住道远后翼下部，后翼底层与低处立面仍是待进一步核对的拟合；本批没有因此声称全栋精确还原。照片不能确认蓝绿色顶罩是采光顶还是设备罩，故只复原外壳，使用不透明涂装面，不新增室内开洞。各层高度、体量、设备尺寸及管线路径均拟合。用户新照片未拍到这些屋顶，不用于给上述细节补拍摄日期。
