## 实际修改

1. B/C 入口增加小型斜遮檐、金属边框、分缝和斜支杆。B 遮檐范围的竖片下缘及横杆让位，避免相互穿插。位置按现有入口拟合，非精确测绘复原。
2. B 原外廊楼板穿出竖片屏幕，内退 2.8 个模型单位；补从院内楼梯平台至外廊的连接板、两侧及内外缘护栏。连接位置和玻璃护栏为当前拟合方案，需继续对照完整平面。
3. B 大厅及侧廊吊顶改用细密金属网板材质，前廊柱改平整灰白表面；C 入口墙改平整抹灰并补门楣玻璃和上框。
4. B 外侧地带、B/C 后通口和入口前庭改石材铺装；入口补收边、排水和检修盖。C 官方图明确可见的长条地面保留在廊内。
5. 集中看图发现 C 院落大板与廊内长条地面同高重叠，裁去院落/外前庭的覆盖部分，恢复两种地面的清晰边界。只改装饰面，无新增地面碰撞台沿。
