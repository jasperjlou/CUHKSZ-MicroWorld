# V150 图书馆下层后翼与室外学习区

2026-10-12；开发 `2.0.1-dev` / `official-visual-build-150-library-lower-rear`。全 A–G Goal 保持 active；稳定 v2.0.0/V145 不覆盖。

## 依据与改动

重新对照校方 1F/2F/3F 示意图、官方后路全景 `70037189` 中的灰砖窄窗墙、建筑师平剖面和十周年远景。二楼后缘独立配准后在左端约为局部 `(-39.72,-32.73)→(-9.19,-31.34)`；旧墙为 `z=-25.1`，明显缩在楼板内部。三楼具有独立端头和室外学习区，不能复用上层 C 字形凹口。

- 新增 `LibraryLowerRearEnvelope.gd`，分别沿二、三楼图示边界建造灰砖后墙、窄竖窗、细框、窗台和楼层收边；二楼办公室侧后缘及左侧卫生间体量随同一楼层边界收口。
- 三楼露台内缘采用玻璃外墙、两个拟合门洞；室外边缘增加有碰撞的玻璃护栏。办公室翼外露屋面仅保留二楼与三楼轮廓差集，不跨过三楼地面或当作新公共楼层。
- 撤去旧上层凹口形状的三楼玻璃，以及后侧通用玻璃盒子、占位柱廊和旧固定后门。
- 后门移到二楼长后墙的对应位置，重接原 G 公共走道、门厅、平台、短阶和侧坡。**G 服务围护、门位与后路标高仍为拟合假设**：公开 1F 图只标公共功能，未完整说明二楼办公室下方的服务空间；本批沿用既有 G 入口/0.48 米平台，不以走通证明真实入口就在该层。未对不可见办公室内部作精装。

## 验证与接续

本批先完成结构，再集中检查变动后的后门、门厅和三楼露台；失败目标保留，按实际碰撞定位后只续查受影响部分。最终结果以 `tests/artifacts/library_lower_rear_v150_accepted.json` 为准，不复测未变的全校路线。

初批后门到 G 公共走道及露台前半段通过；斜向目标 `(850,275)` 穿过露台玻璃，按真正门洞路线补查通过，未删玻璃。旧后墙移除探针 `x=-35` 实际碰到原卫生间后墙，改为检查原门口中线，未拆卫生间。随后验证新位置侧坡与三条露台护栏。

渲染发现旧地面沥青露在门厅内，改用 0.106 米石材完成面，并同步抬升内坡下端形成连续接缝；坡度只减小，其他碰撞不变，最后仅核查接缝标高与对应画面。带露台镜像文字的早期图、门厅未铺满与坡脚沥青图退休。

接受 **26 条分批有效移动记录、4 个起点、12 项检查**，9 张图已查看，6 张用于各自最终有效范围。26 段步行发生在最后内坡铺地接缝调整前；最后只补 3 个接缝标高探针及 1 个画面，没有把旧路线说成全部在最终铺地上重新走过。三次有效运行日志无引擎错误。170 项导出资源存在且无重复，稳定包未重建。

继续核准后路地面相对 G/2F 的共同标高、后门身份与服务区边界，补二楼公共区与办公室的真实分隔、三楼后侧家具/窄缝以及完整柱网。然后接学生中心下层真实入口、连廊和知新/旧图书馆道路。全 A–G 地面、高差、背面、边角、层间及跨区连接范围继续保留。
