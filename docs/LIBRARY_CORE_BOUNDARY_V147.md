# V147 图书馆左核心共墙与六层房间配准

2026-10-12，开发线 `2.0.1-dev`，模型 `official-visual-build-147-library-core-boundary`。正式版 v2.0.0 / V145 固定保留，完整下园 Goal 继续。

## 依据和年代

本轮重新打开[校方馆内地图](https://library.cuhk.edu.cn/zh-hans/floor-maps)，直接查看本地原始 4F、5F、6F 图片。4F 来源路径为 2021-11，5F 文件标注 202401，6F 来源路径为 2025-08；这些是图纸版本或托管时间线索，不是实景拍摄日期。本轮没有新取得珍藏室装修照片，继续只校正可被平面支持的结构与连接。

原件及 URL 见 `references/visual_build_20261008/originals/library-plan-20261010/manifest.json`。显示帧沿用 V112：4F 1920×1295、5F 1728×1470、6F 1820×1376。手工拾点和独立变换见 `library_upper_registration_v112.json`：5F RMS 2.92 像素，6F 稳定候选 RMS 10.08 像素。误差不能解释为实际测绘精度。

## 模型修改

- 原左核心包络投影到 5F 后，纵向约为 798–971，而图示核心上端约 785、珍藏室共墙在 952。旧末端侵入房间约 19 像素；按模型比例约 1 米，属于拟合差值。以 5F `(288,868.5)` 为中心、785–952 为纵向包络修正全部 G–5F 同一核心，位置变为 `(-26.84291846,0,8.45674881)`，拟合深度 8.6963、宽度仍 5.4。侧走道与整个核心外缘仍需进一步对应，不能把该宽度当实测。
- 楼梯、平台、电梯、墙体与各层楼板梯井统一使用新位置和尺度，避免只挪五层外皮而错开竖井。珍藏室靠核心的墙段改由核心末端墙承担，两侧短墙接回，消除重复面和凸入室内的墙块。核心内部布局仍为代表性结构，电梯不提供实际运行功能。
- 六层五组房间及 602–605 撤掉旧 `.97/+156/-11` 近似坐标，改用已独立拟合的 `point6`，同步平面旋转。房号及功能保持；本轮没有编造私密房间内部。示意房间尺寸、共墙细节、后翼和屋顶仍需精修。

## 集中验证

初批 `LibraryCoreBoundaryV147.gd` 包含移位后核心 G–5F、珍藏室沿墙通道、六层组团间走道和结构探针。四层侧门目标太靠中庭护栏、六层一条直线穿到房间边缘，均保留为失败记录，不计入通过。续查脚本从实际狭窄门外落点和组团外侧通道继续，不移动墙体来迎合直线目标。最终有效记录及范围以 `tests/artifacts/library_core_boundary_v147_accepted.json` 为准。

四个渲染机位用于核看珍藏室、共墙、核心上层出口和六层房间外侧。本批不是整馆或整个校园验收；未受影响的展示章节和跨区主线没有重跑。

## 接续
