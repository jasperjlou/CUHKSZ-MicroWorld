# V59 田径场尺度、场边铺地与出入口

2026-10-10，`official-visual-build-59-track-registration`。整个下园 Goal 保持 active。

## 依据与模型边界

校方[2023-03-14综合运动馆启用指南](https://peu.cuhk.edu.cn/article/368)说明九条跑道、天然草坪及两片七人制足球场；照片拍摄日未知。继续以十周年建成航拍和已查看的官方全景判断场地与运动馆关系，不能把上传年份当成拍摄年份。校方2026-10-09体育影片尚未逐帧查看。

旧模型第一道按内缘外0.3米估算只有约365.6米。本批采用[世界田联2019场地设施手册第1–3章](https://worldathletics.org/responsive/download/downloaddirect?filename=7d39b677-8043-45f4-89f4-6c8814023057.pdf&urlslug=Track%2Band%2BField%2BFacilities%2BManual%2B2019%2BEdition%2B-%2BChapters%2B1-3)的单圆心标准场地作比例依据：内缘半径36.5米、直道84.39米、道宽1.22米；第一道测量半径36.8米。手册同时包含其他曲线组合，因此这只是合理的标准尺寸模型，不证明校园使用完全相同的竣工线形，也不是比赛认证。

当前105×68米足球线为标准场地参照。校园两片七人制场地的实际球门、可移动球门和分区线仍未复现，不能以标准线替代现场布置验收。

## 已建内容

- 新增独立 `AthleticsGround.gd`：九道塑胶面、十条边线、终点横线/号码、天然草坪场心与足球线；每个半圆256段，降低弯道折线感。
- 场地锚点由 `[-14,2.24,-1018]` 改至 `[-14,2.24,-1030]`，给综合运动馆观景廊下与场边留出连续通道。12米位移是配准估计，地理北向仍未校准。
- 补跑道外石边、窄排水槽、环形石铺地、绿色轻围栏、灯杆和场外座椅。围栏使用独立薄实体碰撞，避免把通透网栏画成实墙。
- 两条直道侧及两个弯道端合计四处开口，重接外围步道与田径场支路。门位/宽度均为拟合，场周仍采用原平地标高。
- 移除没有充分照片依据的旧混凝土看台块。保留综合运动馆下折观景廊。
