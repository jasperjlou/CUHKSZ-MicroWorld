# V184：科研体育林缘与外围阶段收口

开发 `2.0.1-dev`；稳定 `v2.0.0` 保持。地面阶段有限收束后转玩家体验与 Agent 展示，再封装发布，深度建模排在发布后。

复看十周年体育组团鸟瞰，科研楼与场边的山林应接近坡脚。增加 74 棵林缘树及共享叶簇，按现有地形落位，科研裙房、侧梯和后车道保留至少 18 米的场地排除区。林下原默认草地改为林地表面；坐标与三角形形状未改，仅分材料批次。原远林位置使用独立随机序列保留。

原模型外侧铺了巨大绿色背景。改为近边缘过渡到中性底面的简化背景，田径场外侧延续此处理。参考旧 GTA 的有限场地呈现方式；这部分明确属于展示底面，不是现实道路、广场或周边城区的复原。真实田径场草坪、场外草坡保留。外围真实建筑、精细树种、测绘高程继续留待后续资料，不能称周边已经完整。

两次局部画面共查看 8 张，第二批 sports/street/outward 三张有效；两张 research 机位被钟塔或玻璃遮挡，不用作验收。进程退出 0，报告无失败，无引擎错误/警告。视觉改动未增加通行验收；重新分组的地形三角形坐标保持不变，当前主线通行将在体验阶段集中核验。

结合 V181 道路贴坡、V182 后路林缘和 V183 四区铺地复查，允许进入体验阶段。阶段边界：本次解决主要硬铺连贯性、明显路面重叠及主要视野裸坡；未宣称全下园测绘级完整，也未补外围城区。体验检查若发现卡路/坠落等发布阻塞，继续修掉；其余立面、隐藏房间和未确定层位不再扩展发布前范围。
