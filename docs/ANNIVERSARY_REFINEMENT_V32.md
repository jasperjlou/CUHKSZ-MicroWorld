# 下园十周年参照精修 · V32

本轮实现了东门至学生中心的铺地分区、知新楼缺失楼翼与错层体量、道远楼专用入口及弧形玻璃侧翼。校园精修 Goal 继续有效；V32 是可运行的阶段成果，不是全部楼宇和道路均已精确复原的结论。

## 已落地

1. 35 个显式地面分区：7 个硬质铺地区域、28 个嵌入草地，覆盖东门上层平台、中央大道、图书馆前、学生中心西侧绕行、连廊下方及知新楼前广场。中央轴线不再绘制为一条连续草坪。
2. 亚光灰色花岗岩的米制分缝、浅颗粒及粗糙度变化；横向深色条带、树池和齐平石边。水池、桥坡、下沉庭院、连廊楼梯保留开口；小地图同步读取地面区域。
3. 知新楼补齐另一侧楼翼；两端六层、内部横窗楼翼四层和较高后翼五层分别表达。新增翼的首层玻璃、门洞、地面、顶棚一起补齐。旧图书馆按知新楼组成部分处理，没有凭名称另造一栋重复建筑。
4. 道远楼替换通用 U 形门廊：高入口、竖向格栅、透空顶框、弧形分段玻璃翼及柱梁。校徽暂无清晰独立素材，当前采用楼名牌，占位未冒充真实校徽。
5. 主轴树冠增加高度与枝叶密度，按已有空间分组渲染；二次截图纠正了铺地过白的问题。

## 仍需继续的精修

中央区铺装已由草坪底图改为明确材质分区，但各条带宽度、铺地单元尺寸仍是照片拟合。知新楼背面、道路弯曲半径、场地高差、道远楼台地和更远楼宇仍需要多视角校方资料校正。当前画面是程序化校园重建，没有达到照片级完整复原；不能据这次步行测试宣布校园精修 Goal 全部完成。

启动：`启动入口/启动官方全景建造.cmd`。已经打开的游戏需退出并重新启动此入口，才能加载新生成的场景。无需重启 Windows。
