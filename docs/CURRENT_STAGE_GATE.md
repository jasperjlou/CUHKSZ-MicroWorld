东门原点不变，真实北向未校准。照片上传时间不作为拍摄时间。库内旧资产、实景和已完成的几何分析优先复用。

## 转阶段条件

1. **地面/外围 → 体验**：上述四个区间各有当前画面核对；所见明显铺地和连接问题已修或有具体可接受的阶段边界。只剩精确测绘、看不见的房间、历史图纸冲突等资料待核项时，保留后续精修，不拖延进入体验阶段。
2. **体验 → 封装**：玩家 F1、鼠标/镜头转向、基础移速与跑步、小地图、Esc 返回菜单可用；当前模型的重点游览路线能连续走通。基础移速复核用户此前要求的 2–3 倍改善，不在已调整值上机械再乘一次。
3. **展示 → 封装**：自动展示按空间顺序覆盖当前新成果；用人眼高度的接近、转角、短暂停留展现地面、立面、楼梯和下层，配少量总览。镜头不穿墙/埋地/被柱遮满，不靠大量高空俯视回避粗糙地面。章节剪辑明确，章内真实通行；更新被建模改动影响的旧路径。
4. **封装 → 下一轮精修**：集中验证当前主线与展示，生成可运行 Windows 正式包；GitHub 源码/tag/Release、构建校验和本地应用指向同一正式版本；干净路径验证玩家和 Agent 两入口。应用仍只有两个面向用户的入口。写发布收据和接续文档，然后才恢复深度精修。
