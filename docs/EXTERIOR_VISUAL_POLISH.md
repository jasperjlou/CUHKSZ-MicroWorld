# 外景与走道打磨 — 2026-10-08

当前 V6 启动入口默认加载这批外景更新。本机修改尚未推送；关闭正在运行的游戏，重新双击根目录 `启动游戏.lnk` 即可加载。

## 实际改动

- 44 栋建筑统一外墙、玻璃、石材和木质表面的细节与色调；14 栋重点建筑增加实例化窗框、窗台，共 6622 组。上园书院补局部空调盒。
- 道扬书院增加立面竖向院名；大学图书馆调整为深灰上部体块与较浅的下部体块，增加 58 根暖金色侧面遮阳格栅；学生中心采用较浅的灰色立面。
- 步行铺地增加错缝砖、石材分缝与轻微颜色变化；9 条步行路线增加 18 条细边缘收口，14 处重点建筑入口增加铺地引导；沥青增加低对比颗粒。
- 草地增加尺度较大的颜色变化；天空、日光、环境光重新配平并开启建筑与树木的实时投影，改善体块和柱廊的明暗层次。

新增细节由 `world/unified/CampusExteriorPolish.gd` 与 `SurfaceDetail.gdshader` 在运行时生成。窗框、窗台、遮阳格栅与道路细边均是视觉几何；原道路骨架、门口、地形碰撞和室内入口没有重建。新增细节使用批量实例和距离裁剪。原 V4/V5 烘焙资源保留。

## 参考来源与使用范围

实际下载并查看了 5 张实景：道扬书院外立面、设计方中庭航拍、学校官方图书馆内外景。参考图存放在 `references/visual_polish_20261008/originals/`，模型使用自行编写的程序材质。

- [道扬书院实景来源](https://foundation.cuhk.edu.cn/foundation/category_article/27/37)：白色外墙、窗框、空调盒、竖向书院名称与架空基座。
- [建筑设计方中庭项目](https://wwjarch.com/Central-Courtyard-of-Chinese-University-of-Hong-Kong-SZ)：图书馆深灰外壳、浅灰学生中心、遮阳格栅、廊道与石材庭院。
- [学校图书馆官方照片](https://www.cuhk.edu.cn/zh-hans/article/6130)：立面、玻璃分格与室内木质阅读空间。本轮主要使用外景特征，室内照片留作后续细化。
- [学校官方校园全景导览](https://campusvr-en.cuhk.edu.cn/)：已获取当前导览页面；从已有场景索引整理 30 处相关入口。本轮没有完整巡视全部全景，也没有导入全景图作为游戏资源。
- 用户提供的 `A:/项目/港中深GTA旧资产/` 是 Tuanjie 打包播放器。本轮查看了目录格式及项目已有旧模型空间记录，未重新进行大体量资源提取。

照片特征用于风格化建模，格栅数量、窗台尺寸、细部位置仍是创作解释；本轮没有测绘校准或新增真实道路位置的确认。图片网址、文件哈希和使用记录见 `references/visual_polish_20261008/manifest.json`。

需要复现本批渲染时运行：

```powershell
& .\.tools\godot\Godot_v4.5.1-stable_win64.exe --path . --fixed-fps 60 --script res://tests/ExteriorPolishCapture.gd
```

调试对照可在末尾添加 `-- --no-exterior-polish`，关闭新增程序材质与细部，使用相同的当前光照。正常启动无需添加参数。
