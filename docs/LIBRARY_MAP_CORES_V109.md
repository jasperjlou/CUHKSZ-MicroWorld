# V109 公开平面配准与两组核心筒纠偏

2026-10-11；版本 `official-visual-build-109-library-map-cores`。完整下园 Goal active，未提交或推送，旧GTA源包未改。

## 本轮证据改变了什么

V108四楼家具虽已落地，但将现有三组核心中心硬当固定锚点，会使公开4F平面出现明显残差。复看公开1F、4F、5F、6F、建筑师平面/剖面和两张中庭照片后，发现V107按旧1F灰模一个大方形直接拟合15.2×15.2斜核心，不能作为当前核心边界的充分证据。左侧早期8.6×15.5核心也过深。

因此先纠正跨层基础，未在错误外壳里强塞401 FabLab或把整圈外窗改为玻璃。四楼不规则开口及完整楼翼仍未替换，本轮不是四楼整体精修完成。

## 可复用配准数据

`references/visual_build_20261008/library_public_map_registration_v109.json` 保存全部手工锚点、变换、误差及下一批开口轮廓。

- 公开1F归一显示坐标1818×1344，通过101–104、106–109、105、110、111五组房间中心，拟合现有局部坐标；RMS约0.200模型单位。它证明内部对应一致性，不是现场测量精度。
- 公开4F归一显示坐标1920×1295，用三组跨层核心中心对应公开1F；RMS约10.02个1F归一像素。图标中心/手工点有误差，不称为竣工测绘。
- 旧4F灰模1440×900的两处开口八个角点，单独对应公开4F；RMS约12.06个4F归一像素，图面旋转约90.12°，无镜像。该角度是两张图之间的关系，不是真实北向。
- 4F旧模型没有套1F尺度；全外壳仍需独立留出点核验，Y/层高没有由此校准。

公开图来源为[校方馆内地图](https://library.cuhk.edu.cn/zh-hans/floor-maps)，本地文件由原manifest追溯；1F文件标注202401，4F位于2021-11路径，5F版本202401，6F路径2025-08，均不能当拍摄日期。建筑师历史平剖面/实景来自2021-03-16发布的项目资料，只用于稳定结构。2024年更新家具证据继续沿用V108。
