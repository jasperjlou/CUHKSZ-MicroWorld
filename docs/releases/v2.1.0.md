模型 `official-visual-build-184-perimeter-closeout`，含 V185 玩家/展示及绘制优化。Windows x86_64，Godot 4.5.1。本次归并 V146–V185 的成果，正式版固定后继续校园精修。

## 本次更新

- 图书馆：修正部分核心共墙、上层公共空间、屋面/后翼、主入口梯下馆内下层与后侧出入口；补后车道至逸夫沿线地面和林缘。
- 学生中心与荷花池：按历史图纸、较新实景和旧资产几何重建局部比例、柱网、核心楼梯、跨院楼翼、连廊与院落梯，细化黄饰面/红网/灰石景墙和池岸。
- 知新旧馆、科研、体育：补旧馆核心、中庭及学习区；科研裙房、入口、侧路、台地；体育下穿、白色端翼基座、连棚和场周通道。
- 地面/外围：修坡面铺装悬浮、路口铺装侵入车道，调低砖面过强色差，补合理林缘；外部用中性展示底面收口。真实草坪和林地保留，尚未重建周围城区。
- 玩家：镜头复位与拖动状态修复；保留原基础步速 2.5 倍、跑步、右键转镜头、缩放、左上小地图与 F1/F2。
- Agent：16 章编排导览，修图书馆小组室/旧馆旧坐标，改善池岸、下层和狭窄连廊机位，加入门口与室内细节镜头。章内真实物理步行，跨章明确淡出剪辑。
- 绘制：241,760 个不透明盒实例按空间合批，实例与物理体保留。东门本机短采样由约 68 降至 35 毫秒/帧；仍有性能余量，不承诺稳定 60 FPS。

## 运行

完整解压 Windows ZIP，运行「玩家游玩.cmd」或「Agent自动展示.cmd」，无需安装 Godot。保留整个 `runtime` 文件夹。程序未代码签名。

玩家：WASD 移动，Shift 跑步，右键拖动转镜头，滚轮缩放；地图点击设目标；F1 查看坐标依据，F2 俯视，R 回东门，Esc 回双入口菜单。

Agent：空格暂停/继续，左右键切换章节，Esc 回菜单。这是编排导览，不代表外部模型自主视觉导航。

本机包固定在 `builds/releases/v2.1.0/Windows/`，根目录两个快捷方式在核验发布时切换至该包。v2.0.0 及原入口映射保留用于回退。构建命令：`python tools/build_stage_v185.py --release`，已有正式构建时拒绝覆盖；复现需单独工作区/输出目录及本地 4.5.1 引擎、导出模板。
