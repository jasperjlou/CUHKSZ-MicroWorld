# v2.0.0 · 下园校园阶段版

模型基线：`official-visual-build-145-zhixin-crossing`。Windows x86_64，Godot 4.5.1。此版固定当前主要建筑、分层道路和游览体验；校园精修继续推进。

玩家与 Agent 使用同一套校园。玩家可自由探索，右键转镜头、滚轮缩放，基础步速为原版 2.5 倍，左上小地图可设目标。F1 显示坐标依据，F2 俯视，Esc 返回两入口菜单。

Agent 展示为 15 章编排导览，约 7 分钟：东门铺地与台阶、教学前廊及高差、图书馆格栅／池岸／主入口梯下馆内下层、学生中心下沉廊与庭院、后车道至逸夫、逸夫东／西座公共层及山桥、旧馆／科研／体育区。章节内真实身体移动，跨章节明确淡出剪辑；空格暂停、左右键换章。它不是外部模型自主视觉导航。

## 本次固定的成果

- 教学 A–B–C–D 后侧分层道路、楼板／核心楼梯、低翼与场地接口。
- 图书馆公共下层及上层核心、池岸／入口、后侧接学生中心及逸夫的路线。
- 学生中心下沉连廊、服务门面、庭院连接，以及主广场至旧图书馆和科研体育区的道路。
- 逸夫东座两院落、西座三翼／两井／折返梯与公共窗墙、四层侧桥及展示路线。
- 知新／旧馆路口导航改走实拍护栏开口，绕开墙角；铺装按材料分区收口。

## 验证与边界

15 章展示 151 条移动记录、12 项产品控制检查通过；记录来自 V144，V145 没有修改其章内路线。跨区主线在 V145 上完成单起点 133 条连续移动记录；不包含所有房间和支路。

正式 EXE/PCK 从干净工作目录实际启动：玩家 9 项、Agent 10 项检查通过；两种无测试驱动的原生入口也正常退出。最终两个 GPU 画面已查看。详见 [公开验收记录](v2.0.0-validation.json) 与 [包校验](v2.0.0-build.json)。本次版本整理未改变 V145 模型物理，不重复整段路线测试。

以东门为原点，真实北向未校准。楼距、层高、平面及部分不可见空间仍是资料拟合；主线通行不代表全校园精度验收。图书馆整体上下层配准／116 接缝／5–6F、学生中心完整门位、教学楼实际下层房间、逸夫屋顶、各楼背面与边角继续保留在覆盖台账。

## 安装与入口

下载 Windows ZIP 并完整解压，双击“玩家游玩.cmd”或“Agent自动展示.cmd”，无需安装 Godot。`runtime` 文件夹需一同保留。程序未代码签名。

本机固定构建在 `builds/releases/v2.0.0/Windows/`；项目顶层两个快捷方式指向此包。旧入口归档在 `tools/legacy-launchers/`，编辑器与历史研究仍可使用。开发运行用 `tools/LaunchProduct.ps1`，未验收源码改动不覆盖稳定包。

构建命令：`python tools/build_stage_v145.py --release`。需要本地 `.tools/godot/` 下的 Godot 4.5.1 及已校验的 Windows x86_64 导出模板。导出清单为默认产品及 autoload 的明确依赖，原始照片、全景、旧 GTA 模型和详细几何提取数据不随包发布。
