Agent 入口改为目标探索：用户选择校园地点或公共空间，Agent 从当前位置规划路线、真实行走并观察，也可连续探索附近两处。支持暂停、停止和中途改目标；受阻后重规划，无路可走时明确失败。原建筑编排导览保留为模式内选项。

采用本地规则 Agent，共用玩家的真实物理和碰撞；不依赖付费模型、不在任务中传送。当前精修场景尚未接入的 NPC、乘车等互动不作为可用动作。

同时包含 V257 道远台地金属栏杆、两处楼梯护栏接头、砖铺排水，以及旧馆后路铺面接缝修整。

已验证东门至广场、中央广场、图书馆主梯下空间与附近探索，覆盖暂停/继续、取消、动态障碍和不可达反馈；并非所有校园起终点组合已验收。全下园仍持续精修，尺寸拟合、真北未校准。
