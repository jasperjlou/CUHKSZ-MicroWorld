# v2.1.6 图书馆、学生中心精修与 30 章校园展示

新增图书馆 209–213 公共房间基础围护，细化 209 培训室座席、墙板和照明，按较新资料补预约取书柜、咨询台和还书口；校正公共阶梯，细化格栅顶和石铺。

学生中心分开首层前梯与 301 西侧宽梯，修门外平台和横廊连接，补采光顶、院落灰砖、石阶前缘及平台格栅。玩家位置提示能区分新前梯、二层院落、西侧宽梯与西门平台。

Agent 新增四个章节，总计 30 章。七个受影响章节实走 102 段、5,962 次镜头采样通过；另 23 章复用 221 段旧证据，合计 323 有效段，不声称最终整轮无中断重播。玩家复用本批结构阶段的局部验收；23 张源码画面和独立包双入口另有记录。详见 PRODUCT_REVIEW_V235.md 和发布验证收据。

Windows 包完整解压后，选择“玩家游玩.cmd”或“Agent自动展示.cmd”，无需安装 Godot。WASD 移动，Shift 跑步，右键转镜头，滚轮缩放，V 切换第一/第三人称；展示空格暂停，左右键切章。章节内实体行走，章间有剪辑。

这是持续精修中的阶段版；尺寸、部分层位与采光井深度仍按资料拟合，真实北向未校准，并非校方官方产品。原始资料、失败记录和全下园未解决项保留，v2.1.5 可回退；发布后继续 C–D 标高、灰栏梯端点和 032 等区间。
