# v2.1.1 · 图书馆外廊与近景游览

在 v2.1.0 基础上，合入 V186–V188 图书馆资料核对及模型更新，并完成 V189 游览与地面收尾。Windows x86_64，Godot 4.5.1。

## 更新

- 图书馆灰石铺地统一，五根廊下支柱改圆柱，暖色竖向构件调整；裁剪重叠旧铺装。
- 依建筑师文字、历史建成实景及官方全景，补地面至二层入口的连续曲面外廊、灰色栏杆和薄板底面，保留内侧地面通道。
- 补齐池岸横向道路与侧廊之间的半米铺装接缝；坡廊表面与二层楼板做视觉分层。
- Agent 增至17章，新增沿外廊走上二层的近景章节，池岸开场降低高度，下层入口机位避开坡廊遮挡。
- 玩家保留基础速度2.5倍、跑步、右键镜头、滚轮、小地图、F1/F2和Esc双入口菜单。

## 验证范围

本批受影响的图书馆四章40段物理通行、20项产品/输入检查通过；13张开发画面查看，10张为最终有效采样。其余13章和未改动主线复用v2.1.0对应范围的证据，不声称本批重跑整个17章或全校园。

独立EXE/PCK在干净工作目录验证玩家11项、Agent12项，并通过两种不带测试驱动的原生启动。两个导出画面已查看；ZIP内部文件、运行时SHA-256与源依赖校验已记录。研究原图、旧GTA资产和测试驱动不随包分发。

## 使用

完整解压ZIP，选择「玩家游玩.cmd」或「Agent自动展示.cmd」，保留整个runtime文件夹，无需安装Godot。程序未代码签名。

WASD移动、Shift跑步、右键转镜头、滚轮缩放、小地图选点；F1信息、F2俯视、R回东门、Esc回菜单。Agent空格暂停、左右切章。章节间有明确剪辑，章内实际步行，为编排导览。

## 阶段边界

外廊宽度及0/4.4层高仍为资料拟合，灰栏短梯的上下端、C–D共同标高、后路层位与全A–G精修未完成。新校方照片EXIF支持2026-09-07拍摄；历史图纸/全景拍摄日未明，不以上传日代替。保留东门原点，真实北向未校准。
