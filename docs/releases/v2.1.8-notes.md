# v2.1.8 图书馆下层、后车道与逸夫林缘精修

图书馆主入口楼梯下方的馆内下层按校方 2025 年换毯后的照片重做公共地毯与研讨室木地板边界，补圆角玻璃、磨砂膜、细门框、开启门扇五金和穿孔顶边。

图书馆后车道补连续随坡排水盖板、白边线和贴坡虚线，修墙脚草缝和挡墙白三角。逸夫支路补乔木、低篱及林下过渡，修掉接头处沥青和砖铺装重叠，并补挡土端墙、收齐坡肩。保留有依据的山形与维护草地；植被数量、尺寸和标高仍为拟合。

Agent 仍有 30 章，这次更新图书馆学习空间和后车道至逸夫两章。玩家第一/第三人称共 42 段移动、2,648 次镜头采样通过；Agent 两章 40 段、5,268 次采样通过，未记录实体重叠，玩家镜头连线无挡镜。其余 28 章保留 305 段旧证据，合计 345 有效段，并非本次全量重放。独立取景复核和包内双入口验证详见 PRODUCT_REVIEW_V246.md 与版本验证收据。

Windows 包完整解压后选择“玩家游玩.cmd”或“Agent自动展示.cmd”，无需安装 Godot。WASD 移动、Shift 跑步、右键转镜头、滚轮缩放、V 切换第一/第三人称；展示空格暂停，左右键切章。章节内物理行走，跨章节有剪辑。

这是持续精修中的阶段版，部分尺寸、高差和不可见结构按资料拟合，真实北向未校准，并非校方官方产品。保留 v2.1.7 回退、原始资料与失败记录。全下园 Goal 继续，逸夫余项、C–D 标高、灰栏梯端点、032 下层及 301 井深仍待处理。
