## 实际修改

1. 旧版所有楼翼一律约 19.6 高，改成侧翼屋面 12.2、斜翼/后翼/前端主楼屋面 23.3（楼根局部单位）。以已保留的 4.8 首层和 3.7 常规层间距承接旧模型的不同楼板数量；不是旧单位直接换算成实测米制。
2. 高、低屋面分别收口；低侧翼移除通用设备盒，增加石铺通道、低绿化池和碰撞女儿墙。低屋面接第三层院内廊。
3. 后核心增一组折返梯及楼板洞口，最高可达楼板顶 19.725。低侧翼之上的两条长廊撤回后核心小平台，补临空护栏，避免悬空长廊；前两层通往实拍前廊的连接保留。
4. 删除深处旧版“教学与公共服务”玻璃门墙、D 字样及重复门框，保留 V131 实景入口。最终画面中发现四片孤立的院内玻璃示意片，一并移除；这些玻璃原本没有碰撞。

主文件：`TeachingBlocks.gd`、`ZhangCourtCore.gd`、`ZhangLowRoof.gd`、`LandmarkBuildings.gd`。相关旧文件已备份在 `.tools/backups/zhang-tier-before-v133/`；既有其他楼修改保留。数据记录同步楼板/屋面及证据状态。
