# V154 学生中心共同柱点、前侧核心和悬挑支撑

开发版 `2.0.1-dev` / `official-visual-build-154-student-core-supports`；稳定 `v2.0.0` 未覆盖。前一轮 V153 已改变实际模型，归类为 progress。本轮继续全下园 Goal，不把学生中心单栋当作完成范围。

## 实际建造

- 在历史 1F/3F/5F 图上人工选取八个同名柱符号，采用保持形状的二维相似变换；5F 轮廓生成改用该变换，替换之前的独立横纵外框拉伸。3F 变换记录为后续校正依据，院落本轮仍保留 V153 手工对应。
- 按可追踪柱点补七根前部支撑，接地面至上部楼板，避免大悬挑完全浮空。柱截面约 0.73 米、贯通高度和与各层的结构关系仍拟合，不宣称完整结构设计。
- 补前侧历史楼梯核心的五组折返梯，连接模型 G 至六层；各层平台、围护、扶手与入口配套。楼板切开真实梯洞，内部洞通过矩形分片处理，避免将内环误铺成实心地板。两处电梯井及关闭门扇仅作空间边界，电梯不运行。
- 中间楼层靠图纸上侧的凹口开出，并加边缘栏杆；完整房间和实际走廊边界仍需补充。
- 学生中心通用灰砖立面的碰撞代理由墙后 1.15 米移回可见墙体后部 0.45 米，避免虚墙侵入图纸所示楼梯净宽；门窗外观未借此变形。

## 来源及误差

图纸与照片来源：[建筑师提供的学生中心资料](https://www.gooood.cn/en/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm)，发表 2021-05-28、项目期 2012–2019，拍摄/修订时间未知。本地 `architect-029/030/031.jpg` 分别为 1F/3F/5F，`032/033` 为剖面；`010/013` 实景显示悬挑下的柱和折返院落、黄色窗墙及红色面板。它们属于历史结构依据，不代表已确认 2026 年现状。

来源目录：`references/visual_build_20261008/originals/student-rear-20261010/`。20261010 是归档日。东门原点、前廊定位点和地理北向未校准的限制保持。

八柱点拟合 RMS：3F 约 2.09 像素、5F 约 0.72 像素。另取未参与拟合的前侧梯间与电梯符号核对：3F 残差约 0.81/2.13 像素，5F 约 2.74/6.38 像素。按 1F 比例尺，最大约 0.46 米；这说明柱网拟合不能自动证明所有核心完全重合。人工读点约 ±3 像素，原图符号简化也有影响。证据与复现脚本：`student_shared_grid_v154.json`、`tools/register_student_grid_v154.py`。

本轮楼梯使用 1F 核心范围并在各层贯通，宽度、门位、折返平台和楼层高度为拟合，**不能据通行结果宣称每层真实核心已完全复原**。5F 电梯符号差异仍须进一步判断；后侧/另一端核心尚未建全。院落各梯在不同层图中有重叠投影，完整实际起终层与踏步范围仍需继续核对。

## 验证范围

集中运行前核心上下行、七柱中的五个主要前柱脚/柱顶、各层洞口/平台、中层凹口及受影响前廊路线。最终核心上行58条、下行46条，加复用未受修梯影响的前廊7条，共111条有效分批记录、3起点；23项检查、4个最终画面通过，8个初/终画面已查看。未重跑整个下园。具体有效索引、失败原因、复用边界和最后源码哈希记录于 `tests/artifacts/student_core_v154_accepted.json`。原始报告和失败日志保留，不以分批独立起点冒充一次全区走通。

## 接续事项

先核对 5F 前电梯符号差异与前侧核心门位，并把院落梯的分层投影、三层凹口/上层各独立块连接登记清楚；补后侧/另一端核心、真实房间边界和剩余悬挑支撑。图书馆侧连廊拟合门位、共享下首层实际入口及图书馆后路 G/2F 标高继续保留。然后沿 D 至 F/G 继续，所有 A–G 背面、下层、角落及较新材料证据均不结清。

首轮失败分别涉及楼板开口未覆盖折返平台、箱形平台立边和整组倾斜护栏伸入转弯区；最终开洞覆盖平台，平台采用顶面碰撞，梯侧改竖直栏杆，保留扶手斜率。射线起于实体内和从单面板下方发射的错误探针改为从外向内/自上向下；并非删除物理边界换取通过。初/收尾失败日志保留，核心以最终 clearance 报告为准。
