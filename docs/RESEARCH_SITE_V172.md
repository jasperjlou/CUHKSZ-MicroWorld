# V172 科研楼总平面落位与场地连接

2026-10-12，开发线 `2.0.1-dev`。稳定 v2.0.0 保留，完整下园 Goal 继续 active。

本批从整体位置开始修正科研楼，避免在错误落点继续累积门廊装饰。依据建筑师供稿总平面 043、实景 059，以及校方下园鸟瞰场景 `130027046`（全景资源 `92544949`）。建筑师文章发布于 2025-12-24，不能当成拍摄或绘图日期；校方全景拍摄日期未知。来源、原图哈希及图上控制点见 `references/visual_build_20261008/research_site_v172.json`。

总平面可辨认科研双翼与校园主轴约 23° 的夹角，以及科研楼在钟塔后侧、体育馆侧后方的关系。旧模型锚点 `(91,2.24,-845)`、朝向 `-90°` 让整栋楼靠钟塔过近，且两翼与主轴完全平行。本批用钟塔、旧图书馆、体育馆三个图上近似中心及其现有拟合坐标估计科研中心，改至 `(126,2.24,-914)`，朝向 `-113°`。东门原点和其他建筑锚点保持原值。

这不是测绘配准：三个控制点都是已有模型的拟合位置，三点仿射没有独立残差可用，楼体角度按图上相对主轴另行拟合；没有将图纸朝上当成北向。尺寸、楼层高度和原有 0/5.5/11.5 米裙房标高仍有待独立剖面校准。

## 模型与路径

- 整栋科研楼、双翼、曲面遮阳、裙房内部楼梯、采光井、门廊和侧梯使用同一建筑变换，未分散平移局部零件。
- 新 `ResearchSite.gd` 从运行数据读取相同变换，建立贴合门洞的侧后硬铺地、排水条带，并对山坡拟合出裙房和后车道所需的局部场地。地形在外围平滑接回旧山坡，移除落入场地的程序树。场地标高仍是拟合，未称真实等高线复原。
- 后侧车道移到倾斜裙房外缘；钟塔方向的地面步道接侧梯，体育馆方向步道接主入口大梯。原落点的两块大铺装、孤立排水条带和长椅撤去，补有限的林木分隔；新树位置同样只是景观拟合。
- 按鸟瞰及 059 实景把朝校园的连接翼、后高翼端面和高玻璃翼侧面改为浅色石墙上的窄横窗带，保留真实围护碰撞。保留正面的竖向玻璃与另一端未证实的立面。
- 科研楼自动展示章节改用楼内局部坐标，展示双翼、曲面立面、主梯和庭院；跟随当前建筑位置，不再走旧坐标。

原钟塔末端道路的部分弯线仍沿用旧拟合。本批重接科研相关分支，不代表整条钟塔后路已配准。总平面和鸟瞰尚不能确定高架弧形连廊两端的具体门位及标高，没有据此编造一条高架连接。

## 验证记录

初轮暴露新车道斜穿旧植栽坡造成地形陡折；修整连续坡面后，旧园路高出地面的沥青碰撞面仍在接点形成小台阶。增加与旧沥青同高的连续实体路面，并在后车道端缓慢降低，消除第二处接缝。

画面检查还发现后门铺地与地形共面，出现草地穿透；把硬铺地表面抬高 3 厘米，排水条带随之调整。两次失败及相应日志保留，收尾仅复查受影响的道路和门口，不重复走整座校园。保留初轮43段有效通行与最终9段，共52段、3个起点；中间修坡轮的2段重复前缀不计入。12项有效检查、4张最终画面通过，累计查看8张模型画面。最终退出0，无引擎错误；两轮失败退出1均保留。189项导出依赖存在且唯一，差异空白及JSON检查通过。汇总见 `tests/artifacts/research_site_v172_accepted.json`。本批只证明步行衔接，不扩称车辆转弯验收。
