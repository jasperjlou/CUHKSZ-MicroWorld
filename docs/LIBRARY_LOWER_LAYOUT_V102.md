## 旧资源不能直接决定阶梯层位

旧场景名称为“图书馆1楼”，却包含类似宽坐席的阶梯结构。公开2F/3F图明确画出宽坐席的上下关系，因此不凭旧场景名把现有2F–3F坐席移回下层。1F到2F普通公共梯准确位置仍须跨层、全景与几何核对；V44确认的室外入口梯/二层坐席层位关系继续保留。

日期边界：1F文件202401是图纸修订线索，2F/3F的2021-11是资源路径；均不是拍摄日期。旧模型与全景拍摄年代未知，不能称2026竣工图。
