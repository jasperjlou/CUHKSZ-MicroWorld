# V80 志仁外园后车道与钟楼侧步道

版本 `official-visual-build-80-garden-rear-street`，继续现有 Goal，完整 A–G 仍未完成。

## 图像依据

复看官方下园航拍 `130027046`（资源 `92544949`）的六幅已缓存图块，以及 T 形路口 `116443799`（资源 `70040607`）四面。航拍显示花园木平台/石景旁的树带、停放车辆和绕钟楼绿轴的车道；路口全景显示灰赭人行砖、浅路缘、排水边带、过街线和种植边界。这些图支持相邻关系和材质，不能证明当前模型的米制位置或高程。

上述全景拍摄日期未知。复看的摄影者图 54 页面发布于 2026-03-06，前景有 2025 装置，仍不能据此给照片指定拍摄日。保留较新图支持的金色钟楼形态，不根据旧路口图将其改回早期外观。十周年页面含历史施工图，未用于本批当前铺地的直接复原。

## 实际修改

- 新增 `GardenBackStreet.gd`：沿既有后车道布置连续灰赭窄砖人行道、浅色路缘、暗排水边带、白边线、局部篦子、路灯和较密树带。
- 机动车道改为纵向/横向都细分的网格和相同形状碰撞面，避免整幅宽路面跨过弯曲地形；关闭旧通用道路重复绘制。
- 将教学楼台地与车道横断面分开，沿花园处接上较高标高，向钟楼端逐渐降低，山侧服务路沿同一标高剖面接续。所有高度、坡度与过渡长度仍是场景拟合。
- 撤去后缘悬空旧砖条，收回旧大平铺面，补花园两处斜向连接。连接面端部收薄以接现有地面，西侧连接另设连续坡面，避免直接贴在局部陡土坡上。
- 服务道路数据中原 `130,-790` 拐点改到后车道共同接点 `130,-781`，模型和路线引用同一节点。未改变东门原点或宣称完成地理北向配准。

## 集中验证与修正

首批视觉检查发现沿旧坡直接铺的人行道仍呈过陡横坡，返回花园端部也卡住，因此首批不作为最终通过证据。第二批将后车道抬至花园标高并控制沿路下降，撤掉旧悬空砖面，修好东侧四段；西侧连接下行在短坡面末段的高度检查失败，继续修正连接坡面。未把单向能走通当成完成。

最终只续检受影响西侧连接、钟楼弯道、后车道及山侧服务路；保留第二批未受修改影响的东侧四段。报告：`garden_back_street_finish_v80.json`、`garden_back_street_final_v80.json`。四个截图采用最终模型，旧尝试的截图文件已被最终视角替换；失败尝试的 JSON 和引擎日志保留。最终计数：东侧4段 + 西侧/钟楼12段 + 弯道/服务路9段 + 横穿道路往返4段，共29段有效局部记录；不是一次全程运行。4处路面横坡检查通过。四个最终视角已复看，所有运行无脚本/引擎错误。弯道原直线切出车道的失败改为沿道路曲线，同时软化薄沥青面及人行铺面边缘的碰撞突沿；最后4段往返通过。对应末两份报告为 `garden_back_street_road_finish_v80.json`、`garden_back_street_edge_finish_v80.json`。V64及后续依赖旧后路标高的绝对坐标证据由本批替代，未受影响的钟楼台阶和其他街区不重测。

## 未完成与下一批

本批不是测绘复原：花园/车道真实相对高程、两端精确曲率与坡长、停车排布、棕榈和完整树冠、科研楼与钟楼的间距仍待进一步配准。新增西侧斜向路径是当前拟合连接，不声称现场已确认无障碍坡道。下一批继续知新楼两端车道分叉及其与主广场的关系，然后补当前旧图书馆内部资料和志仁黑匣子剧场公共入口。图书馆主入口楼梯下面馆内下层、后车道到逸夫及全部 A–G 缺项保留。
