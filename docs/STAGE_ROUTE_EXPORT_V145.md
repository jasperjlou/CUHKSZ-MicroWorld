## Windows 构建

目录：`builds/stage-v145/Windows/`。EXE 96,725,504 字节、PCK 16,711,072 字节，合计约 108.2 MiB；校验见目录内 `build-manifest.json`。

Godot 4.5.1 官方导出模板已按官方 SHA-512 清单核对，仅解出 Windows x86_64 模板。上游版本页：https://github.com/godotengine/godot-builds/releases/tag/4.5.1-stable 。包内附引擎、引擎依赖和 Noto 字体许可。

按场景自动收集依赖曾漏掉 GDScript 的预载文件，故改为从默认产品场景及 autoload 递归收集明确资源路径，显式导出 168 个依赖；运行验证单独证明它们足够启动当前产品。未将静态路径扫描当作运行证明。清单见 `export_resource_closure_v145.json`，可由 `tools/build_stage_v145.py` 重建。

产品包不含研究原件、测试驱动、旧 GTA 模型或旧场景的参考派生牌匾贴图。当前运行字体及数据文件在独立包内加载成功。源码中的旧研究成果与本地照片均未删除。
