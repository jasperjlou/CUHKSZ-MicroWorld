# 下园西段：体育馆、旧校门与运动场

2026-10-10，配置 v13。使用官方全景的四处参考，保留现有东门原点、建筑锚点和朝向。当前 24 组模型、44 条地面路线、45 处导航点；其中西侧出口仅保留方向点，不代表已经复原门体。

## 已落地的结构

- 体育馆：移除整个实心玻璃盒，改为围护外壳、深入口门廊、密排暗色竖向遮阳、通透门洞和短台阶。场侧屋顶有明确的高峰与低折段，彩色遮阳和屋脊按场侧观看方向核对，避免把入口视角的左右直接套到背面。
- 场侧：增加架空柱列、连续玻璃外廊、两侧上楼台阶、平台栏杆与近场铺地。球门移到足球场实际模型端线，移除先前贴在楼前的装饰球门。
- 接待厅：浅色接待台、墙面标识、条状吊顶及灯、玻璃旁红色座椅和桌子，可从门廊进入。
- 旧校门：两根独立石柱及错层挑臂、低矮校名墙、门岗、隔离柱、斑马线和树篱。删除原先没有照片依据的跨路横梁。
- 运动场：跑道用显式半圆端点与平行直道连接；补中圈、大小禁区、端线、角旗、球网、终点线及道次、场灯和沿边植被。
- 西侧出口：目前参考只支持方向，不支持门体外观，因此移除另一套通用门架，保留路线终点、铺地和照明。
