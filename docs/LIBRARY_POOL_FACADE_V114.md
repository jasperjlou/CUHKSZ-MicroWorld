# V114 图书馆入口侧窗型、穿墙修正与连续天窗

2026-10-11，版本 `official-visual-build-114-library-pool-facade`。整个下园 Goal 继续。

## 实际改动

- 公开四层轮廓的 22–24 边改为三行局部成组短窗，25–29 边改为三行规则竖窄窗；橙色只留在部分短窗组。补窗内水平金属杆、深窗台及沿立面方向的细分板缝，封闭玻璃有碰撞。
- 四楼前侧四组 A–D 书架向内退约 2.5 米并缩短至 3.6 米，解决端板穿出弧形外墙。五楼珍藏室临外墙的两段重复实墙撤掉，避免白墙遮住外窗。其他珍藏室内墙和入口保留。
- 两只独立小天窗改为连接两中庭的连续转折天窗，补双坡玻璃、折线脊梁、横向细框和周边基座。下方两中庭及楼板仍各自独立。
- 屋面先沿高度函数的两条折线切分再三角化，解决不共面的分片插值在屋顶拉出长裂缝。

## 验证边界

结构批次后集中检查。首次画面发现穿墙书架与重复内墙，修正后四楼沿窗通道 7 段单起点连续往返通过，6 个代表性外窗碰撞探针通过。屋顶随后是纯渲染变化，复用未受影响的通道/外窗结果；屋面裂缝修复后仅重看两个屋顶视角。有效日志无引擎错误。

最终接受：水边立面、窗洞近景、屋面整体和天窗近景共 4 个视角。其中前两个拍于最终屋面修复前，证明的是未受影响的立面与室内退让，不是最终屋面。旧默认高机位仍显示另一侧未细修立面，不作本次入口侧对照证据。全部结果在 `tests/artifacts/library_pool_facade_v114_accepted.json`。
