# V258 可选目标的物理 Agent

用户在科研楼侧场地工作开始后要求优先改 Agent。科研区域尚未改模，断点保留到 V259；V257 道远及旧馆后路成果保留。

第二入口和 `--agent-demo` 现在进入目标选择器。可选地图地点及已建公共空间；任务为“到达并观察”或“到达后继续探索附近两处”。支持开始/改换目标、暂停/继续、停止和 Esc 返回。原30章建筑导览保留为该模式内的明确可选功能，不再代表自主探索。

采用本地规则策略，不调用付费模型。目标由用户给定，规划器根据当前校园道路和已有室内通行路径建立 AStar3D 图，使用真实墙体、护栏、完整尺寸胶囊扫掠和地面支撑检查筛除不可通行边。东门门前使用二维铺地区域，能绕行实际铭牌；没有删除铭牌、缩小玩家碰撞体或修改目标位置。室内路径采用当前建筑变换，未复用旧V5世界坐标。

执行只写玩家 `navigation_direction`，通过原 `move_and_slide` 发生移动。任务开始、改目标、暂停、失败均保留角色现场位置；没有章间传送。物理停滞触发有次数上限的重规划，失败明确显示，不改写成功状态。新任务/重试重新检查阻碍，避免临时障碍移除后永久封死连接。

行为接口 `observe()`、`get_available_actions()`、`step(action)` 提供观察、合法动作及执行入口。`navigate_to` 接受后是 pending，不等于到达；实际抵达后记录 ARRIVED，再现场观察才记录 OBSERVED。远处观察、未知目标及当前精修场景未接入的 NPC 互动均拒绝。任务控制的暂停/取消属于用户控制面。日志保存在 `user://agent-runs/latest.json`，包含合法状态、实际位置、动作结果和受阻边；每个新任务替换该 latest 日志。

这不是通用语言模型自主推理或所有校园事件的迁移。当前精修场景没有早期原型中的拍照学生、晚宴签到、可操作公共交通，未广告这些动作。图上候选目标可选择，不代表所有起点到所有终点已经验收；没有路径时明确失败，保留目标以便后续拓扑修整。外立面、全园净空与所有层间组合仍属于完整 A–G Goal。

验证覆盖：东门绕铭牌到广场、改目标到中央广场；暂停/继续/停止/回玩家模式；从东门连续至图书馆主梯下馆内空间；附近三地点探索；非法和远程完成拒绝；不可达目标失败且不传送；动态实心障碍触发重规划、移除后重试成功。目标选择器和暂停中的实际渲染画面已查看。初始类型解析错误、直线撞铭牌/低花池、中央广场知识图缺连接均保留失败记录，修复的是类型及导航知识，不是世界碰撞。
