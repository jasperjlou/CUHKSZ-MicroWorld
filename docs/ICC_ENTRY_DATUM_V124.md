# V124 会议中心入口与下层共用标高

2026-10-11；`official-visual-build-124-icc-shared-entry-datum`。上一批 V123 为实际进展；整下园 Goal 继续 active。

## 已落地

- 将历史图纸外接点 +62.45 与教学 A ±0=62.450 对齐游戏 2.24，得到共同偏移 -60.21。会议中心下层 -1.56、前平台 3.24、门厅 3.44；撤把馆内 5 米高差误作室外入口大梯的旧结构。
- 入口改为约 27.4 米、升高 1 米的桥面，再接 0.2 米短台阶入门厅；补桥底、边梁、柱、护栏及下层独立庭院、挡墙、侧梯、休息厅门槛。桥长参照历史 CAD，宽度和侧梯等按场地拟合。
- 对照会议中心入口反向全景与东门草坪面，入口转向中央步道、与教学 A 相对。根节点由 `[78,2.24,-80]/yaw180` 改为 `[99,-1.56,-102]/yaw270`；水平位移仍属拟合，未称角点测绘配准，东门原点未动，真实北向未校准。
- 一并迁移后侧门廊至校园地面标高，重铺周边石地，开下沉空间和侧梯地形缺口，撤石板下的重叠草地，收整桥脚花坛/石凳/草坪边界；同步导航路线与三个旧定位点，并新增下层休息厅定位。

## 集中验证

初批：门楼侧路到中央步道 1 段通过；沿桥脚侧栏杆直穿的路线失败，未计通过；桥底缺碰撞。修正转入路径、桥底、石地重叠后，桥脚至平台 4 段通过，短台阶暴露楼板伸入梯段而卡住。

收回伸入台阶的门厅楼板、使用有少量净空的梯面碰撞，并将侧梯接到完整顶平台、补下层门槛斜收口。随后从已到达的平台位置续检：门厅往返、桥面下行、侧梯上下、休息厅进出、桥下通道及侧后路共 19 段连续通过，最终退出 0。

保留 1+4+19=24 条有效局部移动记录，共 3 个起点，不是一次全区环游。保留未再改变位置的桥面、庭院、桥底 3 处射线检查；中间侧梯探针在梯段末端调整后退休，以最终上下行记录验证。三次有效日志均无引擎错误，前两次因实测失败退出 1。最终 5 个视角逐张查看；最终验证后未改模型。索引：`tests/artifacts/icc_entry_datum_v124_accepted.json`。

V124 整栋移动后，旧 ICC 绝对坐标通行证据不再代表当前场景；历史资料仍保留，其他建筑未受影响的验证不重复执行。
