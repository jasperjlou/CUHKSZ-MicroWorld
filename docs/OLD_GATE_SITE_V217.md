# V217 旧南门外侧街道与道远楼前场

开发2.1.4-dev / 模型V217。V216有实际模型及验证进展，但其“外围道路沿X=-174穿旧门”的前提需要被新证据纠正。本批保留旧失败和资料，不删除历史。

## 证据与改动

重新查看官方旧校门场景116410028（资源70013462）的四个已存原始面。朝内面显示两独立石柱在车行入口一侧；朝道远楼面显示连续石铺、前场树木和停放自行车；朝外面显示横向城市道路与黄色网格线。结合2026年5月地图、建筑师043总图及旧GTA边界，原X=-174直线沥青将校外街道和楼前硬铺混成一条，并因此穿过岗亭。解决方式是重新区分道路与前场，而不是仅把岗亭移走或绕行。

城市道路局部直段移至围栏外X=-201、Z=-640至-850，拟合宽14米；其余端部渐接保留路线，端部并未实景配准。原X=-174局部沥青改石铺前场。旧门入口沿Z=-790接到钟楼方向车道；主路表面有对应实体支撑，门内6米过渡将低入口接至旧路18厘米铺面，避免长路饰面悬在玩家脚下。

双柱岛缩到入口侧，移除横穿入口的旧草地矩形；斑马线限于入口宽度，隔离墩改为矮圆柱，保留两侧间隔。内外两条步道在入口切开并用浅坡衔接。补朝外全景可见的黄色网格、公共步道和排水收边；补齐道远楼前两块既有硬铺之间的3.4米空缝，不覆盖红绿种植坡。

全景拍摄日未知：十周年横幅仅为线索，不直接认定2024拍摄。地图为2026年5月版；建筑师文章2025-12-24发布不等于图纸日期；旧GTA年代/单位仍未知。门柱高、街道宽、转弯半径、场地坐标、材质和植栽为拟合，真实北向未校准。

## 集中验证

1起点28段连续实际行人通行通过，覆盖外侧街道、入门、钟楼方向车道往返、内外步道过门、道远楼前通路及支路回接。无途中传送。初批4图、最终3图已查看；三次引擎运行退出0，无脚本/引擎错误。

初批画面仍露出入口浅坡侧边、道远楼前场接缝与对侧路缘间的默认草地，已用非碰撞薄铺面补齐，最终图确认；碰撞未变，复用28段通行。它证明这些人行线路可走，不等于车辆转弯半径、无障碍或真实测绘验收。

V216旧门岗亭占城市车道的局部问题已由道路重配准取代；岗亭仍在拟合前场，不再占外侧车道。V216原12+5行人证据按未改变范围保留，但涉及门口断面与车道的旧结果以本批28段为准。
