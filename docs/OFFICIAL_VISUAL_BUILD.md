# 官方全景建造：东门至下园主轴

后续同日扩展已铺到主广场、科研楼、体育馆和田径场，并细化铺地及教学楼。当前范围和阶段结果见 [下园扩展记录](LOWER_CAMPUS_EXPANSION.md)；以下 9 组建筑、14 条路线为最初东段建造记录。

2026-10-08 本机建造更新，入口是模式菜单第一项“官方全景建造 · 东门起点”，或 `启动入口/启动官方全景建造.cmd`。场景在 `world/visual_campus/VisualCampus.tscn`，可编辑布局在 `systems/data/campus_visual_build.json`。

## 原点、方位与依据

原点取官方全景 **East Gate / scene 116410030 / pano 70013461** 的入校门槛中心。站在门外面向校园，右侧为 +X、入校方向为 -Z、向上为 +Y，门外地坪为 Y=0。小地图上方表示“向校园内部”，不是正北。

官方五月版校园地图是斜视示意图，没有北向箭头；全景热点角度是展示和跳转参数，互相连接的场景角度不能一致闭合。因而本版没有把热点角度、页面初始视角或屏幕上方当成真实罗盘。地理北向和绝对 GPS 尚未标定。米制尺寸、道路宽度、高差及相互偏移是视觉估计。

连续关系已按门外 / 门内 / 草坪 / 主轴及官方地图核对：入校左侧是教学区域，右侧是会议、行政、图书馆区域；学生中心在图书馆之后。不能把全景“可跳转”直接当成可以直线步行的边。

参考索引及图片用途见 [参考记录](../references/visual_build_20261008/README.md)。

## 已建范围

这是下园一段连续的可游玩建造场景：9 组建筑、14 条路线、10 个定位地点。包含东门两侧楼体与连廊、门内石材广场、14 级台阶与草坪台地、中央步道、教学 A/B/C 组团、会议方向廊体、行政楼、大学图书馆及学生中心。地形和楼体有实际碰撞；人物没有步行传送补救。

道路有连续铺地、路缘、排水沟、车道黄虚线、局部回纹铺地；步道旁加树、路灯、座椅和花箱。图书馆前水池与神仙湖是两个不同地点，不互相替代。

教学楼根据用户纠正重做：删除统一 U 形体块，改为围绕开放内院交错的楼翼；外侧窄竖窗采用分段石墙形成洞口，玻璃后退，院内是玻璃、连续水平层带及密集遮阳格栅。底层有真实柱廊和穿行空间，不将底层处理成普通一层窗。A/B/C 的后翼高度、侧翼组合及窗距有差别；尚未逐栋完整可见的部分仍标为估计。学校一期教学楼的航拍用于 A/B/C 形体判断；二期教学院落、礼堂和会议组团的照片不能直接替代 A/B/C。

行政楼保留低翼与高架玻璃横梁形成的巨大门洞。图书馆改为凹弧形上部立面、三排上层窗、约 150 根下部金色竖向构件，以及二层入口楼梯和平台；学生中心根据 Lotus Pavilion 二层全景使用黄褐砖面、红褐围护、开放露台与栏杆。

## 楼层处理

| 部分 | 模型处理 | 可信边界 |
|---|---|---|
| 教学楼 | 架空层约 4.8 m，上部约 3.7 m；楼翼采用 4–6 层组合 | 相互交错及外观类型有照片依据，具体层数和高度仍是视觉估计 |
| 行政楼 | 低翼、架空高杆与上部两层玻璃体量分开建模 | 门洞与体量有全景依据，层高估计 |
| 大学图书馆 | G / 2F–5F 的命名场景与三排上部窗带，入口 2F | 命名楼层有导览依据；外部标高、层高估计 |
| 学生中心 | 已见 1F/2F 命名，按可见庭院和露台构型建模 | 更高楼层、完整边界尚未逐一核对 |
| 东门及会议方向 | 高楼体、连廊和低廊分开 | 外观与关系有依据，完整层数估计 |

楼层数据逐栋保存在 JSON 的 `floor_levels`、`component_storeys`、`count_confidence` 与 `scenes` 中，不宣称测绘精度。

## 操作与验证

WASD 相对镜头移动，Shift 跑步，基础移速 2.5 倍；右键转镜头，滚轮缩放；左上小地图点选目的地，仅显示直线距离；F1 显示坐标与建模依据，F2 俯视，R 回到东门起点，Esc 回到模式菜单。

本轮只做阶段渲染和相关物理通行检查。脚本 `tests/VisualCampusCapture.gd` 输出 8 个视角及 `tests/artifacts/visual_campus_milestone.json`。物理路线用同一个 CharacterBody3D 从普通出生点开始，经过门槛、广场、台阶、主轴、水池桥、图书馆二层楼梯，然后返回教学内院；路线中没有重新设置位置。报告记录端点高度、距离与失败项。F1、镜头拖动和倍率也在同一阶段检查。

原全校园 V6、Agent 语义位置及 RC1 保留在已有入口。本场景复用人物控制器，但没有宣称接入原 V6 的 Agent 语义导航与室内交互系统；模型不是全校 294 个全景的完整重建。修改尚未推送 GitHub。

本轮最终收据：8 个建筑/道路视角及 1 个游戏 HUD 截图已生成；13 段连续物理路线、F1、右键镜头与移速倍率检查通过。旧 V6 的低成本静态审计 223 项通过；未重跑全套 V6/RC1 测试，也未进行真人完整试玩。建筑生成约 199 ms 是本机一次启动记录，不是帧率承诺。
