# V187 图书馆廊下圆柱与灰石铺地

2026-10-12。开发源码 `2.1.1-dev` / `official-visual-build-187-library-arcade-finish`。本批在 v2.1.0 体验与正式封装完成后继续；稳定 Windows 包和两个入口保持 v2.1.0。整个 Goal active。

## 本批模型

- 图书馆曲面廊下五根方柱改为浅色圆柱，保留已有轴点与高度；直径 0.68m 按照片比例拟合。
- 曲面通高竖向构件改为暖砂金色，保留既有间距和体量。
- 将旧入口外铺地、廊下条带及侧端返回合成一个灰石铺地面。共享同一个平面掩模，裁掉局部和世界坐标两套旧铺地覆盖，消除重复表面；G 层物理标高未抬高。
- 新灰石材质用拟合的 0.8×0.4m 模块、细接缝与低反光颗粒，远处过滤细节；没有改全校园材质。

## 参照和边界

2026-09-17 校方报道 article/1404 的 DSC02471、DSC02494，EXIF 为 2026-09-07，支持浅色圆柱、暖色竖向构件及灰栏梯。相机时钟未独立校准。复看 2024-09-14 报道 article/1069 的 1069-3/4/6：长条灰石及对向建筑可作通道语境，不能把所有活动照片当作同一机位。历史 library-018 与 G 全景 scene 41566368 / pano 25181873 明确存在沿曲面上升的带栏外廊，但拍摄日期与真实标高未核准。

灰栏梯不能仅凭一张近景直接认成 G–2F 楼梯。其两端、外廊高差、主入口下层与学生中心共同标高仍待配准，本批没有新增猜测楼梯。后路“两排实景/三排模型”冲突继续保留。

## 集中验证

24 段连续实走、一个起点完成池端—侧廊—G 门厅—返回。首轮总体失败：视觉布尔裁剪的退化碎片导致凸分解报错，另外 Godot 自动节点命名使五柱计数只找到一根；原始报告和日志保留。修正为原生多边形裁剪、共享掩模及显式唯一柱名；这些修正不改变碰撞形状/位置。

修复后只补生成与渲染检查：7 项通过、0 引擎错误，统一铺地一个多边形、内部重叠面积为 0，3 个固定视角已查看。复用首轮已经通过的 24 段物理结果，未重跑全校园或发布包。此验收不代表楼梯或全 C–D 完成。
