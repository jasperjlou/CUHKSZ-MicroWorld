# 主广场周边旧楼：立面与公共入口

2026-10-10，配置 v17。诚道楼、乐天楼、知仁楼、知新楼及道远楼延续已有锚点。本批没有调整朝向、地形原点或楼层高度。

## 实景依据与纠正

[官方乐天楼全景 116846253](https://campusvr-en.cuhk.edu.cn/?scene_id=116846253)中，入口一侧是灰色窗间墙、独立窄窗、青色玻璃与玻璃雨棚；全景另一面能看见带设备栏架的相邻立面。原模型把设备栏架直接复制到乐天楼入口上方，本批移除这项混用。

[官方知仁楼全景 116846254](https://campusvr-en.cuhk.edu.cn/?scene_id=116846254)明确显示成对竖窗、浅金属栏架和架空底层。本批把单窗改成成对窄窗，栏架改为空心侧框、水平细条和小设备箱，最低一排窗不挂栏架。

[官方主广场全景 116440774](https://campusvr-en.cuhk.edu.cn/?scene_id=116440774)显示知新楼长翼的连续横向窗带、临广场白色端墙及楼名、首层青色玻璃和旗杆前场。原先转角长侧面仍为普通窄窗、端墙又开满窄窗，本批分别改为窗带和白色实体端墙，补齐底层转角玻璃与端部玻璃。

[校方十周年启动区照片](https://10.cuhk.edu.cn/en/start-zone)用于核对旧楼白色涂装、灰色窗间墙和整体建筑类型。页面部分照片为施工期，未把脚手架或临时围挡加进现状模型；组合照片也没有被用来强行判断某栋未明确的总层数。

所有原图复用 `references/visual_build_20261008/originals/landmark-instances/` 下的 `le-tian/`、`zhi-ren/`、`main-square/`、`start-zone-photos/`。没有重新下载已经保存的参考。

## 已落地

- 五栋旧楼使用独立的涂料／灰色窗间墙立面，不再沿用普通砌块纹理；独立窗框、腰横档和薄窗台明确区分于其他校园建筑。
- 乐天楼保留长条加短翼的现有体量，补统一玻璃雨棚、可进入的后退门厅、前沿石材铺装和开花盆栽。
- 知仁楼补成对窗与空心设备栏架、架空层梁、灯具、玻璃入口和后退公共门厅。
- 知新楼长侧面沿正确楼翼轴线使用窗带；近广场端墙留白安置楼名，底层玻璃封合到转角；入口与侧翼门保持通行。
- 知新楼前场旗杆由过宽散布改为三杆一组，实体基座放在步行轴线旁；补花盆与铺装。旗面为素色示意，不声称复制官方旗帜。
- 近景仍可见砖缝，远景按像素覆盖率淡化过密灰缝，减少红砖铺装的细纹干扰。

`StartZoneFacades.gd` 负责三种立面；`StartZonePublic.gd` 负责入口、铺装和有限的公共室内，均由 `StartZoneBuildings.gd` 调用。`CampusSurface.gdshader` 新增涂料材质并处理远景灰缝。一次性迁移脚本 `tools/refine_start_zone_public.py` 有重复执行保护。

## 验证与边界

主体完成后一次运行 `StartZonePublicCapture.gd`，**15/15 段实体移动通过**：乐天楼与知仁楼门厅往返、知新楼前场绕旗台、主入口和转角侧翼出入。三组起点内无中途传送。保留 8 个视角，构建 763 ms。

实机与照片对照后，进一步修正知新楼端墙和首层端部玻璃，并调整远景材质，补做 6 视角渲染，构建 762 ms。最后两处近景暴露出楼名字面与墙面重叠、侧翼室内能直接看到背面草地，已抬出字面、补外侧墙和少量阅览家具，再只渲染这两处，构建 759 ms，最新日志无脚本或渲染错误。新增封合位于侧翼最外端面和外侧边界，家具位于内侧门走道之外，已通过路线不经过这些位置；没有重复跑无关路线。

当前仍为 24 组建筑、44 条路线、52 个导航点。完整室内布局、楼翼长度和各层米制高度仍是估计。不得把门厅布置当作校方真实功能分区，也不得用本批通行结果宣称整个下园重新验收。
