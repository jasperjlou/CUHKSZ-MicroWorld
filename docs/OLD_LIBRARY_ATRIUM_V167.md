# V167 旧馆中央弧形楼梯与采光中庭

开发模型 `official-visual-build-167-old-library-atrium`，2026-10-12。正式 v2.0.0/V145 保留。

## 年代与身份

[校方2025-09-17空间优化公告](https://library.cuhk.edu.cn/zh-hans/event/1235)同时展示两馆地面维护：image24 属大学图书馆，image25 可由旧馆圆弧楼梯、木色书格和悬挂投影幕对应识别。旧馆这张较新照片的地毯为灰底黄绿色细纹，替代早期全景的灰绿条纹方块纹样。发布日期不是精确拍摄日，2026暑期翻新后的全部现状仍未得到照片验证。

读取旧馆地面全景41566352/pano25181857向上四块图像，确认楼梯的叠层弧端、多层通高井和实际格栅采光顶；再读取3F全景41830776/pano25322346的预览、前方及顶面，看到裸露梁、长吊灯、白柱和远处中央梯。两套全景拍摄年份未知。新三层25块切片和2025两图保存于 `references/visual_build_20261008/originals/old-library-upper-20261012/`，带URL和SHA-256。场景研究图只留本地。

## 实际改变

- 低横楼4.6、8.3、12m楼板以及15.7m屋面切出贯通中庭，保留原有三座端部核心洞口。
- 中央添加三组两跑楼梯，转折平台为真实半圆环；台阶、薄斜底、白色实心栏板和木色扶手连续连接，地面至四层可通行。
- 补跨井平台和各层环廊边栏板，保留平台入口；通高圆柱框出采光井。旧的直接横穿中庭上层路线失效，改沿环廊或跨井平台。
- 屋顶原实心凸盖改周边矮墙及半透明格栅采光顶，屋面饰层同步开洞；不再用一块实板挡住井顶。
- 地面改用较新照片支持的灰底细黄绿纹地毯，弧端下方补木色书格。V166画面发现的地面外墙顶缝同步封口。

中庭32×7m、中央梯尺寸和实际落位仍按现有36×7.8m屋顶罩及0/4.6/8.3/12m层高拟合。全景支持空间类型和连接关系，不能证明这些米制尺寸，也未解决旧馆全部楼翼的测绘配准和层名关系。没有整体移动建筑或指定地理北向。

## 验证

测试脚本 `tests/OldLibraryAtriumV167.gd` 集中检查地面入口、三层上行及通廊、四层绕井、三层下行、返回入口，并探测四层板/屋面洞口、平台及栏板。结果和最终截图审阅见 `tests/artifacts/old_library_atrium_v167_accepted.json`。107段连续往返、1起点、14结构检查全部通过，无引擎错误。首轮弧端镜头仰角过高未包含地毯和书格，收尾补两机位并封非碰撞墙顶饰面；6张已查看，5张有效终图。物理几何未改变，未重复步行。184个导出依赖唯一且存在，正式包不重新导出。

旧馆三层可见的裸梁吊灯、上层学习区细部、完整楼翼尺度和2026改造现状未完成；中庭与屋顶的米制位置仍需独立平面配准。V166上层直穿低横楼的旧路线已退休，端部三梯自身构造未改，可按其原范围复用证据。继续F/G侧后和下层角落、图书馆后路G2F、学生032局部下层定位及完整A–G。
