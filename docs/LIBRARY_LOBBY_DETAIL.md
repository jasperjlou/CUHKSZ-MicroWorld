# 大学图书馆 G / 二层入口细化 · v22

2026-10-10。依据官方 G 层场景 [41566368](https://campusvr-en.cuhk.edu.cn/?scene_id=41566368) 与二层入口场景 [41830774](https://campusvr-en.cuhk.edu.cn/?scene_id=41830774)，继续修正底层空间的通用占位构造。

G 层改为白框透明玻璃分隔的共享门厅，保留侧向通道，增加暖色网格顶棚与方形灯、低反光地毯、压制木片墙、接待台、圆桌及蓝橙椅。`LibraryLobbyDetail.gd` 独立管理这批细节，材质增加木片和地毯两类。家具数量、平面及门宽为模型拟合，未声称按完整室内施工图复原。

二层入口原来把宽座席区误做成了普通密踏步，现改为八排深踏步座席，侧边配置花盆，旁边正常步行楼梯保留。增加白色斜侧板、密集浅色吊顶片和条灯，吊顶为既有三层楼梯保留洞口。八排、0.55 m 升高和 1.5 m 深度均为当前模型的估计尺寸；座席区不作为连续步行坡道。

同时修正 `VisualCampusBuilder.stairs()` 将带方向的 run 直接用于 BoxMesh 尺寸的问题：位置仍按原来的方向计算，踏步深度改取绝对值，避免反向楼梯表面透空、重叠。物理斜坡保持原值。

集中验收：初次 5 个渲染视角、9 段相关通行通过；其后一段失败是检查路线试图从梯段中间横穿到三层梯脚。改为绕行旁边走廊到梯脚后，剩余 7 段路线全部通过，涵盖三层上下楼、二层返回及正常楼梯下降。原失败报告保留，没有重复运行已通过的 G 层和座席路线。最终楼梯渲染确认透空问题消失，场景构建 961 ms。
