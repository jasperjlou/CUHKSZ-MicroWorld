# V144 逸夫西座公共层窗墙与展示

2026-10-12；`official-visual-build-144-shaw-public-glazing`，产品 `2.0.0-rc1` 仍未正式发布。

## 本轮模型

西座中楼翼和前楼翼的二、三层补连续玻璃窗、灰色窗裙、窄金属窗框、黄色竖向分隔，三层靠山大厅按平面窗段改为真实透光窗墙。玻璃本身有碰撞；开门位置留通行空间，未将玻璃贴在原实墙上。中翼两层增外墙与后侧公共入口，内部暂不填入未经定位的房间家具。

清除被新窗墙包住的重复平台护栏，保留楼梯出口与室外井边栏杆。小地图直接读取 `ShawWestPlan` 的裙楼、三楼翼和两井轮廓及实时变换，替换旧粗矩形；它仍是示意地图，其他楼栋轮廓精度未同时提升。

Agent 展示新增“逸夫西座 · 折返梯与山桥”，当前共 **15 章**。本章从入口雨棚出发，沿折返梯至三层，进入中翼公共壳体与靠山厅，再经屋顶梯到山桥。片头看立面与折返关系，收尾从桥上回看楼群；使用现有物理角色，不用恢复瞬移。

## 实景依据与限制

本轮重新取到并查看[建筑师授权资料](https://www.archiposition.com/items/20190905014221)中的西座立面、鸟瞰及近景三图，文件在 `references/visual_build_20261008/originals/shaw-public-v144/`。文章发布 **2019-09-10**，拍摄日期未知。照片显示公共层玻璃与黄色竖向构件，也提供屋顶设备阵列线索；后者尚未据此建造。

交叉查看官方全景 `116440787` / 资源 `70037192`：中楼翼公共层仍可辨识连续窗列与竖向分隔、前翼端部灰墙和入口雨棚。全景拍摄日期未知，不把资源路径的 2024 当拍摄年。当前新版指南可提供房间名字，但尚不足以逐间确定装修与楼翼对应。

大厅窗段位置依据已读三层平面；窗框间距、窗裙高度、黄色构件密度与米制比例为拟合。中翼历史平面有内部分隔，本轮仅补外围，不能把整间空壳当作完整房间复原。屋顶圆形构件、公共层现状家具、塔楼核心、完整立面及精确场地比例继续待核；地理北向未校准，东门原点不变。

## 集中检查
