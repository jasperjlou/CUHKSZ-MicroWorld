# 2026-10-08 人类探索体验更新

本机工作区的 V6 体验改动；尚未提交或推送到 GitHub。

## 操作

- WASD：相对于镜头方向行走。基础步速从 5.1 提高至 12.75 游戏单位/秒（2.5 倍）。
- Shift：快走，20.75 游戏单位/秒；看手机时仍会减速。
- 按住鼠标右键拖动：水平和垂直转动镜头；松开停止。滚轮缩放。
- F1：切换名称与置信信息；也可点击「名称与置信 [F1]」。按键在 GUI 消费输入之前处理，支持 physical_keycode，不因长按重复切换。
- F2：切换俯视/地面；Tab 手机，E 与附近人物交谈，Esc 返回开始菜单。

## 探索玩法

左上小地图显示道路、建筑、湖区、当前位置和镜头朝向。点击建筑即可设置目的地，地图连线与右下卡片显示方向和直线距离；不是自动寻路线路，也不触发传送。地图北向沿用现有模型的近似坐标方向。

可点击「开始校园漫游」，依次访问道扬书院大厅、湖畔亭、图书馆阅览区、教学楼 A 教室 101。实际身体进入目标附近后推进进度；可暂停并继续，也可自由设置地图目标。完成四站后显示完成提示。该路线是自由探索引导，不属于 RC1 研究任务或新增模型基准。

室内显示当前场所与公共楼层提示，原人物对话和手机互动继续使用。手机或对话打开时隐藏探索卡片，避免遮挡。HUD 与 F1 信息使用背景面板，小窗口手机靠右布局。

## 实现边界

`CampusPlayer.gd` 继承原 `Player.gd`，继续调用原物理控制器、碰撞与移动逻辑；镜头变换仅针对 V6 人类模式启用。原控制器增加默认值为 1 的人类速度倍率，Agent 不应用该倍率，RC1 仍使用原场景与原速度。静态审计明确检查这三行授权扩展，而不是放开整个角色目录检查。冻结的校园几何、室内资源、导航坐标与碰撞未改。
