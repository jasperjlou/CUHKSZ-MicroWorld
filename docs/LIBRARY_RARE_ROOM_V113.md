# V113 珍藏阅览室、五层斜桥与六层左前通高边界

2026-10-11，`official-visual-build-113-library-rare-room`。全下园 Goal 保持 active。

## 实际模型变化

- 珍藏阅览室由后退的矩形房间改为沿前缘转折的九点轮廓。采用 V112 独立五层到四层变换，保留小斜边作为双门入口，补墙、门框、门楣、顶面和室内地面。现有两张示意阅览桌按新房间重新放置；内部家具和材质没有当前实拍支持，不宣称精确内装。
- 五层新建两处中庭之间的独立斜桥与珍藏室前平台，撤掉错误套用四层边界的两段护栏；桥、平台和基础楼板做差集，避免重复铺面。原来五层仅复用四层洞口的做法会让护栏横穿斜桥，已由实际图面关系纠正。
- 跨层木书墙在五层入口开洞，保留下部书墙和门上部格架，避免整面实体挡住珍藏室门口。左侧公共梯五至六层下端提前结束，将房门与转向平台留在楼梯外；具体平台深度、踏步数和米制尺寸仍是可行走的局部拟合，不是地图可以证明的测量值。
- 五层左前方白色通高区域切开并加内侧护栏；六层左前方按其自身平面图裁出连续白色通高空间，撤掉错误延用四层左边界产生的多余楼板，调整边缘护栏并在核心墙体处断开。六层房间组团位置本批未变。

代码入口：`LibraryRareReading.gd`，以及 `LibraryUpperRegisteredPlan.gd`、`LibraryRegisteredUpper.gd`、`LibraryCurvedCirculation.gd`。

## 依据与年代

[校方馆内地图](https://library.cuhk.edu.cn/zh-hans/floor-maps)本地五层文件标注 202401，六层源目录 2025-08。它们支持房间名称、入口、桥和通高空间关系，但不是结构施工图；图片托管年月和文件名标记不视为照片拍摄年份。变换及误差沿用 `references/visual_build_20261008/library_upper_registration_v112.json`：五层 RMS 2.92 归一图像像素，六层稳定候选 RMS 10.08，六层尚有角点身份和局部轮廓误差。

校方[珍藏区启用报道](https://library.cuhk.edu.cn/article/571)记载启用活动在 2021-10-10、地点为大学图书馆五层；本轮仅用该文本核实房间身份，没有取得新的珍藏室内景，不将 2021 年活动陈列复刻为现状，也不误用香港沙田校区的特藏阅览室资料。

白色区域按地图周围边线、逐层缩减关系与此前建筑剖面解释为通高区；这是跨资料推断，仍需对应现场剖面核实。具体手工轮廓以代码及 V113 evidence JSON 记录，未声称真实北向或施工精度。

## 检查与修复

本批先改房间、斜桥、平台、六层楼板及护栏，再集中跑局部连接。首个直行目标误穿既有曲线梯连接桥护栏，改从桥端进入中间走道。随后实际发现五层斜桥遗漏及错用四层护栏，补桥并重定边界；平台与房门间过窄，缩短最后一级公共梯的下端，保留转向空间。

最终梯段仍被平台前沿卡住，碰撞诊断指向梯面与平台盒子重叠。原端点用三维斜向量归一，导致水平退距不足；本层改用水平退距 1.075，使斜面在平台边缘达到同一标高。其他已通过的楼层梯段没有顺带改动。

有效通行和探针索引、源文件哈希见 `tests/artifacts/library_rare_v113_accepted.json`。分批记录，不代表单次完整校园漫游；失败目标不计入验收。模型收口后不重测未受影响的远端核心、其他下园道路。

最终保留 14 条未受梯端修正影响的房门/室内记录，续查 23 条上六层并经核心回五层的路线，补查 10 条四层来向至最终梯脚的连接，共 47 条有效记录、3 个起点，其中部分路段重叠。5 个楼板/洞口探针通过；5 张最终图已查看，有效日志无引擎错误。俯视可见下层楼板，不能单靠颜色判断六层是否开洞；探针同时确认了开口。画面还显示左核心末端有一部分伸入珍藏室共墙处，保留为后续配准缺项，没有把空房间和通行通过当成室内精修完成。最后验证后未改模型。
