# V224：二层Lotus Pavilion装修与分层门口

开发 `2.1.5-dev`，模型 `official-visual-build-224-student-lotus-dining`。固定正式v2.1.4不变。

## 来源和改动

依据官方[二层餐厅室内](https://campusvr-en.cuhk.edu.cn/?scene_id=126106530)与[二层院落外侧](https://campusvr-en.cuhk.edu.cn/?scene_id=116440790)。原图已于V223缓存，拍摄日期未知，不能用检索日期当实景年代。本轮重新查看室内三个侧面，复用上轮已看的全部四面及外侧关系。历史029仅作原柱网延续线索，不是独立二层平面。

补独立二层装修：8张浅木桌、36把黄绿椅、双面黄色长卡座、3组服务窗、4根延续柱、20条向顶棚展开的黄肋片、75条顶棚格栅和暖灰方砖；避开当前院落梯投影及两侧门口。布置、柱网延续和标高仍拟合，厨房范围未完成配准。

初批验证发现u710二层后侧门306被旧楼梯开口逻辑吞掉：三层至四层梯口的横向跳过规则从4.4一直作用到12.4。现将4.4–8.8完整门窗与8.8–12.4上部梯口分开，恢复二层可通门，同时保留上部楼梯开口。不能将先前错误门口算成已验证。

收尾将二层院落窗改为透明玻璃，并在一、二层灰砖外墙的内侧窗间与上下边添加白色涂层；保留外侧灰砖及碰撞边界。取消卡座边重复摆椅，花槽改叶簇，柱饰顶端接合顶棚。视觉仍简化，尚非完整实景精修。
