# 旧楼区道路与前场细化 · v18

2026-10-10。当前 Goal 继续 active。本批将已细化的五栋旧楼接入连续街道空间，保留所有建筑锚点、层高、东门原点和局部坐标轴。场地尺寸与未确认的道路走线仍为建模估计。

参考沿用官方主广场（116440774）、乐天楼（116846253）、知仁楼（116846254）、道远楼（116440775）全景原图：暖色步道、沥青车道、红砖楼间前场、白色路缘、弯臂路灯、低石墙与成熟树荫。原图位于 `references/visual_build_20261008/originals/landmark-instances/`；未重新绘制或修改参考图。

实际改动：

- 主路约 260 m 两侧增加连续暖色步道、分段路缘、过街开口、触觉铺装、排水口、弯臂路灯和树池。既有树列保留，移除重复的旧路灯。
- 诚道、乐天、知仁、知新、道远五处入口新增显式连接路线；前场红砖与入口石材衔接。主广场用步道框住两片草坪，增加低种植边界与座椅落脚铺装。
- 旧 `west_crossroad` 在 z=-805 从 x=-174 通到 x=0，穿过道远楼；其西段改到 z=-839，原东段单独保留为 `east_crossroad`。这是消除模型穿楼的估计连接，不是对现实道路坐标的测绘确认。
- 补通旧校门与横向街道之间的步道。独立处理道路面层和标线，修复灰色步行砖盖住过街沥青的问题。

入口和道路沿用原物理地面；新增路缘、低种植边界属于可跨越的视觉细节，没有额外阻挡玩家的隐藏碰撞。阳光、建筑层数与其他已核对空间保持原实现。

实现入口：`world/visual_campus/StartZoneLandscape.gd`，由 `LowerCampusLandscape.gd` 调用；`tools/refine_start_zone_streets.py` 是已执行的一次性 v17 → v18 数据迁移，拒绝在更新版本上重跑。

验证集中进行：

- `StartZoneStreetCapture.gd`：7 个视角，3 组起始位置，15/15 段实体移动通过。包括诚道过街到乐天门口、主广场至知新/知仁、道远入口及绕楼道路到旧校门。无组内传送，构建 779 ms。
- 路口面层与座椅铺装修正后，仅追加 3 个渲染视角；无脚本或渲染错误，构建 891 ms。该时间是场景构建时间，不是帧率或性能提升结论。
- 原始通行报告：`tests/artifacts/start_zone_street_milestone.json`；引擎日志 `start-zone-street-engine.log` / `start-zone-street-finish-engine.log`。截图以 `start-street-` 开头。
