# V118 图书馆池岸与入口侧景观

## 实际变化

以十周年照片中水面贴竖格栅、沿入口石路延伸，以及另一侧草地/细石条的关系为依据，重画反射池内侧轮廓，接上V115立面和V117入口缓坡。池底、池壁、水面和地形切口共用轮廓，撤掉旧矩形接头、跨水桥与木盆列。

馆前底板、旧门厅前场、十周年铺装和装饰边条一起裁切，清掉浮在池面上的残片。原过池路线改走池端，`library_entry`导航点迁至已走通的干地。入口另一侧新增带横向高差的草地、细石条、三棵代表性树及2.1宽外侧步道；步道收边避开既有展厅玻璃端角，未改玻璃位置或角色碰撞。

116封闭书库墙体加厚，梯下底面改为有厚度的封闭板；碰撞与外梯净空探针通过，最终画面仍有小三角亮斑，因此不能称视觉封闭问题已解决。

## 验证范围

- 保留16段池端绕行与主入口上下楼、6段G层门槛往返、最终7段外侧步道，共29条有效移动，来自3个独立起点，不是一次全馆巡游。
- 5处池底探针确认水面下没有旧地形或桥面碰撞；最终2处底面/外梯净空探针通过。
- 最终总览、草地、底面3图已看。漂浮铺装与细边已清除，细石条可见；116亮斑仍留项。有效日志无引擎错误。
- 中间外侧步道撞玻璃角的失败记录保留；新池岸覆盖了原长G侧路，因此该旧路线13段全部退休。本批只证明G门槛附近可达，**未证明G入口至校园外路的完整连续连接**。
- 外步道完成后只细分草地、裁视觉边条、加厚116顶板并补查净空，未重复全区测试。逐条索引、退役记录及最终模型哈希见 `tests/artifacts/library_shore_v118_accepted.json`。
