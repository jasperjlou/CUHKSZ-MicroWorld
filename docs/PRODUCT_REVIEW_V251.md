## 玩家与 Agent

玩家第一/第三人称覆盖沿街门洞、核心筒内侧、前场台阶、侧门及上层楼梯护栏。最初两种模式都在 street-front 第5段撞到既有柱子；将编排/测试路线从局部 x=-21 移到柱间通道 x=-22，仅重测失败路线。没有修改实体碰撞或镜头算法，不能解释为任意玩家路径均无阻挡。

保留初跑侧门与上层 26 段、1,678 次镜头采样，加上重测沿街路线 22 段、1,566 次采样，最终接受 **48 段移动、6 处原地转向、3,244 次镜头采样**。接受范围内球形重叠和身体至镜头遮挡均为 0。初跑失败及其已走部分不计入最终沿街路线成绩，原报告保留。

Agent 的 shaw-podium 章节更新为石碑/铺地开场 → 沿街黄门洞 → 折返梯 → 公共平台。实际连续走完 16 段，1,704 次镜头采样无实体重叠，角色隐藏和退出恢复操作通过。其他 29 章复用 V246 汇总的 332 段，合计 348 有效段，**不是本轮完整30章重放**。
