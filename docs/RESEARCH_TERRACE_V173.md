# V173 科研楼玻璃底层、架空转角与上部台地

2026-10-12，开发线 `2.0.1-dev`。上轮 V172 为实际模型进展，本批继续 G 区。稳定版 v2.0.0 保持原构建，完整下园 Goal active。

## 证据和边界

复看校方“Research Complex Backdoor”场景 `116443791` 的四向图：金色遮阳下方是玻璃底层，弧形上部墙面越过玻璃线，下面有白色圆柱；步行道旁是石材树池、低灌木及硬质铺地。十周年专题的 `keyanlou.jpg` 从另一侧显示金色遮阳立面前有树池步行台地，下方还有裙房及道路。现模型把弧形底层玻璃封到外沿，台地过窄且基本空白。

十周年照片路径中的 `2023-11` 只代表上传目录，不能作为拍摄日。校方全景拍摄日未知。2025-12-24 建筑师供稿图 010、046、047、049 用于交叉核对形态和上下关系，绘图及拍摄日期同样未知。[建筑师项目官网](https://wwjarch.com/The-Chinese-University-of-Hong-Kong-Shenzhen-Phase-ll) 标注项目年 2024，本批已重读，不据此推断每张照片都摄于2024年。

另从已保存供稿页面的媒体数据取得全尺寸图045、048并查看：045是会议中心组团轴测，048是科研楼通风/遮阳分析。两张均不是科研裙房平面或钟塔桥端点资料，未据此改动桥位或全楼标高。

## 改动

- `ResearchFront.gd` 保留上部弧形石墙和遮阳，把对应底层玻璃向内退2米，封好侧向玻璃收口及弧形檐底，形成真实可走的架空区域。
- 新 `ResearchTerrace.gd` 加入白色圆柱及圆柱碰撞体，补底层玻璃竖梃。中央已有公共门洞保持可用。
- 现有上部台地向外扩出局部硬铺面，保留中央主梯开口；旧横向护栏移到新外缘，补端部回栏，避免新旧栏杆把台地割开。
- 补三组石质树池、灌木、小乔木、木条坐面、沿玻璃的排水细带和铺地分隔线。树池与座位集中在外缘，沿立面的连续通行带留空。
- 外扩楼板为实体结构，下面的中层平台仍保留净空。

这些是在 V172 同一建筑变换和 11.5 米拟合台地上进行的局部修正。退让深度、平台宽度、树池数量/位置、柱径及绝对层高没有实测支撑，不能据此称整个后山地形、后门具体落点或钟塔高架连廊已完成配准。全景的“后门”名称只用于识别参考视图，不把它自动绑定为模型地面后侧轴向门。

## 集中验证

`tests/ResearchTerraceV173.gd`：19段、单起点连续通行，9项检查全部通过，退出0，无引擎错误。路线覆盖主梯上行、台地两侧、树池后通道、弧形架空、庭院门洞及原路下行；检查包括退入玻璃围护、圆柱碰撞、旧护栏移除、新外缘保护、外扩楼板、树池墙、下方平台净空和架空净高。4张画面已逐张核看。190项导出依赖存在且唯一，差异空白检查通过。

结果见 `tests/artifacts/research_terrace_v173.json` 与 `research_terrace_v173_accepted.json`。本批没有重测整座校园，也没有新增车辆通行结论。
