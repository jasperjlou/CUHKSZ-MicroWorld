# 图书馆池侧与连续外壳 · 2026-10-10

依据[官方荷花池全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116440795)中图书馆方向，以及[建筑师竣工航拍](https://wwjarch.com/Central-Courtyard-of-Chinese-University-of-Hong-Kong-SZ)，修正原先侧墙沿用教学楼窄窗模板的问题。

## 已落地

- 两侧墙和背墙改用连续灰色金属板、三排深凹窗、铜色窗侧及深色窗框，与正面保持同一套构造。
- 侧墙浅凹曲线、上沿起伏、金属压顶和屋面相接；屋面在中段收窄，避免原矩形屋面外挑到新侧墙之外。
- 池侧首层增加通高金色遮阳片、内退玻璃和可穿行入口；开口保留在池岸弧形平台后方。
- 二层侧回廊向内调整 3.2 m，补转角承接平台，继续连接学生中心廊桥与图书馆主门厅。
- 侧墙细部在同一个节点内按材质批量生成，未为每个窗新增一个独立模型节点。

代码在 `LibraryEnvelope.gd` 和 `LibrarySpaces.gd`。配置版本 v10，24 组原建筑坐标和朝向均未改动。侧墙最大凹进 2.8 m 是当前尺度下的建模估计，不能当作实测尺寸；前后窗位也不是逐窗测绘。

## 验证记录

`tests/LibraryReturnCapture.gd` 集中检查 6 个视角，以及被本次外壳修改影响的二层连接和池侧入口。首次记录 `library_return_initial_failures.json` 暴露了回廊内移后的转角承接平台缺口，已扩大连接平台。最终记录为 `library_return_milestone.json`，引擎日志为 `library-return-final.log`。旧的中庭连接检查脚本也同步到真实内移后的行走路线；历史通过记录不代表已重新执行全程。

后续仍需统一光照与灰度层次，改善阴影里的细节、屋顶偏亮及背景地形边缘；不得把通行通过当作整栋建筑测绘复原完成。

最终结果：9/9 段连续实体移动通过，6 个渲染视角，构建 703 ms；最终引擎日志无脚本错误。没有重跑无关建筑路线。实景对照页当前为 11 组。
