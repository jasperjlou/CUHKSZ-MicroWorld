# V148 六层共墙组团与较新实景细节

2026-10-12，开发版 `2.0.1-dev` / `official-visual-build-148-library-sixth-commons`。稳定包 v2.0.0 / V145 保留，完整下园 Goal active。

## 依据与新发现

- [2025-08-29 空间调整通知](https://library.cuhk.edu.cn/zh-hans/event/1219)明确自 2025-09-01 起六楼开放区面向所有读者；调整后有 7 间小组学习室、1 间会议室、22 间教职工研究室。这是运营变更日期，不是照片拍摄日期。
- [2025-09-17 空间优化公告](https://library.cuhk.edu.cn/zh-hans/event/1235)明确“善本室”更名为“特藏室”。本轮取得并查看公告的两张图片：木质竖牌及六楼开放区，原件和哈希见 `references/visual_build_20261008/originals/library-upper-v148/manifest.json`。照片准确拍摄日未知，不能标为 2026 现状实拍。
- 六楼照片可见灰色地毯、透明隔断及浅色点状上沿、白色平吊顶与长条灯、木色圆桌、带轮网背椅及酒红色沙发。照片未覆盖完整楼层，家具数量和位置不能按全景测绘推断。
- 继续使用校方 2025-08 路径的六层平面与 V112 独立配准。五组房间各为背靠背的三间/两间组合；原 616–620 在旋转 180 度后左右编号颠倒，已校正。前端单独房间在图中写“401”，不能擅自改成“601”；本批先建无编号外壳，真实编号和用途对应保留待查。预约网站要求校园账号，不把身份核实作为其他建模的阻塞。

## 实际模型

`LibrarySixthCommons.gd` 取代当前六层的独立房间盒子：五个共墙组团分别只有一面中隔墙、三间侧的两面分隔墙及两间侧的一面分隔墙；外沿采用玻璃及细框，上部点状浅色带，补门扇、拉手、门禁面板与房号。房间宽深按图示比例拟合为组团约 5.4×5.2 米，不是实测。室内布置没有编造。

602–605 改连续共墙排，门面朝核心与房排之间的走道；前端独立房间补外壳但不标号码。公开范围以门外通道为主，门扇保持关闭，不宣称本轮完成所有房内空间。

开放区替换三张通用方桌，补代表性圆桌、网背转椅、酒红沙发与右翼平吊顶/长条灯。数量、布置、吊顶标高仍为照片与现有平面结合的拟合，不冒充完整 113 个座位的现状清点。五层门牌按新公告改为木质“特藏室”竖牌，门洞保留。

## 验证与接续

结构批次完成后集中检查六层公共路线、前排与独立房间门外通道、共墙碰撞、所有门口楼板与净空、家具支撑及五层门口。精确记录以 `tests/artifacts/library_sixth_commons_v148_accepted.json` 为准；不将局部射线或门外路线当作完整室内验收。

下一批回到图书馆后翼、屋顶与跨层支撑，并接学生中心真实下层入口及服务门位。六层前端房号、完整家具/室内与当前实景仍留项；图书馆后车道至逸夫、主入口梯下馆内下层、东门至学生中心硬铺及全部 A–G 背面、角落、高差完整保留。真实北向仍未校准。
