# V41 行政楼后立面、四楼门厅与架空空间

2026-10-10，`official-visual-build-41-admin-registration`。东门原点、建筑锚点和现有主屋顶高度保留；这批纠正的是后侧楼层关系，未完成整个 B 区。

## 证据纠正

重新展开[官方四楼后门全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116443793)的四块二级正面图，并对照右侧玻璃转角及[背山全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116443781)，确认可见关系是**三排上部横窗，下方另有四楼门厅和架空空间**。V14–V40 文档中“四排上窗”的解释有误；旧模型把门厅塞进最低一排办公窗，也把楼板铺满到后侧，压低了架空空间。

资料读取日期是 2026-10-10，官方全景拍摄日期未确认。目录中的日期不作为拍摄年份。检索到的 Griffin Enright 行政办公楼效果图与建成实景明显不符，已排除出本次建模依据。七楼改造公告仅证明第七层存在，不能独立证明总层数或层高。

## 实际改动

- 后立面改为三排成组横窗及间隔窄窗，两端补连续玻璃转角；保留正面暖色底层窗带和上部竖向遮阳。
- 将后侧桥体底面上移到上部办公体量下方，前侧四楼楼板保留，恢复中央架空关系；移除原来虚构在正中央的后门和小门厅。
- 在一侧玻璃转角下建立退入门厅、深色实体墙、门框、打开的门扇及雨棚；导航中的“四层后门”同步移到新入口。
- 将低翼屋面接平到平台，补侧向连接、挡土边界、入口砖带和排水。室内只做可见公共门厅，不虚构办公室布局。
- 给原来只有外观的台阶井两侧玻璃栏杆及眺望台内侧栏杆补碰撞。上部玻璃补反射底面，避免整块办公楼呈现空玻璃笼的视觉。

实现集中于 `AdministrationRearBridge.gd`、`AdministrationBuilding.gd`、`AdministrationPublic.gd` 和数据中的行政楼/后门记录。

## 本批验收

初次检查中，主楼梯三段上行、另一侧平台往返及架空顶面射线通过；一段斜线测试从平台切进台阶井并掉到下层，暴露了旧栏杆无碰撞的问题。已保留失败报告，没有把它算作通过。

## 仍待细化

三排上窗与下部门厅的相对关系有实景依据；平台相对地面 12.4 m、上部桥体底面约 16.1 m、入口所在侧及其准确偏移、门厅进深、平台宽度、楼梯分段、后山绝对配准仍属拟合。这个验收证明相关路径能走和本次空间修正已落地，不能证明尺度准确或行政楼全部完成。
