图像可见弧形中央楼梯、上方多层中空、白色通高柱、木色圆弧底部书格和灰绿色交错条纹方块地毯。它们与现有封板模型差异明显，作为下一批中庭改造依据；本批没有声称中央中庭已经复原。原始图片留本地参考目录，资源 URL、日期边界及改模关系见 `references/visual_build_20261008/old_library_union_v166.json`。

## 改模

- 对端第三座折返梯连接当前地面至四层，补两跑、转折平台、围护、扶手和各层真洞口；与已有两座梯共用构造，方向相反，入口面向公共厅。
- 教学回翼与低横楼重叠区（局部 X21.84..42、Z-18.46..-9.88）改为低横楼持有低层楼板，教学回翼仅补交集之外部分；高处教学楼层和退台外墙保留。
- 四处楼翼交接撤去埋在建筑内部的横墙和窗带；两侧前楼高于回翼的外露墙段保留。屋顶内接处不再立一圈多余女儿墙。
- 底层院落玻璃仅沿真实外露边界生成，撤去穿过回翼的内玻璃；两侧装饰吊顶退到低横楼之外，避免盖住新增或既有梯井。

以上修正的是现有拟合体量的内部矛盾，尚未证明整个旧馆占地、附楼比例和现状入口朝向完全准确。
