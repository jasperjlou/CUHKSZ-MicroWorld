# V146 主入口梯下 116 白三角修正

2026-10-12。开发模型 `official-visual-build-146-library-soffit`，工作区产品版本 `2.0.1-dev`。正式版仍固定为 v2.0.0 / V145，未覆盖或重新导出稳定包。

## 根因与改动

长期记录为“116 底面小三角亮缝”的现象，实际是一块公共区发光灯板跨进密集书库斜墙：灯板局部中心 `(17,4.02,0)`，世界中心 `(78,6.26,-273)`。原放置规则只检查中心是否在 116/119 外，1.25 × 0.95 的整块面板仍可越过斜边。

正确换算截图与逻辑视口坐标后，可见像素射线先命中该非碰撞发光面板（约 12.91），再到实体墙（约 13.17）。该结果在 `library_soffit_v146_bright_diagnosis.json`，明确区别于早期错误像素坐标下命中的其他墙段。

`LibraryLowerRightPlan.public_light_fits()` 现在检查完整矩形及约 0.1 的墙边余量：必须完全处于公共轮廓内，并与 116/119 轮廓无交叠。移除越界灯板后，公共区仍有 25 块灯板。室内拟合灯具布局不是当前实景灯位测量。

这批最终没有改变墙、斜底板、楼梯、门洞及任何碰撞。侧封板加厚、拆墙内重叠端盖的尝试没有解决现象，已全部撤回，补丁和失败日志保留在本地。没有用新增墙体、降低照明或关闭阴影掩盖问题。

## 证据和验证

- 116 轮廓继续沿用公开 1F 图的既有拟合，主入口外梯及下层身份沿用 V117/V120；本批没有新照片，不新增拍摄年份或现状装修结论。
- `library_soffit_v146_finish.json`：6 项检查通过，包括 4 个结构探针、公共灯板仍存在、已定位的越界灯板被移除。最终日志 `library_soffit_v146_light_boundary_final.log` 无引擎错误。
- 最终梯下与外梯两个视角已查看：白三角消失、主入口外梯及开口保留。第三个名为 public 的机位过于贴墙，不能证明完整公共空间外观，排除出有效展示机位。
- 模型碰撞未改，复用此前通行结果，不重跑整个校园或 15 章。早期试改的结构失败、GDScript 类型错误及像素定位错误均不算验收通过。
