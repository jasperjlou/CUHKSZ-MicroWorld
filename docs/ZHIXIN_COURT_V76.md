# V76 知新楼内庭与主广场临街地面

## 本批实际改动

- 依据官方 Main Square 正面两幅图，将知新前翼朝内庭的两侧立面、教学返回翼的内侧改成连续横窗；外端稀疏小窗保留独立结构依据。
- 将“知新楼”标识移到旧图书馆标识相对的另一翼，并降低到入口上方。
- 主广场两侧约模型 Z=-636 至 -779 范围及知新临街前坪改为赭黄色细长砖。新增独立材质 34，按 300×100 mm 视觉拟合，细缝随像素覆盖衰减。
- 灰色石铺内庭与黄色前坪分开，补深色边带、低树池及边界排水槽。画面中的深色线按铺装条带处理，没有据此虚构台阶。
- 三旗台前移到临街前坪，补与逸夫弯道衔接的白色车道边线，修正被草地覆盖的树池土面。
