# V78 主广场连续草坪与端部上行

## 实际调整

主广场背向全景显示连续下层草坪；靠逸夫端有顺沿街方向上行的台阶，靠钟楼端延续园路短阶。本批移除 V54 等间距三组横穿草坪的宽梯，恢复完整草坪及连续挡墙，新增逸夫端宽梯和沿墙上层步道，连接诚道、志仁的真实端部开门位置。钟楼端不叠加另一组教学台地宽梯，保留 V64 园路串联短阶。

地形同时撤去三条旧斜坡，加入新台阶的转折采样；下层草坪清掉旧横向铺面、灌木和占用中央空地的树带。上层路线绕开梯栏末端，模型路线数据同步改写。

## 验证与衔接

集中验证下层街道—逸夫端台阶—上层步道—诚道/志仁入口—原路下行—连续草坪—钟楼既有两段短梯。24段连续通行一次全部通过；草坪原中央梯位置高度保持下层。收尾发现新台地边界抬起弯道路边，将台地侧边退到X15.8–16.2并收窄上平台后，3处街道标高检查通过、两张受影响画面复看。总计4张最终视角已检查，两次运行均无引擎错误；未重复24条不受边缘修正影响的路线。结果见 `tests/artifacts/main_square_terrace_v78.json` 与 `tests/artifacts/main_square_terrace_visual_v78.json`。V54以及V76/V77涉及已移除三梯的通行记录退休；未改变的楼内记录可继续作为局部证据。
