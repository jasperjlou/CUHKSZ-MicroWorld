# V171 科研楼侧梯、下层门廊与悬挑石台

2026-10-12，开发线 `2.0.1-dev`。上轮 V170 是实际模型进展，当前继续 G 区；稳定版 v2.0.0 未更新，完整 Goal active。

## 依据与范围

复看 V170 下载的建筑师供稿图 011 与 073，并结合 009/010 整体照：玻璃端部旁有沿地形上升的浅色台阶、灰石栏板、悬挑平台和下方浅赭色檐口/白色廊架。现有裙房侧面是一整堵 11.2 米封闭直墙，遗漏了这组公共空间。

来源仍为 [2025-12-24 发布的建筑师项目资料](https://www.gooood.cn/the-chinese-university-of-hong-kong-shenzhen-phase-ii-by-wang-weijen-architecture.htm)，拍摄及绘图日期未知。011 可以辨认台阶与平台局部；073 支持逐级平台关系，不能作为整栋建成平面或现场绝对标高。照片中的侧梯与模型入口的精确对应位置尚未测量。

## 本轮修改

- `ResearchSideAccess.gd` 加入地面门廊、玻璃侧窗和真实门洞，接入原下层公共通道。移除相应的旧实墙，不以穿墙通行代替开口。
- 两跑侧梯从原地面标高升至 5.5 米，再到 11.5 米屋顶边廊；中间平台留侧门连接裙房。台阶有踢面、梯底、碰撞坡面和浅色石质栏板。
- 中层增加向前伸出的灰石平台，连接侧门及裙房内部；外缘有石栏板和压顶，避免悬空敞边。
- 下层补浅赭檐口水平分缝、独立白色廊架、硬质铺地与排水条带；廊柱及廊顶避开侧梯通行和净高。
- 最高平台开出屋顶旧护栏的出口，接现有侧后边廊。后山车道的真实标高尚未配准，未据此声称已经接上山路。

首批发现上层新栏板横穿现有屋顶边廊，缩至 x≥45 的真实外缘，保留外侧防坠保护。首轮画面还暴露新低廊顶伸入旧车道、旧路灯从平台中冒出的问题：廊顶退至建筑侧 z40–43 的铺地，缩短避开侧梯；旧内嵌路灯移至外侧路边，已有钟楼路灯附近不再重复放置。保留失败记录，仅复查断点后续与调整后的门廊入口。

保留原科研楼锚点、东门坐标原点。四米梯宽、梯长、台阶数量、门位、平台外挑及 0/5.5/11.5 标高都是实景组织关系下的拟合。旧中央大梯和 V169 内梯的确切现场归属仍待裙房完整平面核对；本轮验证不证明这些拟合已经成为测绘复原。
