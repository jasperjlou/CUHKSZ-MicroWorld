# V120 池边连续竖片与 G 室外连廊

2026-10-11，`official-visual-build-120-library-pool-arcade`。全下园 Goal active。

## 本批结构变化

V115 将公开三楼前缘的第 3–6 段做成通高竖片，弯向入口的后续几段仅留下三楼短竖片，导致下方内部核心直接露在池面上。V120 结合已建正面照片，把临水连续范围改为第 4–9 段；第 3 段侧向退台下方开放，用于进入退后的 G 门前室外条带。竖片底边仍为拟合值，不能据此声称上下层标高已完成测绘校准。

新 `LibraryPoolArcade.gd` 将公开 1F 图中标注 Entrance/Outdoor Interactive Space 的退后门前空间建成灰石通道，侧边接池端干地。弯曲外缘与三楼共用一组点，补白色支撑柱、入口侧白色端柱、窄梁和水边收口。白柱数量/截面为拟合；没有把 2024 活动布置当永久设施搬入。

池岸由旧直线跨接改为跟随完整竖片曲边，撤回侵入门前室外条带的水面。现有地形、馆前石铺及十周年地面均调用同一池面裁剪方法，因此同步收口。内部斜核心和楼梯保留，没有为照片删除功能结构。

路线元数据区分 `library_main_2f_approach` 与 `library_g_side_arcade`：前者是主入口坡路/外梯，后者是本批侧向 G 门通道。都由专用结构拥有铺面，未叠加通用道路条带。

## 集中验证与失败处理

首轮从池端进入侧通道时失败：新铺面把原本 `.12` 的装饰层赋予碰撞，使平接位置出现不支持的 12 cm 台沿。修正为 G 基准高程碰撞，`.12` 装饰面沿用既有地面做法；没有缩小玩家或关闭障碍碰撞。此时脚底与装饰面存在全工程既有的偏移，后续整体材质/标高整理应统一。

首轮第三处探针原在局部 `(-4,33)`，事实上落到新水边以外，不能期待干地；改到内侧 `(-4,29)` 后检查。保留首轮失败记录，不计入验收。

最终 `tests/artifacts/library_pool_v120_final.json`：**24 段连续往返、1 个起点、5 处探针全部通过**。路径：池端 `(14,2.24,-334)` → 开放侧面 → 退后 G 门 → 馆内短段 → 原路返回。探针包括干地支撑、外侧无草地封水面、侧退台无墙。此路线不是图书馆后车道到逸夫的路线。

最终日志无引擎 ERROR/SCRIPT ERROR。3 张图：`courtyard-refined-library-pool-v120-{overview,front,arcade}.png`；碰撞台沿修正前已看，修正未改变可见几何，最终重出同视角。侧通道和前曲面有改善，但总览依然显示上部/入口亭整体比例与实景存在差异，未标为整栋完成。

物理复验期间仅更新无渲染路线元数据，最终场景几何与复验一致，未因此重跑全区。
