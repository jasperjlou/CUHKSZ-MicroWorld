# V190 玩家视角与暂停前收束

2026-10-12。用户要求本轮完成后同步 GitHub / 本地正式版并暂停，保留后续精修。目标版本 v2.1.2，模型仍为 V188，Agent 17 章保持 V189 编排。

## 改动

旧玩家镜头以脚底上方 2.4 m 为射线起点，只保护镜头中心；内梯和低楼板下该起点可能越过遮挡。CampusPlayer 改为 1.5 m 高度的锚点、0.24 m 半径球形扫掠，并在平滑之后再次约束镜头。近裁面从 0.25 降到 0.08 m。保持建筑尺寸、标高和 1.88 m 角色物理身高。

默认偏移从 (0,4.6,8) 改为 (0,2.5,5.2)，垂直视野从 60° 改为 55°，降低俯视感，增大近处建筑在画面中的比例。右键、滚轮和 2.5 倍基础移速保留。镜头缩至角色附近时，2.4 m 内隐藏角色网格，退到 2.7 m 外恢复，避免小房间被角色头部挡满及临界闪烁；物理角色仍保留。独立 Agent 镜头保持原配置。

球扫掠不处理起点已重叠的形体，故锚点位于角色已验证的胶囊净空内；未声称修复无碰撞装饰或所有校园未知净空。接口依据：[Godot PhysicsDirectSpaceState3D](https://docs.godotengine.org/zh-tw/4.5/classes/class_physicsdirectspacestate3d.html)。后续新增低顶/碰撞几何必须复查该约束。
