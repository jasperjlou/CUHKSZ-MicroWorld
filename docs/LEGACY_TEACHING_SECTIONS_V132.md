1. 斜向长楼翼、端部横向体量、较低平台及连接处能从旧模型区分。相邻教学组团有重复的结构关系，可用于检查当前体量是否连错、漏掉低层连接。

3. 高度 23.5 的图仅能看到低层边缘、围挡与局部阶梯；剖切面不封盖。不能把大片同色区域当成真实空地、封闭房间或草坪，亦不能据此认定实际下首层不存在。
4. 建筑师上下两层平面具有不同的实体/绿地/柱廊轮廓。后续应先对齐外围路缘、斜翼端点和前廊，再分别建各层，不能把上层院落投影作为整个下层铺地。
