# V82 知新—道远排列、旧南门与下园篮球场

2026-10-11，版本 `official-visual-build-82-start-zone-registration`。完整下园 Goal 保持 active。

## 本批纠错依据

2026年5月校方导览图与建筑师提供的043总平面一致：道远位于知新背后、靠校外道路一侧，主入口朝向外侧；旧南门在这一组团靠钟楼端的横向道路尽头。此前把道远放在知新钟楼端并令其朝主街，导致道路、旧南门与停车空间都跟着错位。

建筑师总平面刊登于2025-12-24，原图文件与来源见 `references/visual_build_20261008/start_zone_registration_v82.json`。发布日期不是图纸测绘日期。官方航拍92544949的 `l-2-1/l-2-2/f-2-1` 补充屋顶、球场、停车与种植岛关系，拍摄年份仍未知。此前下载的 Griffin Enright 竞赛图仍排除，没有把未建方案当现状。

校方体育部当前“室外球场”目录明确下园两片篮球场。目录实景 `B0027968.JPG` 可见红绿运动铺面、绿色围网、白钢篮架、暗绿坐凳及旁边涂辉龙楼。两片数量已有文字依据；围网开口、精确场线和尺寸仍采用模型拟合。2026-10体育新闻页面只证实设施类别，未用其发布时间冒充这些照片的拍摄日。

## 模型变化

- 道远锚点从 `[-65,4.64,-805]` 移到 `[-112,4.64,-733]`，朝向从90°改为−90°。其两侧楼梯、砖铺台地、花坡、入口短阶及地形一起刚体转换，导航入口同步更新。
- 旧南门移至 `[-174,2.24,-790]` 并朝外侧道路。撤掉原Z=−838西向横路与旧入口铺地，新横路沿知新钟楼端连接主街和旧南门；补两侧步道及体育馆方向的人行连接。
- 上批知新后停车排在新道远台地范围内，已移到球场旁。楼间保留窄服务车道和沿楼步道，不为保留旧测试而让停车穿楼。
- 新增两片球场、篮架/篮筐与网、场线、围网、可通行开口、灯和坐凳；地面连续接回街区步道，停车侧有独立进出路径。
- 原错误道远位置恢复航拍所示绿化岛。球场材料收尾降低过亮色调，围网增加像素覆盖过滤，避免远处细网产生摩尔纹。

以上米制锚点、间距、2.4米台地高差和球场边界仍为比例拟合。本批解决相邻关系与朝向，不声称已完成测绘级配准。
