# V257 道远台地、侧阶与旧馆后路接口

正式版保持 v2.1.10；开发版进入 2.1.11-dev。上一轮完成正式发布，本轮为实际模型推进。东门原点保留，真北未校准。

重新查看官方道远全景 116440775 的左右面，以及官方航拍 92544949 的三个已有图块。道远侧面可见红砖台地、石边与条状排水、开放金属栏杆；原模型使用玻璃栏杆不符。改为横杆和立柱，原防坠碰撞完整保留；两处长侧阶封闭立面，保留原坡面碰撞、位置及高度。砖铺增加交错砖缝、单砖色差与细颗粒，石边增加接缝和排水格栅。排水在楼梯口前结束。

旧馆后路初始画面还出现弯头处沥青与步道间的草缝，将既有步道向路缘衔接补足；没有另铺一条道路。最初排水试排含一段落入侧阶范围，最终删除，仅保留两梯之间的明确边缘段。初始画面和日志保留。

资料边界：全景及航拍的拍摄日期未知，不能当作2026现状证明；2026校园图只用于名称和邻接，未给局部米制测量。新搜索校方资料未找到能确认后翼底层的新几何图。后翼底层、楼间绝对宽度、高差、侧门和无障碍连接仍为未核准项。本轮不凭航拍中被屋顶遮挡的部分补门洞。横杆间距、砖尺寸、排水位置仍拟合。

本批集中验证结果及图像哈希见 `references/visual_build_20261008/daoyuan_connections_v257.json`。初批两条连续路线：道远侧阶—台地—背后侧路往返10段，旧馆后路及端头4段；不把两处起点当作已连通的一条路线。第一次收尾仅改排水装饰和步道薄面；随后近景发现原台地栏杆没有接到两侧楼梯扶手，延长原全高防坠碰撞并补两个短接头。这项结构改变另验6段受影响的转角/楼梯线路，保留前14段记录。未进行全园重测或新一轮发布。

下一批 V258 沿钟楼端横路进入科研楼侧场地，先读 V170–V173/V206 的实景与未完成边界，核对可见地面、坡脚和楼体接口。已确认的局部不重复建造；隐藏后翼、C–D共同标高、灰梯、032/301和完整A–G继续保留。
