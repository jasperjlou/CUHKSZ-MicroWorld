# V221：学生中心301大厅、挑空与上层玻璃廊

2026-10-14；开发2.1.5-dev，模型V221；正式v2.1.4与双入口保留。本批是有证据的结构补缺，大厅尚未精修完成。

## 依据与年代

[校方学生事务处设施页](https://osa.cuhk.edu.cn/zh-hans/facility/368)将该室内照片标为301多功能厅。木饰面、上层玻璃廊、两层窗及顶棚特征与[建筑师项目文章](https://www.gooood.cn/en/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm)016/017照片对应；文章中文正文也将多功能厅置于三层。房间身份有交叉支持。

OSA页面未提供照片拍摄日，资源路径2018-08只记录为路径年月，不能充当拍摄日。建筑师文章发布2021-05-28，项目2012–2019，原照片拍摄日及图纸修订日未知；本次获取日期2026-10-14不意味着2026实景。现行家具、装修和用途的持续性仍需较新资料验证。下载的五张OSA照片及页面与SHA-256在`originals/student-osa-20261014/`保存，其他房间照片未擅自定位。

## 实际修改

沿用030三层平面和已有共同点配准，大厅范围原图u425–794、v505–691。补厅侧木饰面隔墙、北侧主双门、西南侧室内门和端部关闭玻璃界面；木块地板采用新专用材质，窗内衬面遵从现有立面窗格，保留原玻璃与碰撞边界。相对层高继续使用8.8、12.4、16.0，均为拟合。

两组照片支持双层通高及上层玻璃廊，移除4F内部u500–794、v548–691范围的错误楼板，保留邻边上层通道并加白色裙板、玻璃、框柱防止跌入。**上层通道宽度及开口精确轮廓仍是照片约束下的拟合，缺独立4F平面。** 没有把该开口直接复制到5F、6F或屋顶。

现有5F底面仍是普通楼板，天窗、吊顶格栅、上部光井尚未构建；这是下一批首要事项。窗间比例与墙厚仍继承拟合外立面，不能称为现场测绘复原。

## 通行失败及处理

初批从厅内穿过西侧u425、v518–554开口后，目标位置缺少同高地面，角色下落；14项射线虽全部通过，但实际行走发现问题。失败日志和报告保留，不能用射线结果代替走通。

未凭空补一块架空平台。该门暂做关闭双扇门并保留碰撞，待解决外侧平台/门槛高差后开放。北侧主门与西南侧v668–684室内门均有地面承接，并已真实通行。此关闭表示本项目待配准限制，不证明现实门常闭。
