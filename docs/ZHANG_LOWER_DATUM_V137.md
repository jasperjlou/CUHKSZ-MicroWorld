# V137 张岭彬楼上下层与后路联动

## 本批实际结构

- 主体楼翼、低翼及后核心共同下移4.8米；低屋面顶相对前廊7.525，主屋面18.625。旧模型换算候选值约7.349/18.457，差异为沿用板厚及现有楼层间隔的拟合，不是实测还原。
- 后路相对前廊-4.565，下层公共地面-4.8，约0.235落差由后门前短缓坡连接。前廊世界Y仍2.24，所以后路Y=-2.325、下层Y=-2.56。
- 原同高整片地面改为前廊层结构平台与其下方可进入的公共空间；核心梯井保留真洞口。地形网格同步按边界挖空，补下层地面、后门、围护/挡墙、柱梁和顶面。旧通用装饰地板撤除，避免把楼梯洞口视觉盖住。
- 两侧步道增下降段；后路接下层公共空间再连回核心楼梯。侧梯位置、围护/柱网、下层房间划分仍拟合，当前下层是公共结构壳体，不能说完整房间复原。
- 两条上层桥面用1.1米/23.38米缓坡接到保留的照片连廊4.925/8.625；低屋面补入口护墙缺口及短边护栏，桥面补板底/侧边。坡长、高差与连接形式为兼容实景前廊锚点的拟合，仍需精确平面核准。
- 下层核心楼梯导航点Y同步-2.56；照片上层导航不变。

## C-D 接头的明确未完成项

C楼后路尚为旧上层基准。为保持当前可通行，C-D间用一段临时过渡楼梯连接；它不是实景考证结论。下一批必须核准并迁移C后路/下层，使同属低位的后侧道路连续，再移除该过渡楼梯，不能把临时接头当校园精修完成。

## 检验范围与失败记录

有效物理记录分三段，不能合称一次全楼连续跑完：

1. 27段单起点下层闭环：前廊—低翼首层—核心下行—下层公共空间—后路—临时C接头往返—侧梯—回前廊。
2. 33段单起点上层连续前缀：前廊外梯—第一照片廊—缓坡桥—低翼—核心—低屋面—第二照片廊—核心下行至首层。
3. 8段独立起点收尾：从相同核心落点经门洞中央返回前廊。

合计68条有效移动记录、3个起点。初期直穿柱的目标、侧穿前廊凹段墙、从外梯侧面进入斜板下方、贴核心门洞边缘的路线均拒绝并保留原日志；改绕障碍/走门洞中心，不移柱扩大门来迁就测试。前两项保留自完整运行失败前的有效连续前缀，原始失败报告仍在，范围在派生报告中写明。

7项基础探针：后路、下层、首层平台、低屋面、主屋面高度，核心洞口，下层后门。收尾追加2项屋面桥头边缘护栏/中心通路检查，共9项。旧测试固定lowest>-2.15会误判新下层；本批按每段起止地面最低值减0.65检查异常下坠，落点Y误差小于0.4，并未取消坠落检查。

最终5有效视角：后侧入口、下层、侧梯、整体、上层桥。初侧梯相机放在未开挖地形外、低于地面，图作废重拍。物理后收尾仅增加视觉板底/浅色顶面，以及不占已检中心路线的屋面桥头两侧护墙；两项局部碰撞检查与3张受影响画面复核，无需重跑已通过的下层闭环。
