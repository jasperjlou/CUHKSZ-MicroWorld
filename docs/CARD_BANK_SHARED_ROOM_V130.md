# 校园卡/中信共用下层空间 V130

## 模型修改

原校园卡门面后仅有约4.7米深空壳。现保留既有门面与公共入口，将内部深度拟合到9.7米；补向西延伸的地板、顶板，切开原服务廊西围墙对应部分，避免隐藏墙穿过家具或通道。位置仍为既有东门坐标系，真实北向未动。

新增 `CampusCardBankInterior.gd`：银行双服务窗及封闭柜员边界、四组灰色等候座、自助终端、白色服务岛台和高凳；校园卡侧三组白色桌/紫色隔板及旋转椅、木台面浅色储物柜、红色等候座。补米色大砖、局部木地板、白色吊顶、面灯与风口。家具、柜台和后墙使用简化实体碰撞；没有建造未见的柜员后台或保管室。

## 验证

一次最终连续20段通过：共享入口、银行等候与服务窗前走道、办卡客户走道、末排隔板后路、储物柜侧通道、原纪念品店前公共廊返回。4射线检查通过：银行后界、扩展楼板、房间后墙、共享入口头部净空。

初轮沿用室外0.8米停止距离，未完全走过内开门扇就转弯而卡住，该路线作废。室内改用0.18米到达阈值、入口落脚点前移至门扇之后，未通过削掉门碰撞来规避；最终最大终点误差小于0.1米。初次失败日志单独保留。

最终渲染/引擎日志和源码哈希由 `tests/artifacts/card_bank_v130_accepted.json` 记录。更改前副本在 `.tools/backups/card-bank-before-v130/`。

画面收尾将座椅/长凳改圆角轮廓，保留原箱形碰撞；自助终端转向室内，主体碰撞旋转180度后占用范围不变；后墙左右各延长0.43米接上侧墙，闭合外角窄缝，不进入已验证路线。随后集中复看最终四图，物理记录复用。

圆角软包最初缺少底封面，旋转为椅背后从反面可看到孔洞；已补反向底面。仅重拍入口与办卡侧两个受影响视角，保留不受影响的银行/回望视角，共四个最终有效视角；无额外物理重测。
