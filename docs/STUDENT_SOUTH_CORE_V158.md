# V158 学生中心图纸下侧核心与三层通廊

开发模型 `official-visual-build-158-student-south-core`，产品 `2.0.1-dev`。正式 `v2.0.0` / V145 与两个入口不变，未提交推送。文件名 south 指历史平面下侧，不代表地理南向已经校准。

## 实际改动

补图纸下侧五组折返梯、入口平台、真实楼板洞和围护，贯通当前模型 G–6F。该组梯方向与前后两组不同，独立旋转飞行段坐标，确保坡道与扶手碰撞保持一致。邻接服务电梯保留封闭井壳及关门面板，没有模拟可运行轿厢。

030三层图中，院落边缘约v459与下侧房间v505之间有通廊。原模型在u425–710范围漏了一段楼板，又沿院落边留了横栏杆；本次补通廊、移除挡路横栏，仅在西侧落差边补护栏。由三层院落可经南楼翼内侧过道抵达新核心，也能返回。G层出口接公共厅，不冒充已经核准真实下首层的室外入口。
