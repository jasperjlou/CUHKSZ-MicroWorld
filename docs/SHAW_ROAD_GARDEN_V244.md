# V244 逸夫后车道林缘与铺装支路接头

2026-10-14；2.1.8-dev。本批为局部景观/饰面，完整下园 Goal 继续。

## 依据与实际改动

官方全景 70040609 的侧向画面显示乔木、支撑杆、低篱、维护草地与后方山林。模型保留实际山形，增加 97 棵树与 63 组灌木，替换该局部原通用树冠，保留近路草地并为林下增加渐变落叶/土色。数量、尺寸、位置和植被边界均为拟合，未声称测绘或当前种植清单。发布于 2019-09-10 的建筑外景仅作历史体量/山形对照，拍摄日期未知。

本轮重新查看 2026 灯会原图并在线核对 [校方报道](https://shaw.cuhk.edu.cn/article/1529)：发布于 2026-09-23，活动发生在 9月16日逸夫道滨湖区域。它可旁证铺装类别，不能证明后车道坡地布局；全景拍摄日期仍未知。

支路接入后车道时，裁掉穿过入口的路缘饰面，并将支路边线截至车行道外。后续画面暴露沥青与砖铺装重叠，新增 PavedJunction 按既有砖铺装的实际平面边界裁下层沥青，保留同一地形和碰撞。

## 验证与原始失败

共四次运行：三次成功、一次失败。首批五图、第二批三图、接头最终一图已看，共九张。首批林下土色锯齿已改为平滑材质过渡；第二批接头黑色碎片已在最终图消失。

第三次仅检查接头，但遇到未索引网格的 index 数组为 Nil；虽然场景剩余部分继续运行，报告的 failures 为空，运行器仍按引擎错误判为失败。原失败日志、报告及截图保留。修正空数组处理后，第四次成功处理 182 个接头候选路面三角形，无引擎错误。

植物中心距道路边线的最小横向距离 4.1m，仅是中心位置检查，不是树冠净空或通行验收。碰撞顶点/高程不变，没有新增步行或镜头采样成绩。各次报告与摘要见 [证据 JSON](../references/visual_build_20261008/shaw_road_garden_v244.json)。
