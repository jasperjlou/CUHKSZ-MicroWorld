# V75 逸夫东座外侧铺地与侧后连接

## 证据及年代

- 官方校园全景：[逸夫东座道路](https://campusvr-en.cuhk.edu.cn/?scene_id=116443797)，资源 70040609。读取完整预览及前、左、右、后各面的上半图块，另看前、右、后地面图块。可见褐灰色错缝矩形铺砖、散布深色砖、窄色带、东座灰色山墙、方形花箱、树带和直杆路灯；向学生中心与山侧均有步行连接。拍摄日期未知。
- 校方[2026 逸夫中秋湖畔灯会报道](https://shaw.cuhk.edu.cn/article/1529)，发布 2026-09-23，活动发生 2026-09-16。查看 KIT_4197-opq5019134848.jpg，照片中的矩形错缝铺地可以佐证近年的铺地类型；夜景、活动人物和器材遮挡较多，不能据此确定整条路的坐标、宽度或所有地砖均未更换。此处是逸夫书院十周年资料，与大学十周年专题分别记录。
- 2019-09-10 建筑师授权项目资料的一层平面：只用于既有台基和公共空间的结构核对。保留已有 4.5m 后侧高差依据，坡长和位置仍为模型拟合。

## 实际改动

1. 逸夫东座前侧通道改用独立的错缝矩形铺砖材质（拟合模块 0.40×0.20m），加入深浅砖、浅色纵向细带和较深横向分隔。材质仅用于这一地段；图书馆后车道继续是沥青。
2. 学生中心花园通道、东座正门台阶前场、转弯主路步道形成连续硬铺地。移除 V31 重复的前场板块、花坛和路灯。
3. 新增 `shaw_east_paver_side_link`，从前侧路口沿楼侧接入较高的后侧道路；JSON 与小地图共用路径。
4. 原有地形在 X99.3–99.7 以很短距离跃升，不能作为该支路的通行地形。仅在楼侧支路带内改为 X94–116 的连续拟合坡面，保持其他台地；增加地形采样点。铺面也在两个方向细分，防止草坡从横向长三角面穿出。
5. 补连续树带、树木支撑、直杆路灯、木色方形花箱与开花灌木，保留主入口台阶范围。植物品种、数量和准确位置未测绘。

## 批次验收

`tests/artifacts/shaw_promenade_v75.json`：一条连续 fixture 的 **19 段通行全部通过**，覆盖学生中心接入、沿街步道、既有正门石阶往返、侧路上坡、后车道接入及逆向回程。无路径中途传送。只检验本批受影响部分。

其后仅改变铺面网格、色调、路灯和通行带外植栽，碰撞和已验证路线不变；`shaw_promenade_visual_v75.json` 记录三张最终图，均已人工查看。两次运行无引擎错误。
