# V185 玩家体验、展示与绘制收束

2026-10-12。模型仍为 `official-visual-build-184-perimeter-closeout`；本批更改产品操作、展示路线/镜头和静态绘制，不新增建筑物理体。体验门槛有限通过，进入 v2.1.0 独立包验收；整个校园精修 Goal 保持 active。

## 实际改动

- 进入玩家模式、R 返回东门时复位镜头朝向/俯仰/缩放；F2、进入展示时清除拖动状态。
- 图书馆小组室参观避开已改核心墙，知新旧馆前路避开更新后的中庭边缘。修正路线坐标，保留现有实体碰撞。
- 池岸、张岭彬下层、逸夫西座等狭窄位置采用沿行走方向跟随；图书馆小组室采用独立门口/室内细节机位。章节间保留明确剪辑，章内真实物理步行。
- 不透明单位盒实例按材质、阴影和 48×48×24 米空间单元重组。241,760 个实例全部保留，9,818 原始绘制批降至 5,233；透明玻璃和物理体不改。源节点保留隐藏，研究工具的路径不失效。
