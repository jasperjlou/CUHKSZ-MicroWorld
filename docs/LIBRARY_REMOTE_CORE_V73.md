## 实际模型

- 新模块 `LibraryRemoteCore.gd`：拟合位置 (-37.3,0,-12.5)，一至五层标高 0/4.4/8.8/12.8/16.8，双跑梯、半层平台、各层公开侧门、实体扶栏和指引。
- 统一楼板切口作用于二至五层，包括原外翼 12.8 m 内底板；移除穿进梯井的旧柱及装饰栏杆段。六层没有强行延长此核心。
- 一/二层较大的男女与无障碍卫生间入口，三至五层较小的成对入口，补饮水点及硬质走廊地面。房间目前为关闭的外壳和门面，未建未见到的内部洁具。
- 下层旧桌位让开新核心，吊顶避让梯井，后部隔墙让出连接；公共走廊经既有坡道、后门、门外台阶回到室外石铺地。
