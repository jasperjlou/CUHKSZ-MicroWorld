# V156 学生中心后侧核心与上层通廊

当前开发模型：`official-visual-build-156-student-rear-core-gallery`，产品仍为 `2.0.1-dev`。固定正式版 `v2.0.0` / V145 和两个入口不变。本批未提交、未推送、未重新发布。

## 来源和判断

[建筑师供稿项目文章](https://www.gooood.cn/en/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm) 发布于 2021-05-28，项目期标注 2012–2019。029/030/031 为历史平面，图纸修订日未知；024 是透视剖切效果图、028 是设计轴测、032-1 是剖面，均不是较新现场照片。此次检查不能替代十周年及更新校方实景的现状核验。

本次新读的 032-1 剖面显示前侧局部房间低于主要下层板，但图上没有明确层号或绝对标高。保留真实下首层/共享场地标高问题，不能据此自动增加贯穿全楼的地下层，也不能据此确定图书馆后路 G/2F。024/028 仅约束院落高差、前桥和楼翼关系。照片拍摄日未知，不以 URL 中的 2021/05 或下载日代替拍摄日。

后核心平面四角经 V154 的 5F→1F 相似变换，人工对应残差约 1.10–2.30 px；只是局部图纸配准，并非测绘。完整来源、哈希、残差和拟合边界见 [机器可读证据](../references/visual_build_20261008/student_rear_core_v156.json)。

## 实际模型

- 后侧核心新增五组折返梯、各层入口平台、围护和扶手，贯通当前模型 G–6F。各楼板真实切洞，保留屋面封顶；平台只有顶面通行碰撞，避免立边卡住梯顶。
- 下部核心可从西侧门口和南侧过道进入。上层保留楼翼外围墙，楼梯入口经南侧过道连接通廊；没有把外墙开成通向空中的门。
- 5F 通廊从原先窄条改为图纸中的较宽通行带。楼板拆为不重叠的片段，前/后楼翼留真实开口，外侧有连续护栏。
- 中段两间房的南边界按 031 内退，恢复两个门口和房间之间的隔墙。撤掉此前围绕每个多边形生成、把整个通廊封死的外墙。
- 6F 通廊暂沿用 5F；层高、梯宽、踏步和部分门净高是游戏尺度拟合。前核心及下层院落既有路线未作无关改动。

新增 `StudentRearCore.gd` 已列入开发导出清单；仍使用静态网格与静态碰撞，没有运行时 CSG。

## 验证

137 段实走、24 项结构检查通过，无引擎错误；91 段连续上行/两层通廊和46 段独立下行，两个起点。7 图已检查，保留5张有效终图；原核心机位被墙遮挡、初屋面共面闪纹已替换。屋面最后增加25mm非碰撞饰面，未改通行碰撞，未重跑步行。批次结果在 `tests/artifacts/student_rear_core_v156.json` 与最终 accepted 收据记录。仅检查后核心、两层通廊和两间房门口；两个独立起点，不能称作整个下园一次连续验收。未修改正式包，未重跑未受影响的全区展示。

## 继续保留

院落三组大梯的精确起终层/投影、真实下首层、南侧其他核心和服务空间、6F 独立平面、现状门名/功能、前电梯点残差仍未闭合。下一批先从后核心与四层院落连接核对院落梯，再处理南侧核心；随后图书馆后路标高、D→F/G 及整个 A–G 的下层、背面和边角。东门原点及真实北向未校准限制保持，Goal active。
