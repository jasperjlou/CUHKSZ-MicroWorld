# V188 图书馆曲面外廊一至二层连接

2026-10-12。开发 `2.1.1-dev` / `official-visual-build-188-library-outer-gallery`。v2.1.0 固定正式包与两入口未改，完整 Goal active。

## 新证据改变了什么

[建筑师提供的项目说明](https://www.archiposition.com/items/20211120090540)明确将外廊解释为一、二层入口转换的坡道连接；页面的“图书馆斜坡道”图就是此前保存的历史 library-018。补读“外侧连桥”和上下层平面，确认应保留室外上升路线，不能把格栅后整个廊下都建成平地。建筑师[自身项目页](https://wwjarch.com/CUHK-SZ-Library)也说明二层入口与地面层研习区的分层关系。

页面显示发表时间 2019-07-30，图片目录为 2021-11；都不是拍摄时间。官网项目页的 2017 同样不能代替逐张照片日期。G 全景 scene 41566368 / pano 25181873 可透窗看到同类上升外廊；2026-09-07 EXIF 活动照片只补证圆柱、竖构件与灰栏梯局部，不能据此声称全坡测绘准确。

## 实际模型

新增 `LibraryOuterGallery.gd`：在曲面格栅内侧布置缓升廊道，保持现有 G=0、2F=4.4 的拟合局部标高，绕斜向核心外侧连接二层入口平台。宽 2.2m、入内退距、扶手间距、板厚都为照片比例拟合。廊道两边有连续灰金属栏杆及碰撞，底部是薄板封底，没有把下方空间填成实心楔块。

内侧 G 门厅平路保留；更新 `library_g_side_arcade` 元数据及 Agent 池岸章节路线，避免新增栏杆截住原来直走路线。暂未新增灰栏快捷梯：该梯的实景起终点和中庭共享标高仍需配准，坡廊与梯不能混算为同一实体。
