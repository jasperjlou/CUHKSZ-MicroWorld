# V162 学生中心池侧上层材料与标高疑点

开发模型 `official-visual-build-162-student-pond-upper-facade`，产品 `2.0.1-dev`；正式 `v2.0.0` / V145 及两个固定入口不变。

## 对照改变了修改边界

重新查看官方荷花池全景、2024年书展照片及建筑师001/004/029/030/031/033，新增读取建筑师005、003、014。2021-05-28是建筑师文章发布日期，照片拍摄日未知；005是另一侧外观，003为中庭关系，014为红色冲孔板内侧，不能全部当作池侧照片。2024-01-29校方文章中人物遮挡较多，黄色凹口可作部分印证，完整上部红屏范围仍依赖日期未明的全景。

池侧照片可见层数、连桥及下沉庭院之间的关系与当前统一建筑底标高尚不闭合。仅凭照片窗行数整体升降建筑，会破坏现有主连桥接口；032中局部低房间也不能证明存在完整额外地下层。因此本批保留坐标原点、底标高和低层楼板，没有为了外观相似而擅自移动整栋楼。

## 实际修改

- 在历史五层图配准的前部上层凹口两侧补黄色马赛克饰面，保留后方通廊及下方空院。
- 池侧后部上层补红色透空金属屏、竖向边肋及横框。近景孔洞可以透视，远处按屏幕像素过滤，避免细孔闪烁。
- 屏幕初版薄盒的前后网面产生摩尔纹，改为单张双面网格；黄色饰面外移避开旧窗台视觉穿出。
- 没有新增穿过上层空院的行走地板，摄影机近景位置不代表玩家能站在那里。

红屏起止范围、层高和板宽仍为照片拟合；上层饰面改善不等于低层黄色入口已经修复。下部完整入口、底标高和局部低房间仍是下一批主线。

## 验证

仅检查两层现有通廊与新增屏边界，并查看池侧宽景、黄色凹口和红屏近景。6段分批实走（2起点）、5检查通过，无引擎错误；7图已查看、3最终细部图有效。结果见 `tests/artifacts/student_pond_upper_v162_accepted.json`。首轮有摩尔纹、旧窗台穿出及近裁剪错误的画面保留但不作为最终细部证据。

证据与日期边界：`references/visual_build_20261008/student_pond_upper_v162.json`。东门原点固定，真北未校准。下一批将主连桥—池岸—下沉院—一层平面/剖面放在同一标高关系中核对，再处理低层凹廊与入口，并继续图书馆后路G/2F、D至F/G及全A–G，Goal active。
