# V216 旧馆—道远楼外围步道与校园边界

开发2.1.4-dev / 模型V216。固定正式v2.1.3及两个入口保留；全下园A–G Goal与小时接续保持active。

## 依据与拟合边界

2026年5月校园地图、建筑师043总图和旧GTA几何均支持知新/道远楼外侧道路、旧南门开口与校园边界的关系。建筑师文章发表于2025-12-24，图纸绘制日未确认；地图版本不等于测绘日期。旧GTA原资产只读，本批补两张局部俯视/斜视图；原模型年代、单位、材质和真实北向未校准，不整体导入游戏。

新模型在现有东门坐标系中沿X=-181、Z=-840至-624补4.6米宽步道，带8厘米实体铺面支撑；X=-184.5补矮基座、石柱和金属栏杆，保留Z=-820至-766的旧门整体开口。补路缘、排水收边及槽盖、窄树篱带。尺寸、围栏材质/色彩、树距均为拟合，旧灰模只能支持结构关系，不能用作实景颜色依据。没有新增无依据山坡。

原知新支路的两条步道伸至外围车道中线，现收至内侧路缘。道远楼内侧已有步道与两处楼梯接入，本批不叠加重复铺面。初批画面发现外侧路缘与沥青之间漏出默认草地，最终补齐排水硬铺；收尾仅改变非碰撞外观。

## 验证与保留失败

一次初批物理检查前12段通过，覆盖旧馆支路、外侧步道、旧门入口、道远楼内侧和外围道路。第13段直走道路中线时停在Z=-770.62：既有旧门岗亭约位于(-173,-773)，占据道路中线。它不是新增围栏碰撞，也不能用本批通行代替旧门车道配准。

保留原失败，从前一有效端点另设一个起点，沿岗亭外侧X=-177绕行，再接外侧步道并往返尽端；这5段定向检查通过。因此有效证据为“初批12段 + 另一fixture的5段接续”，不是一次无传送17段全程，也不声称车辆、轮椅或全校园验收。测试脚本已记入正确行人转点。

4张初批画面、2张最终收边画面已查看；四次本批游戏引擎运行均无脚本/引擎错误，初批非零退出仅来自已记录的岗亭路线失败。旧GTA两张参考渲染也成功退出。物理结构未在最终铺面修正中改变，未重跑已验证线路。
