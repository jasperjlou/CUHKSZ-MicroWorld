# V77 主广场对面两条教学楼体

## 形体纠正

官方主广场背向两幅图及十周年启动区照片显示，诚道、志仁是窄端朝广场、长侧立面向后延伸，端面有地面层加五排上层窗。旧模型的宽横向楼块和 L 形返回翼未形成这一关系。本批重建两条楼体，窄端灰色嵌板、四列窗、紫色标语与底层玻璃分开建模；志仁朝外园的一侧采用成对窄窗和悬挑设备栏，补白色柱廊、凹入墙面与花盆。

两楼模型中心 X 改为 74，宽20/长60，保留沿街 Z 顺序和现有台地高度；五排上窗依据可见，实际层高和米制尺度仍拟合。乐天旧返回翼与恢复后的志仁长楼重叠，已移除；后方乐天主体保留，真实交接段仍需核对。

移除了穿过台地和楼身的旧平地 garden_walk 可视带，路线转由既有上台地通道接乐天开门位置；原“志仁—乐天花园”点改称之间步道，避免把志仁外侧石景花园错误指认成楼间空地。

## 证据年代

主要来源是拍摄日未知的官方场景116440774、116846254及十周年资料，2023-11上传目录不当拍摄年份，旧照片可见施工设备，不能代表当前绿化。2026年5月校园图只用于身份与邻接。本轮搜索未取得更新且可证实拍摄日的外立面照。

2024十周年活动页明确志仁首层有“时空胶囊黑匣子剧场”，本批柱廊不是整层室内完工；这一实体的围护、入口和真实室内应继续补证建造。

## 验证

以一条连续公共路线覆盖诚道窄端门、长廊侧出口、乐天入口、志仁外园柱廊及广场台阶。首批侧出路线沿柱中心误设，保留前4条有效记录，改用柱间路径后只续测剩余路线。续批20段全部通过，合计保留24条有效局部记录。两次模型运行没有引擎错误，最终4张画面已查看。受影响的V54旧楼体通行证据不代表新楼体。结果见 `tests/artifacts/square_classroom_bars_v77.json` 和 `tests/artifacts/square_classroom_bars_finish_v77.json`。

## 必须继续的部分

- 草坪、挡墙和台阶分布仍沿用V54拟合；主广场正面画面不能证实当前中央宽梯，必须优先与左右全景和航拍对齐，不以能走通认定位置正确。
- 两楼的准确间距、长度、真实层高、与乐天后段交接仍未测绘配准。
- 志仁外侧石景花园与钟楼/科研支路，楼内消防核心、各层走廊、黑匣子剧场未完成。
- 旧馆2026改造、图书馆主入口楼梯下方馆内空间及其余A-G所有留项继续有效。Goal保持active。
