# V208：图书馆后门层位与后场标高修正

2026-10-14；开发 2.1.4-dev / 模型 V208。全下园 Goal active，固定正式版 v2.1.3 和两个入口保留。

## 证据与决定

官方后路全景 70037189 显示，4F–6F 大玻璃端面下面只有两排灰墙窄窗。重新比对校方 1F/2F/3F 图、建筑师剖面、旧 GTA 33.04/43.04 原单位水平切面和后侧三维图：33.04 的宽后翼对应 2F 办公室体量，43.04 的缩进后翼及露台对应 3F；旧模型后路三处交点为 31.24，接近宽后翼楼板，而不是下层公共面 26.78。结合剖面保留三个下部内部楼层的关系，将后路入口改接 **2F**，撤销 V150/V180 沿用的 G 入口假设。这里是多源拓扑判断，不是测绘或精确米制配准。

官方图页当前六张图片 URL 与旧索引相同；1F 文件名 202401、2F/3F 路径 2021-11 是版本线索。全景拍摄日期未知；建筑师文章发布 2021-03-16，图纸修订日未知；旧 GTA 制作年未知。没有用重取日期宣称资料更新。依据、哈希及稳定副本见 `../references/visual_build_20261008/library_rear_level_v208.json`。

## 实际修改

- 后门、窄窗底排和门廊接到 2F（局部 y=4.4）。保留三短阶与侧坡；后场拟合完成标高 world y=6.16，门廊 y=6.64。没有把上部大玻璃框降至 3F。
- 后场沥青、后路连续过渡、对侧挡坡/排水和窄梯共用更新的道路标高。尺寸、道路坡度和绝对高程仍拟合，未宣称车辆或轮椅合规。
- 撤掉通向 G 的假直走廊；后门内只保留浅的未布置办公门厅，后界封闭。校方平面未公开的办公室隔间和公共通路不凭空编造。
- 保留主入口楼梯下的 G 公共空间及卫生间走道，在三扇卫生间门之后封闭旧外通路径；收窄抬坡范围，消除新地形侵入下层走道。
- 补三楼后翼楼板 0.28 米拟合厚度的边缘饰面，消除原先从楼板边看穿的缝隙。

## 集中验证及边界

初批 `LibraryRearLevelV208`：28 段连续通行通过，包含后门短阶、侧坡、车道双向和挡坡窄梯；5 项结构检查通过。其中旧 G 走道端点检查在后续边界调整后退休。

画面检查发现楼板边缝及 G 走道侵草，集中修复。第一次走道复查 5/6 段通过，回程目标贴近既有饮水机发生碰撞，失败保留于 `library_rear_level_v208_finish.json`。保留饮水机，改用真实空隙绕行；同时地形影响边界移到 world x=104.4 之后。

最终 `LibraryRearLevelV208Accepted`：7 段走道通行、2 项检查通过。与未受收尾改动影响的初批合计使用 **28+7 段有效通行、4+2 项有效结构检查**；不是一条连续全区路线。最终两张门廊/下层画面已查看，三次运行日志均无引擎错误，第一轮复查的路线失败没有删去。初批道路图片保留对应有效范围；旧整体图存在的楼板缝不能作为最终外观验收图。

本批更改的是局部结构关系。旧 G 后门路线验收退休，旧正式包不变。后门与现行办公使用是否开放、精确米制标高、学生中心共同配准和灰栏梯完整目的地仍未证明。
