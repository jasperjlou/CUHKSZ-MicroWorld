## 已实现

- 教学 C 从模型 72 × 47 改为 72 × 94，锚点由 `[-65,2.24,-325]` 移至 `[-86.62,2.24,-325]`。朝向 90°不变，前沿世界 X=-43.38 保留。原几何存入数据 `v43_previous_geometry`。
- 高柱廊整体平移到新局部坐标，保留世界位置和尺寸：双层玻璃、白色腰带、高窗、梁格、悬挂遮阳片、贴墙管线及灰色条石地面。内侧楼梯和上部回廊重新连接。
- 入口移到斜向楼翼端部，补门框、开启门扇及竖向门楣；入口后的走廊沿楼翼延伸，留真实侧口接院落，另一端接后步道。没有补造不可见教室名称或声称完整室内平面。
- 上部端楼采用玻璃体和金属包覆层，补低层绿化屋面；加深斜翼、短后翼及直侧翼，补石材院落、有限种植区、侧后环路和街侧树带。
- B/C 后路在 X=-135.12 连通，并在 Z=-272.5 补横向硬铺地接中央广场；C 柱廊外侧补石材阈值，消除与广场间的草缝。
