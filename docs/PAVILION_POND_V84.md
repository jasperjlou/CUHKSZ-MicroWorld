# V84 四拱亭、短阶与曲线水景

模型版本：`official-visual-build-84-pavilion-pond`。整个下园 Goal 保持 active。

## 实际改变

- 新建白色四面拱亭：四角支脚、连续曲面拱腹、平顶和石材基座。拱下留真实可穿行空间。
- 从亭下向钟楼方向连接四组短阶、草缝方石平台、低矮白色边条；地形随分段标高下降。
- 原通用草地切开为曲线池面与下沉池床，补曲折岸线、沿岸窄木道、跨水弯桥、三条石径接口及岸边荷叶。
- 中央直线铺道在亭后终止，两侧步道绕开水池；涂辉龙和逸夫方向支路接回外圈。移除这一范围旧程序花坛和穿池植栽，补树木、支撑、低灌木与矮灯。
- 新增不规则石板和小方石草缝两类材质，木道按实际窄板尺度渲染。
