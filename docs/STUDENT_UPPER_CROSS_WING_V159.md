# V159 学生中心上层跨院楼翼

开发模型 `official-visual-build-159-student-upper-cross-wing`，产品 `2.0.1-dev`。正式 `v2.0.0` / V145、GitHub及两个固定入口保持，未提交推送。

## 新证据改变实施顺序

[建筑师项目文章](https://www.gooood.cn/en/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm)发布于2021-05-28；此次重新读取现场照片009/012与剖面033，拍摄日/图纸修订日仍未知。012明确显示黄色封闭楼翼从院落上方跨过，并有较深的底梁和高窗，原模型却一直空缺这段体量。

现场照片证明跨院体量存在，不能独立给出准确楼层和进深。文章确认031标签为五层平面，中央仍开敞；本轮把黄色体量拟合在五层以上、当前模型19.6m层，并以中间楼块u410–592和对侧边界v440约束范围。这是照片约束下的高层体量拟合，不能称作已拿到独立六层平面。原五层空院继续保留。

与此同时，029/030的后侧封闭梯位与031的开敞梯迹明显不一致。本批没有把它们强行连成又一根G–6F核心；低层核心顶层出口与上方独立院落梯继续单独核对。

## 模型

- 补当前最高使用层的跨院楼板、屋面、两面黄色高窗围护和底梁，形成可进入的封闭空间。
- 与已有通廊交叠的v228–240楼板没有重复添加；屋面延续薄非碰撞饰面，避免共面闪纹。
- 打开北侧通廊至新楼翼、楼翼至南楼翼的连接，撤去横在室内路径上的栏杆和重复五层的六层墙段。
- 五层院落空洞、护栏、房门和南侧封闭边界保留。房内功能及装修未知，不虚构具体房间身份。

参数/照片哈希/不同楼层梯位判断见[证据文件](../references/visual_build_20261008/student_upper_cross_wing_v159.json)。
