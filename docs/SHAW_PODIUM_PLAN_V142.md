# V142 逸夫东座院落与首层轮廓

2026-10-12；模型 `official-visual-build-142-shaw-podium-plan`。产品仍为未发布的 `2.0.0-rc1`。

## 模型更新

按历史 1F/3F 平面重新拟合大小院落边界、楼板洞口、栏杆和种植范围，保留既有 68×58.6 游戏外框；不是实测尺寸。首层侧房改为外侧开门，补浅阶与落地平台，关闭原先误设的正面门。前房改为带转折的 L 形，补真实开口、共享核心墙与服务门边界。左后部补小核心壳体，尚无完整内部楼梯。

首层两处房间仍为未布置家具的结构壳体；右侧首层、二层及完整公共空间继续待核。没有把三层房间名单直接塞入首层。

渲染发现地形穿入侧房后部，现按占用范围切开地形，以已有楼板承托；后方挡土带、二层高位入口及接路保留。两处隐藏地标同步到当前可达房间。

## 集中检验

院落与入口调整后 48 段连续路线、8 项结构检查通过；修地形后只补侧房后角和楼板支撑的 13 段连续路线、6 项检查。合计 61 条分批移动记录、2 起点、14 检查，含重叠路线，不是 61 条独立路径或全区一次走完。最终运行无引擎错误。5 个最终视角已查看（2 个不受后续地形修正影响的视角沿用，3 个替换）。初次变量类型编译失败、草坡侵入及遮挡机位记录均保留并排除，见 `tests/artifacts/shaw_plan_v142_accepted.json`。
