# V112 图书馆远端楼梯、卫生间与独立楼层配准

2026-10-11；版本 `official-visual-build-112-library-remote-registration`。完整 A–G 精修 Goal 保持 active。

## 本批修正

远端楼梯从早期约 6.35×10.4 的体量，改为公开 4F 轮廓支持的拟合约 4.5×5.9；中心取归一图像 (204,361.5)，平面方向跟随现有公开图变换。旧中心 (-37.3,-12.5) 退休，新中心约 (-37.44,-15.85)，相距约 3.35 个模型单位。早期说明“约四米”指 V109 候选中心，本批按具体楼梯轮廓中心进一步修正，模型单位仍非实测米。

楼梯 G–5F 四段层间连接同步重建：1.55 宽梯段、两侧扶手板、完整/半层平台、侧向门洞、门框、标牌与顶部封闭。缩放已落实到几何与碰撞尺寸，没有对整个人高或物理父节点非均匀缩放。各层洞口改在楼梯自己的坐标系裁切，旧大洞口区域恢复楼板。

三至五层卫生间按图示改成进深不同的并排两室，门朝后侧横向通道，补门框和饮水机；不再沿前后方向排成两间同向门面。一、二层保留原来的女厕/无障碍/男厕入口身份，后移并收齐前沿，避免侵入新梯井。下层三室的完整边界与现场门向尚未完成独立配准，不宣称是当前实测内部平面；厕所仍为封闭房间体量，不虚构内装。

## 依据与配准结果

重新打开[校方馆内地图](https://library.cuhk.edu.cn/zh-hans/floor-maps)，并查看本地 1/3/4/5/6F 图。来源 manifest 在 `references/visual_build_20261008/originals/library-plan-20261010/manifest.json`：1/5F 文件标注 202401，6F 托管目录为 2025-08，3/4F 为 2021-11；这些标记不是实景拍摄日期。本批处理稳定平面关系，不用旧图替代十周年较新外景。

独立手工选点与相似变换结果存于 `references/visual_build_20261008/library_upper_registration_v112.json`，可用 `tools/register_library_upper_v112.py` 复现：

- 五层到四层：8 个对应点，RMS 2.92 个归一图像像素，比例 0.82493，旋转约 -0.056°，平移约 (154.90,20.38)。远端梯中心残差 2.7 像素，支持本次位置修正。
- 六层曾将缩减楼板的左前角误当四层外墙角，结果 RMS 66.58 像素。该点身份不同，已从稳定外壳候选中排除，不能据此挤压整栋建筑。
- 六层其余 6 个候选点 RMS 10.08 像素，其中左 L 梯端仍有 18.4 像素偏差；这是独立诊断，不是精确配准完成。当前六层模型还没套用这次变换。

五层图还揭示珍藏阅览室应为顺着前缘转折的轮廓，与当前后退矩形房间不同；六层左前缘不能继续直接沿四层外墙。两项列为下一批实质模型修正，不能让路线测试通过掩盖平面差异。

## 集中验证及边界

初查发现斜扶手实体端部伸入转弯平台，造成横向换跑受阻；已缩短斜板与扶手端部，保留梯段防护并清出转弯净空。修复后 G–5F 上下行、各层侧门与三至五层厕所门前通道连续通过。4 个梯井探针均确认没有被楼板封死。

接后门时，旧测试捷径从厕所通道斜切到坡道，穿过坡道侧缘而失败；未拆除正确坡道边缘迁就路线，改走内侧实际门口再进入坡道。有效记录、最终画面及源文件哈希在 `tests/artifacts/library_remote_v112_accepted.json`。本批未重跑未受影响的右侧曲线梯和其他下园路线。

最终保留主批次 67 段连续有效移动、后门路线 8 段、女厕门面收口后 2 段，共 77 条分批记录、3 个起点，不是一次全馆巡游。5 张图已查看：梯段、四层侧门、并排厕所、下层门面及其修复后近景；原下层门面图因女厕与后墙重叠退休，最终 4 张有效。女厕后边界收至 -25.2，门面与旧后墙不再相交，该下层房间深度仍是待整体配准的拟合值。女厕边界调整不影响已验证的楼梯、上层厕所以及公共走道，故只补查其门前。三个有效日志无 ERROR/SCRIPT ERROR；最后验证后未再改模型。
