## 实际修改

1. `LibraryInteractive119.gd` 替代通用三桌房间。按较新实景制作两面内部玻璃、两个入口、黄白方形墙板、偏置投影幕/吊装投影机、圆柱、移动白板与显示屏、细孔吊顶/面灯和灰地毯。24 把蓝/紫座面网背椅是代表性活动布置，不宣称永久家具数量或场地容量。投影墙在平面上的朝向、圆柱偏移和约 9.2×10.6 尺寸仍拟合。
2. `LibraryLowerRightPlan.gd` 用逐渐收窄的折曲边界替代右端矩形边界，补连续碰撞地面、地毯、裁切吊顶和外端围护。119 后角接回 V105 后侧轮廓，移除旧矩形后墙；右端具体弧度、玻璃材质与上层对应待更强实景依据。
3. 两间安静舱移到公开图示的外端斜边，入口转向公共学习区，学习桌让出连续通道。
4. 上层旧弧面玻璃/立柱的下层部分不再横切公共区，亭体端部冲突段改成上下分段；上层主体位置保持，不能据此声称上下层已经精确配准。超出旧上层平面的局部补同标高盖板，完整外轮廓仍待剖面对照。
5. 新增细孔材质 44，远处衰减细孔以降低闪烁；使用分组静态网格和静态碰撞，没有导入重型旧包 GLB 作为游戏运行场景。

修改前文件保存在 `.tools/backups/library-interactive-before-v106/`。无提交、推送或原始资产改动。
