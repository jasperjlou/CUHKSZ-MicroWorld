# V151 学生中心下层门位与院落围护

2026-10-12，开发模型 `official-visual-build-151-student-lower-entries`，产品 `2.0.1-dev`。固定正式版 v2.0.0/V145 未覆盖，完整下园 Goal active。

## 本批实际修改

- 学生中心后墙原正中 6 米占位口封回灰砖窄窗。依建筑师 1F 图将两个后侧开口拟合在本地 X=-9.6、-24.0，补内退门框、开启门扇、侧壁、过梁与石材门槛；主开口接一条约 13 米的内部窄通道。门厅侧服务门暂作关闭表现，具体门位和用途仍拟合。
- 最低院落的黄色墙补两处开门与地面接缝，使下层院子可进入现有底层大厅。保留敞厅，不凭外观照片增设房间和低矮吊顶。
- 三段黄色院落立面原来每扇窗旁存在约 1.2 米未封闭竖缝。本批用按区间生成的实墙补齐，保留楼梯开口；按现有各层高度拆分窄窗、灰色上部板、窗楣、横框与细竖框，避免一片玻璃贯穿两层。
- 开发版 Agent 的后路章节改在偏置后门前停留，移除原中央假门坐标。固定正式包的展示路线不受源码改动影响。

源码：`world/visual_campus/StudentLowerEntrances.gd`、`StudentCentre.gd`、`StudentTerracedCourts.gd`、`world/product/ShowcaseChapters.gd`。新增模块已列入导出清单。
