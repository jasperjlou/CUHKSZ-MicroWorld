# V44 图书馆入口层位与公共阶梯纠正

2026-10-10。版本 `official-visual-build-44-library-entry-levels`，整个下园 Goal 继续 active。

## 本批发现与修改

对照官方 1F、2F、3F 图与二层入口全景，发现 V34–V43 把照片里的宽阶梯坐席放在了下层到二层的楼梯旁。官方图把室外主入口梯、二层门厅、馆内二层到三层的公共阶梯区分开；本批按该关系纠正。

- 新建斜向室外主梯及二层落脚平台、玻璃入口，拆除横挡在梯线上的通用低门廊。
- 将宽阶梯坐席移到二层门厅，旁边设置正常步行梯通往三层。三层楼板采用对应的斜向开口，并补两侧护栏和落脚连接。
- 补二层到达面和吊顶分区。阶梯坐席采用下部留空的结构，保留下层公共梯上方净高。
- 补室外主梯周围硬质铺地，保留下层两翼入口、共享通道和楼梯下方馆内空间。

新增主模块 `world/visual_campus/LibraryEntryLevels.gd`。东门原点和图书馆锚点 `[78,2.24,-290]` 未变，楼体局部到世界转换仍是 `(78-z,2.24+y,-290+x)`。

## 验证及修正记录

按受影响结构集中验证，失败后仅检验相关路线，不重复全校园：

- 初批 `library_entry_levels_v44.json`：下层两翼、横向通道、楼梯下口及出口 **8 段通过**；室外梯顶因平台侵入最后几级失败。
- `library_entry_levels_finish_v44.json`：修复平台后，室外梯到二层门口及到达厅 **4 段通过**；发现室内梯口与旧下层梯井之间缺落脚面。
- `library_entry_levels_final_v44.json`：诊断出三层新楼板三角面朝向错误，以及坐席实心底占用下层梯净高；该报告保留为失败证据，不作为验收。
- 最终 `library_entry_levels_resolved_v44.json`：补落脚面、纠正楼板朝向、坐席改为空腹结构后，二层—三层往返、室外下行和下层梯上下 **11/11 段通过**。最终构建 1517 ms，无脚本错误。前述 8+4 段不受最终局部修正影响，继续引用。

四张最终截图已查看。当前证据证明本批结构可通行；不能据此声称所有房间、全部楼层和外壳已经复原。
