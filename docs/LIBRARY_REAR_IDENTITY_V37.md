# V37：后侧建筑归属纠正、图书馆玻璃端面与后门

2026-10-10。整个下园 Goal 继续；V36 为实际进展，但其涂鸦墙对面楼体归属判断不正确，本批纠正后继续建模。

## 先纠正依据

展开[官方 Graffiti Wall 全景](https://campusvr-en.cuhk.edu.cn/?scene_id=116440797)的相邻图块，可同时看到大玻璃端面、内凹后院与折转金属楼壳。将这些共同特征与建筑师图书馆资料交叉对照，归属为**图书馆后翼**；学生中心的灰砖方体、多层黄色院落不符合这组外观。V36 中把该大玻璃体量列为学生中心后立面待建的判断撤销。此项是跨图的形体比对，不是全景热点标签直接给出的楼名。

- [建筑师提供的图书馆项目资料](https://www.gooood.cn/chinese-university-of-hong-kong-sz-library-by-wang-weijen-architecture.htm)，发布 2021-03-16，设计/施工记录截至 2017。其两个交错 C 形体量和面山阅览空间说明用于结构比对，不能作为当前景观年份。
- [建筑师提供的学生中心图纸与实景](https://www.gooood.cn/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm)，发布 2021-05-28。1F、3F、5F 与剖面帮助排除错楼；其中楼层基准和现模型仍需后续统一。
- 官方导览在 2026-10-10 读取；图像拍摄年未知。入口标签 `41803705` 实际图像仍是活动室，未当作外立面依据。主入口楼梯下方馆内下层的用户定义保持不变。
- 参考照片、图纸与来源记录保存在 `references/visual_build_20261008/originals/student-rear-20261010/`。原始全景相邻图块在 `originals/rear-wall-20261010/`，尤其 `e19dae8d99aa6175.jpg` 与 `3a51e1754adb4fa0.jpg` 要一起观察，不能只看单块裁切。

## 实际变化

1. 图书馆两端朝山的窄窗模板改为大玻璃端面，增加内退玻璃、厚金属外框、暖色侧壁、立梃与楼层横梁。沿用现有两翼轮廓；两端尺寸和对称程度仍是拟合。
2. 池侧后翼底座改为两层灰砖与细窗，补玻璃后门、约 0.48 m 高的小平台、三阶入口和侧坡道。坡道约 8 m 长、1.8 m 宽，均为模型估计，不是无障碍合规认证或实测数据。
3. 后门经内侧短坡接到馆内下层。集中检验发现旧内墙挡住入口，已分段开出通道，保留其他围护。
4. 护坡、窄梯与白廊架从学生中心段改放图书馆后侧；坡脚随既有后路标高变化。窄梯模型锚点为 `z=-313`，不是地理定位证据；照片没有控制点，准确位置、路宽和坡高还需配准。
5. 图书馆后场补连续硬铺装，移开该铺地范围里的通用路边树池；未把这些树挪进楼内。学生中心后路本身及上批硬铺地保留为拟合道路，不再用涂鸦墙照片证明它的准确位置。
6. 护坡踏步与地形采样对齐，修正坡面横向高差导致草地穿出踏步；侧边改连续收边，排水槽按车道切线转向。
