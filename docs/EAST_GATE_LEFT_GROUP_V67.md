# V67 东门左侧综合教学组团

依据建筑师二期项目页、摄影者 2026-03-06 发布的照片 6/7/9，以及 V66 官方全景配准，将旧单一门楼改为双塔、前方悬挑厅和后侧低翼围合的组团。东门原点、入校 -Z 和右侧 +X 保持不变。

## 已实现

- 两座错位高塔：浅石材大端面、偏侧竖向玻璃带、窄缝窗、侧面成对窗和暖色底座。内塔拟合高 36.8 米，外塔 40.6 米；并非测绘高度或已核实总层数。
- 前方白色悬挑厅、竖向板缝和两行英文校名；底部保留可行走空间。公共平台标高拟合为 4.4 米，厅底 8.2 米。
- 两跑前阶及中间平台、塔间抬高庭院、真正未封板的采光井、实体护栏、后侧低翼公共通道和下行接回中央步道的楼梯。
- 前庭、外侧和后侧补石铺地，前方默认草坪改为有边界的树池和通行地面；庭院补树、坐凳和栏杆。

实现入口：`world/visual_campus/EastGateLeftGroup.gd`；原 `gate_south` 记录扩为整个组团的平面外框。没有强行给每座塔分配尚未核准的 TxA–D 名称。

## 来源与边界

建筑师：<https://wwjarch.com/The-Chinese-University-of-Hong-Kong-Shenzhen-Phase-ll>。项目标为 2024，但不等于照片拍摄日期；文字明确入口左侧教学院落及两高两低的组合。摄影者：<https://www.beyondvision.cn/show/958.html>，发布于 2026-03-06，拍摄日期未知。照片 7/9 用于正面组合，6 用于外侧对照；完整侧面窗列、塔楼偏移和进深仍待配准。

本批另查看建筑师 03/04/05：它们属于入口右侧会议组团，不套用到左侧。名为 architect-aerial 的下载图实际是钟塔/科研区域，不是左门楼航拍。原文件名含日期只能作为线索，不能当成已确认拍摄时间。来源路径、URL 和 SHA-256 记入同批参考台账。

后低翼门洞、采光井尺寸、屋面构件、前后梯位置及全部米制尺寸仍为比例拟合；完整风车状平面、楼名、塔内楼层/电梯消防核心、悬挑厅内景和隐蔽侧后结构尚未完成。不能以公共平台走通代替整栋验收。
