# V210 学生中心两处后门铺地与后路连接

开发版 2.1.4-dev，模型 V210。固定正式版 v2.1.3 保留；全 A–G Goal 继续 active。

## 已落实

按已配准历史一层平面中的两处后门，将门前铺地接到车道，补第二处路缘开口及两处渐降端头。54米后侧铺地改为连续主体，移除同段宽窄步道重叠，补外缘硬铺和门侧收边。原拟合树木、灌木、路灯占据宽步道的部分移到对侧路缘外。路面随现有地形细分，未改变地形碰撞或增加障碍实体。薄铺面关闭自身投影，避免额外叠层阴影；接缝色差仍有可改进处。

## 证据边界

建筑师一层图 architect-029.jpg（文章发布2021-05-28，图纸修订/照片拍摄日未知）明确两处后门布局。旧 GTA 局部俯视仅辅助确认外围关系，旧坐标不能视为米。门外8.5米主体步道、3.3米支路、4.7米扇形口和0.9米路缘渐降均为拟合构造，不能称为2026实景精确复原。标为 entrance-panorama 的25308209实际为室内礼堂，本批复核后继续排除。
