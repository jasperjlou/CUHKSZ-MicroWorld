# V45 图书馆核心、折转前翼与连续楼面

2026-10-10。版本 `official-visual-build-45-library-cores`。本批为实质建模进展，整个下园 Goal 仍 active。

## 从资料到模型

官方 1F/2F/3F 楼层图中，入口两侧核心反复出现：一侧为三部电梯与消防梯组合，另一侧为斜向消防梯、一部电梯及卫生间组合。现有模型缺少这些实体，而且入口一侧被压成统一浅弧线，无法容纳图中核心及前侧公共空间。本批同时修改楼体和楼板，避免把新增核心做成外挂小楼。

- 新增两组核心的一至三层：折返楼梯、中间平台、门厅、实际侧门、井道开口、电梯门框/层号、卫生间门前界面和局部灯光。
- 电梯目前是关闭的门和井道围护，没有电梯运行功能；卫生间仅建有依据的门前界面，未编造内部设施。
- 前侧外壳由单一浅弧线改为按楼层图拟合的折转轮廓，屋面、立面切线和下层竖向格栅同步跟随。前翼现在容纳两组核心。
- 统一首层和二层楼面；左翼从窄廊扩展为连续公共楼面，与原有中央庭院外廊合并。楼板为公共梯及两组消防梯留真实开口。
- 下层前入口随轮廓移位，学习区入口、主梯及二层到三层公共梯保持相通；移走占据核心位置的一张通用桌，补回侧边学习桌。
- 根据已建成图书馆前侧照片的硬铺装特征，补齐格栅到中央步道之间的石材前庭，去掉该处露出的默认草坪。

东门原点、图书馆世界锚点 `[78,2.24,-290]` 保留。核心局部锚点分别为 `[-28,0,13.2]` 和 `[-6,0,23]`，后者旋转 45°。所有米制尺寸、核心进深和前侧轮廓控制点都是模型拟合；不能视为测绘数据。

## 验证

- 初批 `library_cores_v45.json` 保留为诊断记录：发现三层梯井切割使用了错误的坐标系，以及一条检查路线斜穿旧公共梯护栏；不作为最终验收。
- 修正坐标、前翼和连续楼面后，`library_cores_registered_v45.json` **54/54 段通过**：两组核心一至三层及回程、各层侧门、左翼楼面、下层入口/101 房间抽样、室外主梯及公共二至三层梯。
- 补齐玻璃/格栅边界后，只复验受影响入口：`library_cores_finish_v45.json` **7/7 段通过**。构建 1560 ms，无脚本错误。
- 最后铺地仅改可见材质面，未改碰撞；`library_cores_visual_v45.json` 保存最终前庭画面，没有重复跑路线。最终照片见 `courtyard-refined-library-registered-front-v45.png`。

本批验证不是全部电梯门、所有角落或整栋楼的完整验收。V44 旧外壳、浅二层轮廓及下层前门坐标已部分被替代；不能继续用其旧截图证明当前形态。

## 后续

四至六层楼板与核心延续、高层中庭/跨层楼梯、书墙、顶光空间，后翼及侧门的整体配准仍未完成。前侧折转段还需更精确的弧线、窗洞节奏及外部控制点；池边附属体、外围道路与景观也需复核。不能因核心能走通就宣称校园精修完成。
