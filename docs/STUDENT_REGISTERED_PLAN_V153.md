# V153 学生中心比例尺体量与院落重建

开发模型：`official-visual-build-153-student-plan-massing`，产品 `2.0.1-dev`。稳定 `v2.0.0` / V145 及两个本地入口保持固定。本批是体量和连接修正，整个下园 Goal 仍 active。

## 本批实际变化

- 以历史 1F 图 0/2/4/10 米比例尺的 13.785714 像素/米重建，原 70 × 95 米外包尺寸改为约 48.38 × 65.21 米。两翼前缘错开约 14 米，前端斜边和高层悬挑独立于低层；不再整体缩放旧矩形。
- 三个不同标高的院落、楼板洞口、三段室外梯和入口按同一图像坐标框架重做；黄色窗墙、分层窗楣、门框以及红色面板沿新边界生成。室外梯使用实际角色碰撞，侧栏杆保留。
- 历史 1F 图后侧两处门在新尺寸下重定位，内退门厅和硬铺同步；学生中心后人行道、车道及展示章节的局部路线移动至新后缘。前廊接口保留，原图书馆侧连廊撞墙处补拟合通口。
- `StudentRegisteredPlan.gd` 集中管理比例和坐标，`StudentRegisteredBuilding.gd` 生成新主体；停止调用旧 StudentCentre 矩形主体。旧辅助模块和证据仍保留。

## 来源与配准边界

主要来源是 [王维仁建筑师事务所提供的建筑资料](https://www.gooood.cn/en/student-center-chinese-university-of-hong-kong-shenzhen-campus-by-wang-weijen-architecture.htm)，发表 2021-05-28，项目期 2012–2019。本地 `originals/student-rear-20261010/architect-029/030/031.jpg` 为 1F/3F/5F 图，032/033 为剖面。图片拍摄日、图纸修订日未知；20261010 是归档日，不能作为拍摄日。该批历史结构依据不能证明 2026 年室内装修。

1F 图外包像素范围 `[25,24]` 至 `[924,691]`；米制比例来自 [V152 复核](CENTRAL_DATUM_REVIEW_V152.md)。世界映射：`X=44+(u-100)/13.785714`，`Z=-400+(458-v)/13.785714`。将图中 `(100,458)` 拟合到保留的前廊 `(44,-400)`，并保留地面 `Y=2.24`；这是游戏内定位锚点，未由测绘证明，地理北向仍未知。

5F 独立轮廓按图纸外框映射回 1F；3F 院落与阶梯按可见轮廓手工对应到 1F。**尚未完成共同核心点的最小二乘配准**，`third_to_first` 辅助函数未参与本批几何；不能将外框映射说成精准核心配准。局部标高 `0/4.4/8.8/12.4/16/19.6/23.2` 仍拟合。图纸上可见的细小凹口、低层核心与完整房间未全部复原。

图书馆侧连廊的拟合通口位于 1F 基准图 `u=235..296,v=24`、局部 `Y=4.4` 层：它用于保持既有跨区通行，**不是该门位已获实景核实的声明**。共享下首层服务区与历史 1F 后门仍分开记录，不混同。
