# V155 学生中心窗墙、金属面板和铺地细化

开发 `2.0.1-dev` / `official-visual-build-155-student-facade-finish`；固定正式版 `v2.0.0` 未覆盖。V154 的前核心、支撑和逐层通行属于实际进展，本轮延续该模型。

## 可见变化

- 灰砖立面撤掉过亮、突出的浅色窗套，改为较深的窄窗、暗灰金属框、上下分格和薄窗台。窗高、边框退深依建筑实景比例拟合；灰砖包住外墙处楼板边，撤掉原先切断砖墙的浅色横带，院落梁底仍保留浅色。原碰撞墙保持。
- 黄色院落窗墙将普通窗的可见玻璃收窄，补黄色侧边、暗色框和小壁灯；已有公共门洞保留宽度，不用缩门模仿窄窗。
- 红色金属面板补竖向折边、板块横缝，采用暖红色穿孔表面；不是木材贴图。面板分格约0.95米，仅拟合，未获得施工尺寸。
- 院落铺地采用约0.60米见方的浅灰石材模块，降低块间色差；高屋顶改低反射灰色表面，避免整片屋面像亮白广场铺砖。模块、色值和灯具位置均为代表性拟合。

主要形态对照为建筑师来源 `architect-010.jpg`、`architect-013.jpg`（发表2021-05-28，拍摄日未知）：暗色窄框、黄色小砖墙/灰窗楣、红色面板折缝、院落浅灰方砖及门边壁灯。外景结构可作历史依据，不能据此宣称2026年全部装饰已核实。原点、真实北向未校准和楼层/尺度边界仍保留。

## 十周年照片核对结果

[学生事务处2024-03-20报道](https://osa.cuhk.edu.cn/zh-hans/article/1142) 描述2024-03-09活动。此次实际下载并逐张查看三个已登记资源：`osa1142-1` 是有临时折纸装饰的电梯内景，`-2` 是食品近景，`-3` 是表演布景。它们不能证明室外院落门位、固定红砖墙或铺地。没有据临时布景修改永久模型。

文件名的2024-07-25是截图名日期，不等于拍摄日。三个原图、本地SHA-256和地址保存在 `references/visual_build_20261008/originals/student-anniversary-20261012/manifest.json`，仍属不打包的本地研究原件。`student_anniversary_followup_v154.json` 已从“未查看”更新为逐图适用范围；电梯确切楼层与核心身份未确认。

## 验证方式

本批不改楼板、门宽、楼梯、柱和碰撞几何。修改前用V154场景采集学生中心全部碰撞形状及世界变换；修改后再次采集，按形状类型、尺寸/三角面、变换、启用状态和碰撞层排序计算摘要。必须摘要一致，才复用V154的111条有效局部通行记录；这不把旧通行提升为全区验收，也不代表真实门位已确认。

本轮集中看正面、院落、窗洞、红板和屋顶五个GPU视角，未重复走全栋。原始结果：`tests/artifacts/student_finish_v155.json`；基线：`student_finish_v155_collision_before.json`；最终收据：`student_finish_v155_accepted.json`。
