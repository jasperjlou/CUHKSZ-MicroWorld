# 逸夫西座山侧地面与绕楼步道 · v29

参照[西座官方全景 116440787](https://campusvr-en.cuhk.edu.cn/?scene_id=116440787)中院落、栏杆和背山的关系。本地主要原图为 `references/visual_build_20261008/originals/landmark-instances/shaw-west/aca6809e91fdbdbf.jpg`、`8584e44b3334e0c2.jpg` 与 `06e8edfa3704c466.jpg`。模型沿用已建立的东门局部坐标和西座三翼锚点。

原草坡在 x > 155 后统一抬升，进入西座后翼底层。本批把楼后地形拟合为连续平地，在 x = 175.7 附近设置约 1.8 m 的挡土边界，再向原背山地形过渡。地形网格在边界两侧增加采样，挡土构件和碰撞与这条边界一致，两端渐变回原地形。

后翼底层补石铺地，外侧增加一条连续步道及两端返回前场的铺装，沿边设置窄排水沟、压顶和细栏杆。种植跟随新地形，随机树木避开建筑底部和新步道，补低灌木与乔木过渡。两个小休息点留在通行带之外。

这些是适配当前楼群的地形建模，**挡墙位置、标高、植物数量和绕楼线路不是现场测绘值**。原 51 条道路记录不变，新步道由专用模型绘制，避免与通用道路面层重复。新增一个可选导航点“逸夫西座山侧步道”。
