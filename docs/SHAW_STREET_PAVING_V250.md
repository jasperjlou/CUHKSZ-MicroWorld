# V250 逸夫沿街人字砖与灰石收边

2026-10-14，开发 2.1.9-dev/V250；固定正式包 v2.1.8 与双入口不变，本批未提交发布。

## 模型改动与来源

本批重新查看 V249 下载的官方全景 116443798/70040608 前面下排两张原瓦片。照片清楚显示靠弯道路缘的人字铺灰褐砖、楼侧长方灰石、两者之间的深色条带。本批仅把这些类别应用于逸夫新修沿街入口、石碑与附近街角，保留 70040609 对应前场步道的原独立铺法。

新增铺装沿保留道路的转弯曲线展开，裁到建筑侧界，分别绕开两个浅阶、触觉提示砖和椭圆石碑花床。灰石在墙脚与旧硬铺收边衔接；新饰面不覆盖沥青或楼梯踏面。人字纹由连续互锁的 2:1 长砖构成，细缝按屏幕像素过滤，远景不变成粗网格。灰石有适度深浅单元和细颗粒表面。

12×24cm 人字砖、30×60cm 灰石、2m 人字带、20–22cm 深色条宽与区块边界都是游戏拟合，不是现场测量。全景拍摄日期未知；没有把资源路径年份当拍摄日期。原件在 `references/visual_build_20261008/originals/shaw-registration-v249/`，本批没有新增下载或改变来源日期结论。

地形、道路、台阶和所有碰撞均保留。只新增视觉饰面，因此不重复 V249 通行测试。
