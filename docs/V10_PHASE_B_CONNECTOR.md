# V1.0 Phase B — 林缘与路侧过渡

## 建模前证据审查（2026-09-27）

先检查 Phase A 林缘终点、原参考包、V0.7–V1.0 文档及旧 DAE 提取，再补看官方全景。当前游戏坐标没有绑定真实地理锚点，因此延伸采用有来源支持的局部空间构成，**不能称为已复原真实上下园路线**。

### VERIFIED

- [湖口 42078153](https://campusvr-en.cuhk.edu.cn/?scene_id=42078153)：灰石广场、弧形浅阶、方形树池、平直通行带与树群；从同一拍摄点转向补看，未校准指南针。
- [环岛 116384446](https://campusvr-en.cuhk.edu.cn/?scene_id=116384446)：弯曲沥青车道、浅色路缘、红灰色路侧铺地、草地与修剪灌木；一侧可见浅色高层轮廓，另一侧为浓密树带。画面存在道路分向，不据此认定每支通向哪个校区。
- [音乐学院及第八书院北门 130095287](https://campusvr-en.cuhk.edu.cn/?scene_id=130095287)：门前车道、窄人行铺地、路缘、细杆单臂路灯；道路另一侧为绿化坡地。多个转向画面可见道路延续。没有把热点跳转当作实际行走。
- [校方招生说明](https://admissions.cuhk.edu.cn/node/909)：中园包含神仙湖、机动车道及绿道，连接上下园。该文字支持连接存在，不定位具体路口。
- 现存官方交通资料有书院—音乐学院—科研楼/体育馆等站序，支持交通经过这些区域；不证明步行路线、停靠坐标或班次在游戏中真实复现。

### INFERRED

- 将湖口的灰石通行带与两处路侧参考提炼成“林缘收窄→红灰步道→路侧视野打开”的局部序列；这是跨来源组合，未验证两拍摄点之间逐步连续的真实路线。
- 采用温和转弯、宽度变化、横向草地与车道远景，避免两排高墙形成线性关卡。
- 灯具、路缘、树群及未命名浅色建筑轮廓的位置、数量与尺寸均为推断。远景楼不根据热点标签强行命名为某书院。

### UNKNOWN

- Phase A 林缘坐标对应的真实方位、后续岔口顺序、坡底位置和实测高差。
- 具体人行连接的连续性、穿越车道的位置、无障碍条件，以及哪个端点确实属于上园或下园。
- 新路段是否应有台阶、挡土墙或护栏；证据不足，本轮不添加这些现实断言。
- 全景拍摄日期、与当前现场一致程度、实际站位。热点图是浏览关系，不是路径图。

### 旧模型的使用

沿用已核对的 4 个 DAE / 123 实例报告；它们没有可绑定本次湖口的命名锚点。仅作为下园局部骨架线索，没有用 DAE 单位估算米数、拼接道路或导入网格。


## 已实现范围

从 Phase A 的 Entrance_TreeWalk_End 移除旧边界，沿共享截面接入约 **35.238 个游戏单位**：林缘连接步道 → 红灰路侧步道 → 待核实连接端点。没有换算为实测米数。

入口维持广场宽度，随后收窄、轻转，再在终点打开视野。路线外保留可走草肩、林侧坡地、远处车道及两个未命名浅色高层轮廓。车道和建筑不可导航；不创建虚构的跨园实路。低植被与尽头边界限制尚未核实区域。

玩家按 **C** 切换林缘/湖边视角，移动保持屏幕方向，Agent 仍使用原世界坐标导航。原时钟持续运行，逛完新段再赴约可能迟到，没有修改截止时间。

新增 PaleCurb.tscn（可配置长度的浅色路缘）和 SingleArmLamp.tscn（单臂灯），共用 RoadsideAsset.gd。目录还登记程序化步道及远景，保留 Phase A 资产原版本。没有导入照片、全景纹理或旧网格。

## 视角对应与限度

| 游戏视角 | 对应参考元素 | 未验证 |
|---|---|---|
| 从林缘回望广场 | 湖口的灰石铺地、树池、浅阶与乔木 | 相机锚点、尺度 |
| 红灰步道与路缘、路灯 | 环岛与北门的路侧铺地、浅色路缘、单臂灯 | 精确弯曲和真实路口序列 |
| C 转向后的车道与浅色楼群 | 环岛向楼群一侧的道路、草地、高层轮廓 | 楼名、实际距离及进入路线 |

这是受参考约束的风格化局部构成，不是摄影测量复原。坐标、数量、宽度与拼接为 inferred；连续高程、底层陆地与封闭研究边界为 placeholder。

## 语义与分区

- ZONE_CONNECTOR_UNKNOWN：中文“林缘路侧过渡区”；active=true、confidence=inferred、real_connection_verified=false。
- ForestEdge_Path_02 / Roadside_Path_01：可行走目的地，confidence=inferred。
- UNKNOWN_CONNECTOR：可到达的本轮边界，connector=true、confidence=placeholder、evidence.connection=unknown。
- Connector_Road_View / Connector_Tower_View / Connector_Green_Slope：不可导航的远景地标；建筑 identity=unknown。

记录包含 zone、connector、landmark、walkable、obstacle、confidence、semantic_tags、evidence；scene metadata 与 API 一致。原 lake-4、navigate/inspect、WorldTime、EventLogger、接驳与 verifier 保留。新增路点加入原有连续列表，ETA 使用完整路线，没有导航瞬移或测试专用碰撞豁免。真实上园和下园分区仍未接入。

## Phase B Missing Evidence 与 Phase C

候选调查方向缩小为“湖口—环岛—书院侧”及“湖口—音乐学院北门—体育馆侧”，来自可见道路、校方说明、交通站序和全景线索；**两者都未通过连续地面证据验证**，不能认定精确岔口顺序或可走路线。

Phase C 优先补：

1. 湖口广场边缘至最近车道路口的连续地面视角，确认人行铺地从哪里离开广场。
2. 每个岔口的正面、反向和路缘，确认行人与车辆如何分开及在哪里穿越。
3. 坡顶/坡底对照、宽度和尺度锚点，核实连续高程。
4. 当前接驳站准确位置和带拍摄时间的资料。
5. 楼群身份铭牌或权威地图定位，再给远景命名。

资料不足前不开放车道远景、不硬连校区、不扩 Agent 功能。机器可读矩阵见 [v10b_connector_evidence.json](../references/regions/fairy_lake/v10b_connector_evidence.json)。
