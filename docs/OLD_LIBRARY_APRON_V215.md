# V215 旧馆支路校巴停靠区与围网阴影

开发2.1.4-dev / V215，固定正式v2.1.3。V214属于实际模型/验证进展，本批接续其路缘干扰和远端停靠区缺项。

## 实景与结构

用户20261010_222613照片里有三辆校巴，旁边是旧馆玻璃底层与球场支路。原图EXIF为2026-10-10 22:26:14 +08（文件名末尾为613），设备时钟未独立校准。官方92544949鸟瞰l-2-1也显示球场远端停放多辆车辆、场地与道路相邻；全景拍摄日期未知，不能将两套画面当成同日或最新车队清单。

删除原来盖在支路上的39×12米空沥青占位和不适配的三格标线；在球场尽端一侧建25×22米拟合停靠场地，保留原支路贯通及周边步行留边。补三辆静态校巴的车身、侧窗/前风挡、轮胎轮毂、顶置设备、后视镜和灯具；颜色与10.7×2.5米尺寸为拟合，不复刻运营商标识，也不是可驾驶车队。补P牌、车位线和照片/鸟瞰支持的后侧树带。真实场地边界、车辆朝向/数量变化、与旧馆的绝对距离仍需配准。

## 路缘干扰诊断

同机位保留正常阴影与临时关太阳阴影图；关闭阴影后砖面/路缘乱纹消失，指向围网密纹的阴影混叠。最终只取消LowerBasketballCourts细网面投影，保留可见网格、碰撞、立柱/横杆/矮墙及其投影；正式场景太阳阴影始终开启。初批还移除了详细路缘下重复的通用路缘带。细网投影省略是针对亚像素阴影的渲染近似，不声称精确物理阴影。

## 验证

新增车体碰撞后一次集中验证：1起点12段连续行人通行通过，覆盖车位外围、支路穿行及旧占位区域。它不是巴士转弯半径、车辆驾驶或全区无障碍验收。物理模式退出0，无引擎错误；不在后台反复完整渲染行走。

初批4张正常视图加1张关阴影诊断图已查看，视觉引擎退出0。发现轮胎底离地9厘米、前灯埋在车身内部，已修正这两个非碰撞外观问题；同时修改细网投影。最终两张定向画面已查看：路面和路缘的密集乱纹消失，立柱/横杆/矮墙阴影仍在；轮胎落地、前灯可见。收尾引擎退出0，无错误。物理结构和路线未变，不重跑12段。车辆造型仍较简化，外围空地及真实场地配准未完成。
