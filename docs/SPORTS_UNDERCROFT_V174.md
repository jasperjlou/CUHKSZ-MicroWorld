# V174 综合运动馆架空层与田径场连接

2026-10-12，开发线 `2.0.1-dev`。完整下园 Goal 继续 active；稳定版 v2.0.0 未覆盖，本批未提交推送。

## 参考依据

复看校方 [2023-03-14 启用导览](https://peu.cuhk.edu.cn/article/368) 的建成照片，以及摄影师 [2026-03-06 发布的实景](https://www.beyondvision.cn/show/958.html) 59–61：综合运动馆场侧有彩色三角透空屏、悬挑廊下裸露钢梁，远端底层为白色封闭体量；两馆之间的院落与田径场之间有架空通行空间。照片拍摄日期未确认，2026 发布不能直接等同 2026 实拍。

2021-09-09 设计图只用于辅助理解跨支撑体量和斜向屏风关系，不据此覆盖建成照片。两栋建筑身份保持区分，未把科研楼的全景背向图误当作大学体育馆背门。来源路径、哈希、日期及用途见 `references/visual_build_20261008/sports_undercroft_v174.json`。

## 实际改动

- 新 `SportsUndercroft.gd`：修复综合运动馆远端误作开放柱廊的白色封闭底层，补板缝和关闭通风口。
- 补蓝、黄、紫三组三角镂空屏，采用真实透孔网格并保留防穿越碰撞；加上缘与斜缘金属构件。
- 补中央架空层、下沉看台外廊下的钢梁及斜腹杆，两组底层服务体量增加分缝与关闭门面。
- 从两馆院落穿到田径场入口补连续灰色硬铺、窄边带和铺装分格；新增导航线 `sports_central_underpass`。
- 修正 `sports_between_halls` 原先穿过雨棚端柱的直线路线：柱子保留，通过已有硬铺绕行。该中心线不生成额外折线地面纹样。
- 自动展示补“场馆之间 · 走向田径场”一章，以地面穿行观察架空层、镂空屏和场边铺地。没有新增第三个应用入口。

尺寸、标高、梁网、孔格尺度及铺地细分仍是照片约束下的拟合；没有声称全楼服务房间平面、大学体育馆未见背门或地形测量已完成。

## 集中验证

`SportsUndercroftV174.gd` 初批保留2段通过，随后在既有雨棚端柱处中断；`SportsUndercroftV174Finish.gd` 保留24段，返程也遇到同一柱子。`SportsUndercroftV174Tail.gd` 从最后通过的路点继续，绕柱、进入服务区、沿两端通道绕行，20段全部通过。合计46条有效分批通行记录、3个起点，不能称为一次完整校园连续通行。9项结构检查通过，重复检查不累计；最终退出0，三批均无引擎错误。

两馆通道、中央架空层至田径场入口、服务侧门/正门、既有端梯前通道与白色封闭端两侧绕行均覆盖。场侧全貌、架空通道、屏风近景、白色端部4张最终画面逐张核看。早期机位落入相邻馆玻璃内，已替换；中间同名截图由最终收尾重新生成，接受清单记录最终哈希。191项导出依赖存在且唯一，差异空白检查通过。新展示章路径包含在物理检查内，整段展示镜头未另跑全流程。
