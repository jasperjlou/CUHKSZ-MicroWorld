# 航拍与俯视资料

这里整理能够帮助判断**大尺度拓扑、区域相对位置和整体环境形态**的航拍或高位视角资料。它们适合回答“哪些区域彼此相邻”“道路大致从哪里经过”这类问题，但通常不能直接给出可用于游戏坐标的精确尺寸、坡度或步行接缝。

## 当前条目

- `UPPER_OVERALL`：已审阅的官方高位照片，可用于上园整体形态与地标关系参考。
- `CAMPUS_MAP`：校园透视导览图。它是示意性导览图，**不是正射影像，也不是测绘地图**。
- `VR_130027047`：已抽看的湖区空中全景，可辅助理解神仙湖周边的大拓扑。
- `PUBLIC_AERIAL_VIDEO`：目前尚未完成有效审阅，因此不能作为建模结论的依据。

## 使用边界

航拍或俯视资料可以提高区域级判断的可信度，但不能仅凭单张视角推断：

- 精确道路宽度；
- 真实海拔或坡度；
- 人行道与车道之间的具体接入口；
- 遮挡区域中的连续地面；
- 游戏世界中的具体坐标和比例。

需要落到局部道路或行人连续性时，应与地面实拍、官方全景和其他同路段视角交叉核对。

原始文件、URL、审阅状态与许可备注统一见 [总资料索引](../index.json)，本目录不重复保存未确认可再分发的原件。
