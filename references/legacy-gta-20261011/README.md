## 画面已支持的参考价值

1. 连续建筑带并非孤立方块：院落、悬挑体、下部柱廊和跨场地连接都在几何里，适合校对当前错误的楼翼关系。
2. 门端到中央的教学组团存在不同高低体量、连续外廊与密集竖格栅，可用于下一批教学 A/B/C 的立面和院落配准。
3. 中部及场地另一端包含多个独立楼体、屋面设备/退台、台阶和外围场地边缘，有助于查漏及纠正道路与楼体间距。
4. 图书馆有独立楼层场景，值得进一步恢复并与公开 1F 平面、全景 G 层和用户指定的主入口梯下馆内下层比对；目前不能仅凭“1楼”名称认定对应标高。

## 仍须核实

- **年代未知**：引擎版本、文件时间及本次提取日期均不能作为模型制作日或实景拍摄日。以用户 2026-10-10 照片、较新校方实拍检查改建和景观。
- **尺度与方向未注册**：导出保留世界层级变换，再做 Unity 左手系到 glTF 右手系的 Z 翻转及三角面绕序转换。仅移到水平中心/最低点；原包围盒约 2392.15 × 194.59 × 739.61 原单位，不视为校园米制尺寸。真实北向仍未校准。
- **原材质未恢复**：灰色是检查用覆盖材质，不代表建筑颜色、玻璃、不透明性或地面铺装。原贴图、UV、灯光、碰撞和游戏逻辑没有包含在本 GLB。
- **非完整场景备份**：本次仅导出 `down` 下、引用 `sharedassets0.assets` 的主体网格；场景其他组、人物、植栽或独立室内尚未计入。
- **室内静态合批**：图书馆1楼已解析每个 MeshRenderer 的 `firstSubMesh/subMeshCount` 范围及材质引用；场景根合批为世界坐标，不再重复应用对象变换。导出错误0。该适配只对本包验证。
