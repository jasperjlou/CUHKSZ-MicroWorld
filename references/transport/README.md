# 校园交通参考

本目录整理与 **校园接驳车、站序、候车位置和车辆外观**有关的资料，用于支持 CUHKSZ MicroWorld 中的交通决策原型。

当前游戏已经实现 `walk / wait / board / abandon waiting / replan` 等行为，但这些机制首先是为了 Agent 任务与时间决策，而不是声称已经一比一复现真实校园班次和站点。

## 当前资料

- [routes.json](routes.json)：已整理的站序与交通参考记录。
- 2026 时刻表信息和 2023 巴士外观资料分开使用，不把不同年份信息自动合并成“当前真实状态”。

目前仍未完整确认：

- 原始站牌文字；
- 候车区真实宽度；
- 当前车辆涂装；
- 实际上下客侧；
- 所有站点的精确坐标；
- 原型车程与现实车程的对应关系。

## 游戏中的交通原型

现有 Shuttle System 主要服务于以下研究问题：

- Agent 在时间约束下是否选择等待；
- 延误是否触发改走步行路线；
- 是否会因为错误的交通选择导致迟到或错过活动；
- 是否能够在等待过程中重新规划。

因此，游戏中的接驳站、班次和车程允许标记为 `placeholder`。它们可以用于测试决策逻辑，但**不能反过来当作现实校园交通的证据**。

尤其要注意：游戏里已经存在的站牌或候车点坐标，是 authored world 的一部分，不能用这些坐标去“证明”真实站点就在那里。

## 后续补证方式

如果未来需要把交通系统做得更接近真实校园，应优先补充：

1. 同一时间版本的官方线路与时刻表；
2. 站牌和候车区现场照片；
3. 车辆当前外观；
4. 实际上下客方向；
5. 可重复核对的站点相对位置。

原始来源、日期和许可状态统一见 [总资料索引](../index.json)。
