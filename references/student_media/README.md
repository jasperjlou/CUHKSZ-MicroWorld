## 适合用来做什么

公开视频更适合辅助：

- 识别地标和建筑外观；
- 判断道路、绿化、路灯、栏杆等环境风格；
- 提供某一区域的大致视觉关系；
- 发现值得进一步核查的候选路段或设施。

它们通常不足以单独证明：

- 精确位置、距离和尺度；
- 人行道在遮挡处是否连续；
- 某个岔路的真实步行接入方式；
- 拍摄时的临时施工状态是否仍然存在。

如果未来使用视频支持具体空间结论，应记录拍摄时间、来源、关键时间戳、实际审阅范围，以及它和其他地面照片或官方全景之间是否存在可核对的重叠。
