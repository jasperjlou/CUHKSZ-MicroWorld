# 下园参考包

本目录整理与 **Lower Campus / 下园方向**有关的空间和地标资料，为后续完整跨校园 Journey 与下园活动终点建设提供依据。

## 当前在游戏中的状态

截至 `1.0.0-phase-e`，游戏已经存在一个可步行的 **Lower Campus 方向支路**，但它目前仍是方向性 branch stub，并不表示已经完整重建真实下园，也不表示已经到达某个经过验证的真实活动入口。

因此本目录当前主要承担两件事：

- 为后续 `LowerCampus_Event_Area` 或其他下园目标区域提供可追溯证据；
- 区分“下园方向的大拓扑判断”与“具体道路、入口、建筑位置已经验证”这两种完全不同的结论。

## 入口

- [pack.json](pack.json)：本区域的参考槽位、缺口和来源映射。
- [总资料索引](../../index.json)：通过 `reference_id` 查找原始来源、状态与许可备注。

## 使用原则

参考资料按 `verified / inferred / placeholder` 三档处理。对于下园区域，尤其不要仅凭导览图或远景照片推断：

- 精确道路转角；
- 人行接入口；
- 建筑间距离；
- 实际坡度与高差；
- 某个活动入口的真实位置。

如果缺少完整连续证据，可以采用合理推断完成可玩世界，但新增几何应保留 `replaceable = true`，并记录 inference basis。

目录中存在某个资料条目，不等于该视角已经实际审阅。需要做局部落地时，优先补同一路段的正反向、左右侧和连续地面证据。
