# 上园参考包

本目录整理与 **Upper Campus / 上园方向**有关的空间、道路与地标资料，为后续完整跨校园 Journey 的起点区域建设提供依据。

## 当前在游戏中的状态

截至 `1.0.0-phase-e`，游戏已经存在一个可步行的 **Upper Campus 方向支路**，但当前仍是方向性 branch stub。它表示“世界中已经有上园方向”，不等于已经完成真实上园的完整空间重建。

后续 Phase F 可以在这个基础上建立一个小型 `UpperCampus_Start_Area`，让玩家或 Agent 有一个明确、可辨识的上园出发点；但该区域不需要一次性复制整个上园。

## 入口

- [pack.json](pack.json)：本区域的参考槽位、缺口和来源映射。
- [总资料索引](../../index.json)：通过 `reference_id` 查找原始来源、状态与许可备注。

## 使用原则

本区域同样使用 `verified / inferred / placeholder` 三档置信标记。

航拍、高位照片和校园导览图适合判断区域级关系，但不能直接证明：

- 精确道路宽度和长度；
- 真实坡度和高差；
- 某个转角或台阶的具体位置；
- 游戏中的世界坐标；
- 被遮挡路段是否连续可步行。

如果资料不足，可以通过多来源一致性和校园空间逻辑建立 `inferred` 或 `placeholder` 几何，但需要留下推理依据，并允许未来用更好的实拍或全景替换。

目录中存在某个资料条目，不等于该视角已经实际审阅。需要做局部场景时，应尽量寻找同一路段的连续地面、正反向和侧向视角。
